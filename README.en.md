# baby-tutor · A 0–6 Science-Based Parenting Knowledge Base + Skill

Turn a 0–6 parenting problem into a **safety-first, age-routed, source-distilled** methodology answer.

A parent arrives with a concrete trouble ("my baby wakes all night", "my 2-year-old hits", "should I sleep-train?"). The skill screens for red flags, routes by the child's age into the knowledge base, and returns an **actionable strategy** — not generic advice, not internet hearsay.

## Capabilities

| Capability | What it does |
|---|---|
| **Safety gate (top priority)** | On a red-flag symptom (fever ≥38℃ under 3 months, respiratory distress, dehydration, seizure, fall with altered consciousness…) → output medical guidance only and skip every methodology. Bad parenting advice has physical cost; safety overrides everything |
| **Age routing** | Methods depend heavily on age (night waking at 8 months ≠ at 3 years). If the age is unknown, it asks first |
| **Two-level index + LLM routing** | Read the whole-library cluster map (`_route.md`), judge the *category · cluster* semantically, then read that cluster's sub-index and match on two channels. No vector DB, no service, no MCP |
| **Strategy-first output** | A clear judgment + executable steps + 2–3 alternatives (applicable families, costs, medical red lines); sources and evidence grades are compressed to one trailing line |
| **Contradiction resolution** | On opposing schools (sleep training vs attachment parenting, BLW vs spoon-feeding…) it gives a default recommendation plus which family each school suits — it never presents both as "do this", and never contradicts itself |
| **Evidence grading** | Every entry is tagged tier-1 institutional guideline / tier-2 peer-reviewed / tier-3 expert monograph / tier-4 popular idea |

## Knowledge base

- **2208 methodology entries, 10 categories**, all distilled from the **original text of 77 books** (the `extraction` field traces to title + chapter/page or an official URL). Non-original, pirated, book-summary, and OCR-garbled sources are all rejected
- Each entry has a **15-field frontmatter + a 13-section body** (including the two parenting-specific sections "Normal range & individual variation" and "When to see a doctor")
- Opposing cross-book schools are marked bilaterally via `conflicts_with`, which the consumer uses to resolve contradictions

## Retrieval architecture

A single category can reach 282 entries / ~50k characters — reading it all costs ~30–40k tokens just to pick 1–2 entries. So the index is genuinely **two-level**:

```
Route map    references/_index/_route.md                Whole-library 10 categories × 74 clusters, ~6k chars (LLM entry point)
Level 1      references/_index/<category>.md            That category's cluster table, ~1k chars
Level 2      references/_index/clusters/<cat>/NN-x.md   Entries within a cluster, median 2.8k chars
```

**Path**: safety gate → determine age → read `_route.md` and judge *category · cluster* semantically (1–2 candidates allowed) → read the cluster sub-index and match on two channels → read 1–2 full entries → answer per the output skeleton. If a cluster has no hit, it falls back to sibling clusters, then cross-category.

Both the indexes and the route map are generated by `rebuild_index.py` from entry frontmatter; cluster rules live in the script.

## Producer side · baby-distill

The knowledge base isn't searched — it's distilled from the **original text** of authoritative books. The producer is `skills/baby-distill/`:

- `references/format.md`: the entry standard — 15 fields + 13 sections + a chicken-soup filter (mechanism / steps / decision criteria / red lines — missing any one and the entry is rejected)
- Source quality gate A/B/C/D; scanned PDFs go through a **visual distillation protocol** (page-by-page visual read, discard what can't be read clearly, double-read verification)
- One book per subagent, distilled in parallel; distillation agents only write entries, the index is rebuilt centrally by the main session (parallel-safe)
- Medical figures are cross-checked against official guidelines

After every batch:

```bash
python skills/baby-distill/scripts/rebuild_index.py     # rebuild two-level index + route map
python skills/baby-distill/scripts/validate_entries.py  # mechanical validation (non-zero exit = hard defect)
```

## Design principles

- **Safety first**: red flags override every methodology
- **Age is the first routing dimension**: methods depend heavily on age; ask when unknown
- **Strategy over sources**: give the parent a clear judgment + actionable strategy; sources go to the last line
- **Evidence grading, no side-taking**: on contested topics, give a default recommendation plus which family each school suits
- **No chicken soup**: every entry needs a mechanism (with evidence strength) + stepwise method + decision criteria + red lines
- **Original text only**: low-quality sources are not distilled

## Boundary

No diagnosis, no drug dosages. For illnesses it only gives observation guidance / home-care boundaries / when-to-see-a-doctor thresholds.
