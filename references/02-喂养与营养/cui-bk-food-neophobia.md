# 宝宝对新食材"尝一口就拒"有两种——心理型是单纯怕新食物、多试几次会接受；过敏型是入口就黏膜瘙痒水疱，别执着换方式喂、至少停 3 个月

## 解决的问题

"用新食材做了辅食，宝宝就是不肯吃。"很多家长的第一反应是"他挑食"，于是换着花样做、追着喂，甚至怀疑是"天生嘴刁"。但也有人担心："会不会是过敏？"

原书把这种"用新食材做辅食、宝宝却始终不吃"的现象叫做**恐新症**，并指出它**有两种情况：一种是心理上的，一种是生理不适（过敏）造成的**。分清是哪一种，处理方式完全不同。

## 核心判断

**心理上的恐新症**，是单纯对新食物的害怕与排斥——宝宝对新食物往往有**从抗拒到逐渐接受**的过程，并非所有宝宝都恐新、一个宝宝也不会对所有食物都抗拒。**遇到宝宝拒绝吃某种新食物，家长大可不必担心，也无须强迫。** **生理不适造成的恐新症**，大多表现为宝宝进食一种新食物后，**口腔黏膜、咽喉黏膜会出水疱、瘙痒等症状，这其实是一种过敏反应**。所以，当发现宝宝对一种食物**特别抗拒**时，**不要执着地换着方式添加，以免把过敏问题由口腔延伸到肠道，造成更严重的过敏**。原书特别提醒：**如果宝宝对某种食物过敏，至少 3 个月内不要添加这种食物，应寻找替代食品，不要一味强迫宝宝适应，以免加重过敏。**

## 机制

**为什么要分"心理型/过敏型"**：两者的外在表现都是"不吃"，但机制相反：心理型是**认知与习惯层面**的排斥，靠反复接触、熟悉化就能改善；过敏型是**免疫反应**，靠"多喂几次"不会好转，反而可能加重。用错方法（对过敏型执着添加）会把口腔的局部反应扩展到肠道，造成更严重的过敏。

**为什么心理型多试会接受**：宝宝对新食物从抗拒到接受是一个过程。新食物的味道、口感、气味都陌生，需要反复、无压力地接触，才慢慢被接受——这正是"不强迫 + 每天让尝"能起效的原因。

**为什么"执着换方式添加"是危险的**：如果宝宝其实是对某食物过敏，家长却以为"他不爱吃"，换着做法、追着喂，就等于**反复给过敏原**，局部（口腔、咽喉）反应可能**延伸到肠道**，过敏更重。

**为什么过敏要停 3 个月**：过敏的免疫记忆需要时间消退；短期内反复接触只会强化反应。所以原书给出"至少 3 个月内不添加该食物、寻找替代食品"的明确边界，并强调**不要一味强迫宝宝适应**。

## 诊断信号

**月龄判断**：本条覆盖加辅食后的 6 月~1 岁半。**不适用**：完全未加辅食的小月龄。

用本条：宝宝"对新食材尝一口就拒"、家长想分辨要不要继续试时。**不适用**：进食后出现口周红肿、全身风团、呼吸异常——按过敏/急诊处理（见 cui-bk-food-allergy 与红线）。

## 正常范围与个体差异

- 恐新症两类：心理型（单纯怕新食物）/ 生理不适型（过敏反应）
- 心理型：有从抗拒到接受的过程；并非所有宝宝都恐新、不会对所有食物抗拒
- 过敏型表现：进食新食物后口腔黏膜、咽喉黏膜水疱、瘙痒
- 处理边界：对某食物过敏至少 3 个月内不添加、找替代、不强强迫适应
- 个体差异：恐新程度与持续时间因人而异

## 实操方法

1. **先分辨类型**：是"单纯不爱吃"，还是吃完有口腔/咽喉异常（水疱、瘙痒）？后者按过敏处理。
2. **心理型：不强迫、反复尝**：每天无压力地让宝宝尝一点点，慢慢熟悉，不因一两次拒绝就放弃。
3. **过敏型：立刻停、别换招**：发现对某食物特别抗拒且伴黏膜症状，不要执着换做法添加。
4. **停 3 个月**：确诊过敏的食物至少 3 个月不添加。
5. **找替代**：用营养相近的替代食品补上这一块。
6. **记录**：记下哪种食物、什么反应，帮助区分类型。
7. **必要条件**：无法判断是心理还是过敏时，就医评估（见 cui-bk-food-allergy）。

## 备选计策

- **"熟悉化重复"路线**：每餐固定放一点点新食物在桌上、不逼吃——适用"心理型恐新"的家庭
- **"3 个月回避"路线**：对疑似过敏食物严格停满 3 个月——适用"过敏型恐新"的家庭
- **"就医定性"路线**：分不清类型时先看医生——适用"拿不准"的家庭

## 决策规则

- **怎么算对**：心理型宝宝对新食物的接受度随重复次数提高；过敏型宝宝停用后症状消失
- **坚持多久再评估**：心理型按周看接受度；过敏型回避满 3 个月再评估（遵医嘱）
- **出现什么信号换法**：尝试中症状加重 → 立即停、按过敏处理
- **何时需就医**：进食后黏膜水疱瘙痒、或拒绝伴体重不增 → 就医（见红线）

## 反模式

- **把一切拒食都当"挑食"**：漏掉过敏型，反复给过敏原会加重
- **执着换着方式添加同一种食物**：过敏可能由口腔延伸到肠道
- **确诊过敏还"多试几次就习惯"**：至少 3 个月不加
- **心理型靠硬喂解决**：强迫会加剧抵触
- **宝宝拒绝就彻底放弃这种食物**：心理型需要反复、温和地再尝试

## 边界

- 本条讲"恐新"的分型与处理；过敏的确诊见 cui-bk-food-allergy
- 心理型恐新以"无压力、反复接触"为前提，不能变成变相强迫
- 有严重过敏/湿疹的宝宝遵专科医嘱

## 就医红线

- **进食新食物后口腔、咽喉黏膜水疱、瘙痒**——按过敏处理并联就医
- **对某食物特别抗拒、反复尝试后症状加重**——停止并就医
- **拒绝新食物伴体重不增/下降**——就医评估营养
- 出现全身风团、呼吸异常——立即就诊（严重过敏）

## 代价与风险提示

- 心理型要反复多试、慢慢接受，考验耐心
- 过敏型要停 3 个月、另找替代，喂养计划被打乱
- 要压制"多喂几次就习惯"的冲动，避免执着添加
- 分辨心理型/过敏型需要细心观察，判断失误有加重过敏的风险
