# 哺乳疼、含不住，多半是含乳方式错了——四种姿势按情况选，含乳要"含住大部分乳晕"不是只叼乳头

## 解决的问题

每次哺乳都像上刑：乳头被吸得生疼、甚至破了皮，宝宝含一会儿就滑掉、含不稳。你开始怀疑自己"不会喂"。其实，多数哺乳疼痛和含不住，都不是"你不会当妈"，而是**含乳方式错了**——宝宝只叼住了乳头，没有含住大部分乳晕。

原书给的判断很直白：**含乳正确与否，看上下唇、舌头、面颊、吞咽声这几个点就能判断；姿势有四种，按妈妈和宝宝的情况选。**

## 核心判断

**正确的哺乳姿势有四种：摇篮式（最常用）、交叉摇篮式（适合早产儿或新生儿，便于观察吃奶）、橄榄球式（适合剖宫产、乳房较大、乳头内陷/扁平、双胞胎）、侧卧式（较轻松，适合剖宫产或有侧切/撕裂伤口的妈妈）。但非特殊情况，建议不要用侧卧式哺乳，以防妈妈睡着后压到宝宝、或用乳房堵住宝宝口鼻而引发窒息。正确含乳的判据：宝宝上下唇向外翻、嘴张得够大、舌头呈勺状环绕乳晕、两侧面颊鼓起呈圆形、上唇含住的乳晕比下唇多、吸吮慢而有力、能看到吞咽动作或听到吞咽声。**

## 机制

**为什么"姿势"重要**（p70-72）：找到适合自己和宝宝的姿势，才能顺利、舒服地哺乳。四种常见姿势各有适用：
- **摇篮式**（最常用、最简单易学）：妈妈单手将宝宝抱在胸前，头枕在臂弯处，用臂弯支撑头颈、前臂支撑脊柱，同时张开手掌托稳宝宝臀部；宝宝面向妈妈，以手与地面水平的姿势侧卧，高度与妈妈乳房平齐、尽量贴近身体。为更舒服，妈妈可坐有靠背的椅子或倚床头，脚垫高，把哺乳枕或靠垫放在大腿靠近腰的位置。
- **交叉摇篮式**：与摇篮式类似，但宝宝的头是枕在妈妈的手掌上、不夹在臂弯里。适合早产儿或新生儿，可以让妈妈比较清楚地观察宝宝吃奶情况，注意宝宝不要过于后倾。
- **橄榄球式**：宝宝放在妈妈身体一侧，像腋下夹橄榄球一样，用臂弯夹住双腿、前臂支撑背部、手掌托住头颈部，另一手拇指张开呈 C 字形托住乳房。适合剖宫产（避免压刀口）、乳房较大、乳头内陷/扁平、宝宝太小或双胞胎。
- **侧卧式**：母婴面对面侧卧、宝宝嘴与妈妈乳头保持齐平，妈妈头下垫枕头或枕在臂弯上、另一手前臂支撑宝宝后背并扶住头部。相对轻松，适合剖宫产、有侧切或撕裂伤口。

**为什么慎用侧卧式**（p72，崔医生特别提醒）：除非特殊情况，建议不要用侧卧式哺乳。一旦妈妈在哺乳过程中睡着，乳房堵住宝宝口鼻，或翻身压住宝宝，很可能引发窒息等意外。

**为什么"含乳"是核心**（p72-73）：宝宝只有正确含住乳头，才能实现有效吸吮、吃到足够的乳汁。正确含乳的要点包括：上下唇向外翻、嘴张得够大、舌头呈勺状能环绕住乳晕、两侧面颊鼓起呈圆形、上唇含住的乳晕比下唇多、吸吮速度较慢且用力、有时可稍作停顿、能看见吞咽的动作或听到吞咽声。

**错误含乳的判据与纠错**（p73）：若出现以下情况说明含乳错误：上下唇向内抿、嘴张得不够大；只含住乳头、没含住大部分乳晕（这种情况特别容易造成妈妈乳头疼痛或皲裂）；宝宝鼻子被乳房堵住、无法顺畅呼吸；吸吮时两侧面颊内陷、没有鼓起；吸吮速度快、不用力，偶尔能听到咂咂声。含乳错误时，要让宝宝重新含住乳头——**不要强行将乳头从宝宝口中拔出，可以把手指放入宝宝口中，替换出乳头**。

（"正确含乳含住大部分乳晕、含不住时用手指替换出"与主流母乳指导一致。）

## 诊断信号

**月龄判断**：本条覆盖出生到约 2 个月（newborn-early 到 infant-1-2-months）的哺乳姿势与含乳调整期。**不适用**：妈妈乳头条件本身的问题（扁平/凹陷）走 cui-bk-nipple-problems；宝宝乳头混淆走同条。

用本条：哺乳疼痛、皲裂、含不稳，或想选对姿势。**不适用**：乳头破溃伴发热（可能乳腺炎/感染）——按红线处理。

## 正常范围与个体差异

- 姿势：摇篮式（最常用）/交叉摇篮式（观察+早产儿新生儿）/橄榄球式（剖宫产、乳房大、乳头内陷扁平、双胞胎）/侧卧式（较轻松但慎用）
- 侧卧式：非特殊情况不建议，防窒息
- 正确含乳判据：唇外翻、嘴大、舌呈勺状绕乳晕、面颊鼓起、上唇含乳晕多于下唇、慢而有力、有吞咽声
- 错误含乳判据：唇内抿、只含乳头、鼻子被堵、面颊内陷、快而无力伴咂咂声
- 个体差异：乳房大小、乳头条件、宝宝月龄不同，选不同姿势

## 实操方法

1. **先"含对"再谈姿势**：把宝宝抱到乳房前，用乳头轻触宝宝小嘴四周，刺激觅食反射、等他张大嘴。
2. **趁嘴张大时送入**：妈妈手呈 C 字形托住乳房，顺势将乳头和大部分乳晕送入宝宝嘴中。
3. **对照正确含乳要点自查**：唇外翻、面颊鼓起、上唇含乳晕多于下唇、能听到/看到吞咽。
4. **按情况选姿势**：剖宫产/伤口疼用橄榄球式；想观察吃奶用交叉摇篮式；最常用摇篮式。
5. **慎用侧卧式**：尤其夜间，尽量坐喂；若用侧卧，必须保持清醒。
6. **含错就重含**：不强行拔乳头，把手指放入宝宝口中替换出乳头，再重新引导含乳。
7. **把"含住大部分乳晕"讲清楚**：含的是"乳头+大部分乳晕"形成的"长奶嘴"，不是只叼乳头尖。

## 备选计策

- **"橄榄球式"**：避开剖宫产刀口、适合乳房大或乳头条件不佳——适用剖宫产/乳头内陷扁平家庭
- **"交叉摇篮式"**：手托头、便于观察含乳——适用早产儿/新生儿家庭
- **"半躺生物性哺育"**：（蒸馏者注：非本书内容，来自主流母乳指导）妈妈半躺、宝宝趴在胸前自主寻乳——适用产后初期、妈妈疲惫时

## 决策规则

- **怎么算"喂对了"**：宝宝含乳后妈妈不疼、有慢而有力的吸吮和吞咽声、面颊鼓起 → 含乳正确
- **坚持多久再评估**：每次哺乳都对照要点；疼痛多在含乳纠正后几天内缓解
- **出现什么信号换法**：若某个姿势总让伤口疼或漏奶，换另一种姿势（如橄榄球式）
- **何时需就医**：乳头皲裂出血伴发热、或宝宝含乳时面色发绀——见红线

## 反模式

- **只含乳头、没含住乳晕**：造成妈妈乳头疼痛/皲裂、宝宝吃不到奶
- **含错时强行拔出乳头**：易伤乳头，应手指入嘴替换出
- **夜间长期侧卧喂**：睡着后压到宝宝、乳房堵口鼻，有窒息风险
- **不管乳房条件硬套一个姿势**：乳头内陷/扁平应选更合适的姿势并配合纠正
- **鼻腔被乳房堵住仍继续喂**：宝宝无法顺畅呼吸，须调整姿势

## 边界

- 本条用于健康母婴的哺乳姿势与含乳调整，不替代医生/哺乳指导对具体情况的评估
- 早产儿、有口腔结构问题的宝宝，含乳方案遵专科医嘱
- 侧卧式在妈妈极度疲劳时风险更高，能坐喂就坐喂

## 就医红线

- **乳头皲裂、出血，伴乳房红肿热痛或发热 ≥38.5℃**——就诊（警惕乳腺炎）
- **宝宝含乳时面色发绀、呼吸困难**——立即停止、就医

## 代价与风险提示

- 反复调整姿势与含乳较磨人、耗时
- 夜间不用侧卧式要起身坐喂，妈妈更累
- 纠正含乳要一次次重新引导，需要耐心
- 剖宫产妈妈找舒适姿势更费劲、伤口可能疼
