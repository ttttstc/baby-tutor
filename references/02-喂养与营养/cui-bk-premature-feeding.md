# 早产宝宝出院后喂养：奶量由少到多、少量多次，母乳是首选；胎龄<34 周或体重<2000 克要在母乳里加母乳强化剂

## 解决的问题

早产宝宝出院回家，喂养是最让家长抓狂的一环：他吸吮又慢又弱，吃一会儿就呛、就吐，一次吃不了多少；到底该喂多少？能不能用普通配方粉？医生提到的"母乳强化剂"又是什么，非得加吗？

原书把早产宝宝的喂养单独讲了一整套逻辑：**喂养方式要看胎龄，喂养原则是"由少到多、少量多次"，母乳是首选，但高危早产宝宝要在母乳里加母乳强化剂。**搞清这些，喂养才有章法。

## 核心判断

**早产宝宝消化系统不成熟、胃容量小、吸吮吞咽能力弱，喂养要区别于足月宝宝。出院后：母乳是首选（早产妈妈母乳蛋白、脂肪、乳糖更高，钠更低，免疫因子更多，更契合早产儿需求）；奶量由少到多逐步增加，以"少量多次"为原则；妈妈确实母乳不足、宝宝体重下降超过出生体重的 7% 时，应在医生/营养师指导下用早产儿专用特殊配方粉，切忌擅用足月宝宝配方粉。凡出生时胎龄 < 34 周、或出生体重 < 2000 克的高危早产宝宝，母乳喂养的同时应补充母乳强化剂，否则可能生长缓慢、骨骼发育不良。**

## 机制

**三种喂养方式按胎龄匹配**：早产宝宝胃肠功能发育不成熟，应喂母乳或早产儿特殊配方粉，具体方式随成熟度变化：

- **静脉喂养**：胎龄 28 周前出生的早产儿，需通过静脉输注营养液（混有蛋白质、脂肪、糖、维生素、矿物质的注射液），不需要经过肠道就能补充营养。
- **胃管喂养**：胎龄 28~34 周、或已不需静脉喂养又无法自主吮吸的宝宝，用胃管（将小软管从嘴或鼻插入胃部），每隔数小时通过胃管喂食，喂食后可保留胃管、必要时也可移除。
- **乳头喂养**：胎龄 30~36 周、经医生诊断或能够吮吸乳头的宝宝可开始。**乳头喂养对早产儿十分困难**，起初要和胃管喂养交替进行，也可用早产儿专用奶嘴帮助强化吮吸反射、练习吞咽动作。

**为什么母乳是早产宝宝的最佳选择**：早产妈妈母乳的成分比例与足月妈妈不同，**营养价值更适合早产宝宝**——蛋白质含量更高，脂肪和乳糖含量更高，钠含量更低；更重要的是含有更多活性蛋白质、抗体等免疫因子，其调节免疫、抗感染、促进肠胃功能成熟的作用更大。所以母乳是早产宝宝最理想的食物和健康保障。（别以为婴儿配方奶更有营养，p466。）

**喂养原则：由少到多、少量多次**：早产宝宝虽然营养需求较高，吸收能力却相对较差。所以即使出院后，喂奶量也应由少到多逐步增加，以少量多次为原则。早产宝宝可能因吞咽功能不完善，不能吮吸乳头或奶嘴，也很容易出现吐奶或呛咳，**家长要耐心引导宝宝正确含乳、给宝宝足够时间学习和适应**，必要时可用早产儿专用奶瓶或浅口小匙喂养。

**母乳不足时怎么办**：如果妈妈确实母乳不足、宝宝体重下降幅度较大（**超过出生体重的 7%**），应在医生或营养师指导下，选择早产宝宝专用的特殊配方粉。**切忌擅用足月宝宝配方粉**——以免营养成分搭配、能量密度等不适合早产宝宝，对功能性器官造成过大负荷，不利于生长发育。

**母乳强化剂：高危早产宝宝的"加强版"母乳**：对出生胎龄小于 34 周、或出生体重低于 2000 克的高危早产宝宝来说，虽然母乳有营养和保护优势，**但仍不能完全满足其生长所需**，所以母乳喂养的同时往往要补充母乳强化剂，否则单纯母乳喂养很可能出现生长缓慢、骨骼发育不良等问题。我国《早产/低出生体重儿喂养建议》指出：凡出生胎龄 < 34 周、出生体重 < 2000 克的早产儿，都应在母乳喂养的同时摄入母乳强化剂（也称"强化母乳喂养"）。母乳强化剂能提供丰富的蛋白质、矿物质及维生素等，促进各种营养吸收，使早产宝宝在母乳喂养基础上实现快速追赶生长。**补充需根据宝宝实际情况，在医生指导下进行，以免造成营养过剩或营养摄入不足。**

## 诊断信号

**月龄判断**：本条覆盖出院后至约 6~9 个月，尤其早产宝宝出生后前 3 个月（普遍存在营养缺失、需追赶生长）。

用本条：家长要搞清早产宝宝怎么喂、奶量多少、要不要加母乳强化剂/特殊配方粉。**不适用**：足月宝宝按常规喂养即可。

## 正常范围与个体差异

- 喂养方式按胎龄：≤28 周静脉、28~34 周胃管、30~36 周可乳头喂养
- 早产母乳特点：蛋白/脂肪/乳糖更高、钠更低、免疫因子更多
- 喂养原则：由少到多、少量多次
- 改用特殊配方粉的触发：体重下降 > 出生体重 7%
- 母乳强化剂适用：胎龄 < 34 周 或 出生体重 < 2000 克
- 追赶生长：出院后加强营养以追赶，多数可逐月靠近同龄
- 个体差异：吸吮吞咽能力、奶量、追赶速度差异大，方案以医嘱为准

## 实操方法

1. **先确定喂养方式**：按出院医嘱沿用当前方式（母乳/胃管/乳头/专用配方粉），不自行跳级。
2. **少量多次喂**：每次别喂太多、别喂太急，分多次喂，给吞咽留时间。
3. **喂到一半歇一歇**：宝宝吸吮 3~5 分钟后，把乳头或奶嘴抽出、稍作休息再接着喂（见 p469）。
4. **耐心引导正确含乳**：吞咽弱的宝宝易吐奶/呛咳，慢慢教、给足适应时间，必要时用早产儿专用奶瓶或浅口小匙。
5. **首选母乳**：尽量母乳喂养；分离期也要吸出保存、送到宝宝嘴边（见 cui-bk-nicu-parent-role）。
6. **母乳不足且体重掉超 7%**：在医生/营养师指导下换用早产儿专用特殊配方粉，别用足月配方粉。
7. **高危宝宝加母乳强化剂**：胎龄 < 34 周或体重 < 2000 克，在医生指导下在母乳中添加强化剂，按量添加、不自行加减。
8. **盯体重指标**：定期称重、记录，体重是判断喂养是否得当的关键（见 cui-bk-premature-growth-monitor）。

## 备选计策

- **喂养日志**：记录每次喂奶时间、奶量、吐呛情况——适用"判断喂养是否得当"的家庭
- **分次小睡式喂养**：把一顿拆成几小顿、间隔喂——适用"吸吮弱、易疲劳"的家庭
- **营养师门诊**：请临床营养师核算强化剂/配方粉用量——适用"强化剂不知加多少"的家庭

## 决策规则

- **怎么算喂养得当**：体重稳步增长（在专用生长曲线上行）、吐呛可控、精神状态好 → 得当
- **坚持多久再评估**：出院后最初几天维持住院期哺喂量观察，适应后再逐步增加；按体检节点复评
- **出现什么信号换法**：体重下降 > 出生体重 7%、长期不增、频繁呛咳伴呼吸异常 → 就医调整（见红线）
- **何时可停母乳强化剂**：以医生按体重/身长追赶情况评估为准，不自行停

## 反模式

- **以为配方奶比母乳更有营养**：母乳是早产宝宝最佳营养来源
- **擅自用足月宝宝配方粉喂早产儿**：营养密度不匹配，加重器官负荷
- **一次喂太快、太多**：早产宝宝易吐奶、呛咳，要少量多次
- **高危宝宝只喂纯母乳、不加母乳强化剂**：可能导致生长缓慢、骨骼发育不良
- **自行加减母乳强化剂**：需在医生指导下进行，防营养过剩或不足
- **因喂养慢、吃力就放弃母乳**：早产儿乳头喂养本就困难，要坚持耐心尝试

## 边界

- 本条喂养方式、强化剂适用人群取自原书；具体奶量/强化剂剂量以儿科/新生儿科、营养师医嘱为准
- 静脉/胃管喂养属院内医疗操作，家长不自行执行
- 母乳强化剂是医疗营养补充品，须按医嘱使用，非常规家庭添加
- 特殊情况（代谢病、乳糖不耐、牛奶蛋白过敏等）喂养方案遵专科医嘱

## 就医红线

- **体重下降超过出生体重的 7%**——就医/咨询
- **喂奶频繁呛咳、吐奶，伴呼吸受影响或发绀**——立即就医
- **长期体重不增或持续下降**——就医评估喂养与营养（见 cui-bk-premature-growth-monitor）
- **单纯母乳喂养且胎龄 < 34 周或体重 < 2000 克，出现生长缓慢**——就医，评估是否需母乳强化剂
- **呕吐呈喷射状、呕吐物含黄绿色液体或血、大便带血**——立即就医
- 早产儿出现铁缺乏/贫血征象——就医，规范铁剂治疗（卫健委 2025；见相关条目）

## 代价与风险提示

- 母乳强化剂、特殊配方粉都要额外花钱，长期使用成本高
- 少量多次、每次限时的喂法更耗时耗力，家长睡眠与精力受挤压
- 早产宝宝吸吮慢、易吐呛，喂养过程反复受挫，需要极大耐心与家人配合
- 自行判断奶量/强化剂用量风险高，务必以医嘱为准，别照搬别人的方案
