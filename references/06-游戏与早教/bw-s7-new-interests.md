# 第七阶段的新兴趣

## 解决的问题

2~3 岁的孩子突然爱画画、搭积木、玩过家家，还开始盯着动画片看。这些"新兴趣"正常吗？该怎么支持？动画能看多久？运动上他又能学什么新本事？怀特把第 3 年的兴趣分成"持续的"和"新出现的"两类来讲。

## 核心判断

**持续的兴趣：第五、六阶段宝宝的三种主要兴趣——主要看护人、探索世界、练习新运动技能——在第 3 年中仍然是他大部分的行为，但有重大变化。** 社会能力方面，"原先孩子的社会兴趣几乎完全集中在父母身上，尤其是父母对他行动的反应上"，现在"一个新的重要元素——与同龄人的真正交往——开始出现并稳定增长"（p237）。探索世界方面，"在第 3 年中开始对一些重要方面产生兴趣"，"尤其值得注意的是，他们对语言的兴趣与日俱增，尤其是对跟他们直接相关的语言"（p237-238）。运动方面，孩子已"能够熟练掌握大部分在婴儿时期获得的基本运动技能"，超过 2 岁的孩子"都能轻松地走、跑、跳和攀爬，他们尤其喜欢后面的三种"，"在第 3 年中，孩子会获得一些新的特别技能，例如骑小三轮车"，"还会和第 2 年一样喜欢荡秋千"，其他运动挑战（学习使用胡桃钳或打孔器）"都会激起第七阶段孩子的兴趣"（p238）。**新出现的兴趣主要有三：①创作作品——第 3 年末期，孩子开始将两年辛苦获得的技术和信息结合，用于"完结活动（consummatory activity）"，你会看到他的"第一幅具象派绘画作品"（尤其得到鼓励或有兄姐可模仿时），以及"第一个建筑作品"（搭城堡或宝塔）；有情景玩具还会造出"家庭、农场或城镇"；②假扮行为——"越来越复杂的幻想游戏，既可能独自进行，也可能与其他人共同进行。大量的此类行为是孩子发展良好的显著特征"；③电视——第 3 年新出现的兴趣。**

## 机制

**为什么出现"创作作品"**：怀特把"创作作品"归结为"第 3 年末期"孩子把前两年积累的技能与信息结合起来，用于他称之为"完结活动"（consummatory activity）的行为（p238）。第一幅具象绘画、第一个积木城堡/宝塔、情景玩具搭出的城镇，"这是他们新获得的协调与组织能力的另一个标志"。他特别指出：这些兴趣"尤其是当他们得到了鼓励或是有哥哥姐姐可以模仿的时候"会更明显。**即：创作＝长期积累后的综合运用，需要鼓励与可模仿的对象。**

**为什么"假扮/幻想游戏"很重要**：怀特说"新出现的另一个非常有趣的重要行为是进行越来越复杂的幻想游戏"，可以独自、也可与他人共同进行——**"大量的此类行为是孩子发展良好的显著特征"**（p238）。这与他在第六阶段"假扮游戏是好发展标志"的立场一致（见 bw-s6-good-development-traits）。

**为什么"电视兴趣在第3年才出现"**：怀特说第 3 年中"另一个新出现的兴趣是看电视"，这种兴趣"在宝宝大约 4 个月的时候"最先反映为"对广告节目的反射式反应"，尤其是有突然音量变化的广告（p238）。他给了一个明确判断：**"长时间地看电视在第 2 年末或第 3 年初之前不会出现，因为这一行为所依赖的智力与语言能力的充分发展要到这个时候才会出现。"** 他还提醒："不要指望 2 岁半的孩子会看电视里的教人如何缝围裙的讲座节目，但他会对卡通节目中富于变化的声音和动作感兴趣。对于像《芝麻街》这样的节目，他也会表现出比较浓厚的兴趣——这种节目是针对非常小的孩子而特别设计的，能够不断吸引他们的注意力。此外，如果你允许，孩子对录像带也会越来越感兴趣。"（p239）这与其第六阶段"2 岁前不长看、2 岁后渐增"的观察一致（见 bw-s6-tv-screen）。

**为什么"语言兴趣上升"**：怀特注意到第 3 年孩子"对语言的兴趣与日俱增，尤其是对跟他们直接相关的语言"（p237-238）。这解释了为什么"听人说话时的凝视"行为增加（见 bw-s7-behavior-profile）——**语言成为他关注世界的核心渠道。**

## 诊断信号

**月龄判断**：本条管 **24~36 个月**（第七阶段）。

用本条：孩子开始涂画、搭东西、玩过家家；孩子对动画/录像表现出兴趣；你想知道该支持哪些新兴趣；孩子运动上想尝试新东西；你纠结"看动画"的时长。

## 正常范围与个体差异

怀特书内要点：

- **持续兴趣**：三种主要兴趣仍在，但"与同龄人真正交往"和"对语言兴趣"开始增长（p237-238）。
- **运动**：2 岁以上轻松走跑跳爬（尤爱跑/跳/爬）；第 3 年学会**骑小三轮车**；仍爱荡秋千；胡桃钳/打孔器等挑战引兴趣（p238）。
- **创作作品**：第 3 年末期"完结活动"——第一幅**具象派绘画**、第一个**建筑作品**（城堡/宝塔）、情景玩具造**城镇**；需鼓励/可模仿对象（p238）。
- **假扮行为**：越来越复杂的幻想游戏（独自/共同）；**大量此类行为=发展良好显著特征**（p238）。
- **电视**：第 3 年新兴趣；约 **4 个月**对广告反射式反应；**长时间看电视在第 2 年末/第 3 年初之前不会出现**；对卡通变化声音/动作、《芝麻街》、录像带感兴趣（p238-239）。

个体差异：兴趣出现时间个体差异大；早产儿按矫正月龄。

## 实操方法

1. **支持"创作作品"**：给绘画/积木/情景玩具材料与场地，多鼓励（p238）。
2. **多鼓励"假扮游戏"**：给道具、陪他"过家家"（p238）。
3. **夸作品也夸过程**：他需要鼓励与可模仿的榜样（p238）。
4. **适度看待动画/录像**：随语言智力发展才出现，仍以互动为主（p239，见 bw-s6-tv-screen）。
5. **引入运动新技能**：三轮车（第 3 年）、荡秋千、胡桃钳/打孔器（p238）。
6. **让语言成为核心**：多聊"与他直接相关"的事（p237-238）。

## 备选计策

- **"该给孩子学什么"的家长**：跟着"创作/假扮/运动新技能"的支持走（p238）。
- **"动画能看多久"的家长**：随发育可适度，但不替代互动与户外（p239）。
- **想培养创造力/想象力的家长**：多给材料 + 鼓励 + 榜样（p238）。

## 决策规则

- **怎么算"在轨"**：出现创作/假扮、运动有新尝试、探索兴趣在——即在轨。
- **坚持多久**：整个第 3 年。
- **出现什么信号换思路/求助**：长时间被动看屏替代互动、3 岁仍无任何假扮/创作、无任何探索或运动兴趣——发育评估。

## 反模式

- **只在意外在成果、忽视假扮/幻想游戏**：它才是发展良好的显著特征（p238）。
- **用屏幕替代互动/户外**：挤出语言与运动的时间（p239）。
- **只让孩子看、不提供创作材料**：错过"完结活动"（p238）。
- **强求超出月龄的复杂技能**：如要求 2 岁半看懂讲座类节目（p239）。

## 边界

- 本条为怀特的观察与方法论，非机构指南。
- 屏幕时间以现行 AAP/WHO 指南为准（见 bw-s6-tv-screen）。
- 早产儿按矫正月龄。
- 本条不含早教课程/材料清单。

## 就医红线

（2026-10-04 校准）

- **长时间被动看屏替代互动/户外/睡眠**——调整并评估
- 3 岁仍无任何假扮/创作、无探索或运动兴趣——发育评估
- 语言/社交明显落后——发育评估
- 任何月龄能力倒退——尽快就医

## 代价与风险提示

- 支持创作/假扮要提供材料与场地，家里会更乱。
- 动画/录像可适度，但别替代互动与户外。
- 运动新技能（三轮车等）需看护与场地。
