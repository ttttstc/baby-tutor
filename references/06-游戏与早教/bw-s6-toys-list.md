# 第六阶段推荐/不推荐物品清单

## 解决的问题

玩具买了一堆，孩子玩两下就扔；发条玩具、木琴、串珠看着"益智"却没人玩；祖父母要买礼物你又不好泼冷水。怀特列了一份第六阶段的物品清单（基于该阶段特有感兴趣：探索物品、练运动技能、尤其喜欢攀爬），并提醒一句关键判断：**"对于儿童教育的发展来说，没有任何一种商业玩具是真正必需的。"**

## 核心判断

**怀特强调："对于儿童教育的发展来说，没有任何一种商业玩具是真正必需的。"** 第六阶段的孩子"会花大量时间与父母互动，练习那些能够帮助他们控制身体的技能，并对居住的区域以及其中的所有东西进行探索，以至于没有太多时间来玩儿玩具"——然而"的确有不少针对这个年龄段孩子的商业玩具能够引起他们的兴趣，而且，祖父母在给孩子买礼物时也需要有所参考"。他的清单分四类：**大玩具**（小车/结实的四轮玩具；带较高手柄的四轮学步车，像超市购物车，推的时候起支撑作用；娃娃马车；摇摆椅；小滑梯和攀爬器具；玩具厨房，须配齐"食品""杂货"等；情景玩具如车库和农场；小桌小椅，适合与毛绒玩具/洋娃娃/家长过家家；玩具屋；户外玩具如带盖沙盒和直径 150 厘米的小浅水池）；**小玩具**（故事书，从最简单到带按钮发声的电子书；各种大小形状的球；较小的人物/动物形象娃娃，以及卡车汽车；"假扮"游戏道具如装钥匙镜子的钱包、玩具电话、茶具；一级/二级/三级拼图；涂鸦材料如一大叠纸和无毒可洗蜡笔；洗澡玩具）；**大物品**（大空箱子、大的防碎镜子、楼梯、成年人家具）；**小物品**（炊事用具、塑料容器、橱柜和抽屉里的安全物品、水——"特别推荐"）。不推荐：发条玩具（要求旋转旋钮 380 度太难，但如你愿意替他完成、双方都喜欢，买也无妨）；带槌木琴、串珠和牵拉玩具（"第六阶段的孩子很少会玩这些玩具"）；以及有潜在危险的东西（详见 bw-s6-dangerous-items）。**

## 机制

**为什么"没有商业玩具真正必需"**：怀特说得直接：孩子会"花大量时间与父母互动、练控制身体的技能、探索居住区域及其中所有东西"，"以至于没有太多时间来玩儿玩具"。这与他"自由探索优于玩具"的一贯立场一致（见 bw-s5-toys）。清单的价值在于"参考"，而不是"必备"。

**为什么"小物品里'水'特别推荐"**：怀特把小物品列了"炊事用具、塑料容器、橱柜和抽屉里的安全物品"，并特别标注"**水（特别推荐）**"。这与他在正文里对水的高度评价一致——"比很多其他游戏具有更为持久的吸引力""水可以有无限多种玩法"（见 bw-s6-toys-play）。

**为什么"不推荐发条玩具"**：怀特说发条玩具"都要求孩子多次将一个旋钮旋转 380 度，才能使盖子下面的娃娃弹出来"，"这个任务对于大部分第六阶段的孩子来说太难了"；不过他也务实地说，"如果你愿意为孩子完成上发条的工作，而且你和你的孩子都很喜欢这种玩具，买一个也无妨"。

**为什么"木琴/串珠/牵拉玩具不推荐"**：怀特说得很简短："第六阶段的孩子很少会玩这些玩具。"即这类玩具与第六阶段孩子的兴趣（探索小物、练运动技能、攀爬）不合拍。

**为什么"清单要有大物品"**：值得注意的是，清单特意包含"大空箱子、大的防碎镜子、楼梯、成年人家具"这类**不是玩具、但孩子极感兴趣的环境物品**。这与"第六阶段孩子喜欢攀爬、探索居住区域"一致——家里的箱子、镜子、楼梯、家具本身，就是最好的"玩具"。

## 诊断信号

**月龄判断**：本条管 **14~24 个月**（第六阶段）。

用本条：你想按清单给孩子添置玩具；你买了发条玩具/木琴/串珠孩子不玩；祖父母要买礼物、你想给建议；家里玩具多但孩子兴趣缺缺；你担心误吞/割伤风险。

## 正常范围与个体差异

怀特书内清单：

- **总原则**："没有任何一种商业玩具是真正必需的"。
- **大玩具**：四轮车/带手柄四轮学步车/娃娃马车/摇摆椅/小滑梯和攀爬器具/玩具厨房（配杂货）/情景玩具（车库、农场）/小桌小椅/玩具屋/带盖沙盒/直径 **150 厘米**浅水池。
- **小玩具**：故事书/球/娃娃与车/假扮道具（钱包、玩具电话、茶具）/一~三级拼图/涂鸦材料（大叠纸 + 无毒可洗蜡笔）/洗澡玩具。
- **大物品**：大空箱子/大防碎镜/楼梯/成年人家具。
- **小物品**：炊事用具/塑料容器/柜抽屉安全物品/**水（特别推荐）**。
- **不推荐**：发条玩具（需旋转 **380 度**太难，可代上发条）/带槌木琴/串珠/牵拉玩具（很少玩）/潜在危险物（p227-228）。

个体差异：玩具偏好个体差异大；早产儿按矫正月龄。

## 实操方法

1. **按"探索 + 运动 + 攀爬"选玩具**：贴合第六阶段兴趣。
2. **优先给"小物品 + 水"**：便宜、耐玩（p225，见 bw-s6-toys-play）。
3. **善用"大物品"**：空箱、镜子、楼梯、家具就是好玩具。
4. **不买发条玩具/木琴/串珠/牵拉玩具**：超出能力或很少玩（p227-228）。
5. **别迷信"商业玩具必需"**：多靠自由探索与亲子互动。
6. **给祖父母一份清单**：让他们买"对路"的。
7. **守住安全红线**：清理危险物品（见 bw-s6-dangerous-items）。

## 备选计策

- **想"买对不买贵"的家长**：小物品 + 水 + 大物品，省钱且耐玩。
- **祖父母要买礼物的家庭**：直接给这份分类清单。
- **"玩具一堆没人玩"的家长**：减少玩具、增加自由探索与"大物品"。

## 决策规则

- **怎么算"给对了"**：孩子长时间玩小物/攀爬/假扮、对商业玩具不过度依赖——即给对。
- **坚持多久**：整个 14~24 个月，随兴趣调整。
- **出现什么信号换思路/就医**：误吞/呛咳、割伤、危险投掷物致伤——见红线与安全条目。

## 反模式

- **迷信"益智"商业玩具**：没有一种"真正必需"。
- **买发条玩具/木琴/串珠/牵拉玩具当主力**：太难或很少玩（p227-228）。
- **忽略"大物品/小物品/水"**：最耐玩的往往不花钱。
- **给含 <4 厘米小件/易脱落尖轴的玩具**：误吞/割伤风险。

## 边界

- 本条为怀特的观察与方法论，非机构指南；清单为其书内口径。
- 玩具标签/品牌随年代变化，以现行安全标准为准。
- 早产儿按矫正月龄。
- 本条不含品牌推荐。

## 就医红线

（2026-10-04 依 AAP 与 safe-aap-injury-proofing 校准）

- **误吞异物（<4 厘米小件）/呛咳、呼吸困难**——立即急救并呼叫 120
- **被玩具尖轴/碎片割伤、刺伤**——就医
- 被危险投掷物（玩具士兵、高尔夫球）击中致伤——及时就医
- 玩具细小部件疑似被吞——及时就医/影像评估

## 代价与风险提示

- 按清单买能省钱又对路，但要顶住玩具营销。
- "没有商业玩具真正必需"，需靠自由探索/亲子互动。
- 危险物品要清理，家里收纳成本上升。
