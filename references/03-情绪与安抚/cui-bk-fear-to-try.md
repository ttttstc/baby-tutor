# 宝宝一遇困难就畏缩、崩溃大哭：拆解任务、给针对性指导、表扬他做到的——让他重新敢试

## 解决的问题

宝宝想自己穿鞋，穿不进去，急得把鞋一扔、大哭起来；想画个圆，画不像，索性把笔摔了，说什么都不肯再试。你一边心疼，一边犯难：替他做吧，怕他学不会；不帮吧，他又崩溃。是不是他抗挫能力太差？

原书说：**宝宝发现自己做不成某事时的各种反应，都没有对错之分——关键是理解他、引导他"再试一次"。**

## 核心判断

**当宝宝发现自己无法完成某项任务时，有的会坦然接受转而尝试别的，有的会求助让爸妈代做，有的会崩溃大哭——不管哪种表现，都没有对错之分。家长要理解他们，想办法引导宝宝再次尝试，具体靠三招：帮宝宝拆解任务、给宝宝有针对性的指导、对宝宝做到的事情给予表扬。**

## 机制

**为什么"表现没有对错"**（p409）：面对"做不成"，宝宝的反应只是他此刻应对能力的体现——**坦然接受、求助、崩溃**都是正常范围。**家长要理解他们**，而不是评判"这孩子怎么这么脆弱"。

**招一·为什么"拆解任务"能救场**（p409）：**在宝宝遇到问题时，家长可以将任务拆解**——**通常任务拆解后，就会降低完成每一步的难度，宝宝做起来会比较容易**。家长**可以视情况提供适当帮助，和宝宝一起解决问题**。把"穿鞋"变成"先打开鞋口、再塞脚尖、再拉后跟"，步步都能成，挫败就消了。

**招二·为什么"针对性指导"有效**（p409）：**有时候宝宝会因为"不知道怎么"而害怕尝试**。所以当发现宝宝遇到困难时，**应适时给他一些实用的、有针对性的指导**。比如他不知道怎么画圆，**是因为没掌握用笔技巧、或不懂借助圆形工具**，那就**提醒他调整用笔方法，或给他一个工具**——把"不会"变成"这样就会"。

**招三·为什么"表扬他做到的"**（p409）：**和宝宝一起面对问题时，应恰当地表扬宝宝做到的那些事**，让他**获得成就感**，从而**坚定继续面对问题的信心**。注意焦点是"做到的"，而不是"没做好的"。

## 诊断信号

**月龄判断**：本条覆盖 2~2.5 岁、能力与自信建立期（child-2-3-years）。**不适用**：畏难伴整体发育迟缓、极端崩溃无法安抚、长期回避一切新活动——见红线。

用本条：宝宝遇困难就退缩/哭、家长想引导他再尝试时。**不适用**：伴发育迟缓或长期退缩——见红线。

## 正常范围与个体差异

- 常态反应：坦然接受 / 求助代做 / 崩溃大哭，均无对错
- 对策核心：拆解任务 + 针对性指导 + 表扬"做到的"
- 关键态度：理解、一起解决，不评判、不代做
- 个体差异：气质、挫折耐受度因人而异
- 红线：伴整体发育迟缓、极端崩溃无法安抚、长期回避新活动

## 实操方法

1. **先理解不评判**：把崩溃当正常反应，不说"怎么这么脆弱"。
2. **拆解任务**：把大任务拆成他力所能及的小步。
3. **适当帮忙**：视情况搭把手，和他"一起"解决。
4. **给针对性指导**：指出"方法"上的卡点（用笔、用工具），而非代做。
5. **表扬"做到的"**：聚焦他已经完成的部分，给成就感。
6. **允许不完美**：结果不重要，愿意再试最重要。
7. **一步步加难**：能力长了再加挑战，别一步到位。

## 备选计策

- **"任务拆解法"**：把难事拆成小步——适用"做不成就要崩"的宝宝
- **"方法指导法"**：点破卡点、给工具——适用"不会所以怕"的宝宝
- **"成就肯定法"**：夸做到的、积累成功体验——适用"一失败就泄气"的宝宝

## 决策规则

- **怎么算"有效"**：宝宝遇困难后愿意再试、崩溃时长缩短 → 在改善
- **坚持多久再评估**：反复练习数周，看尝试意愿变化
- **出现什么信号换法/就医**：伴整体发育迟缓、极端崩溃无法安抚、长期回避新活动 → 就医/发育评估
- **何时必须就医**：见红线

## 反模式

- **贴"脆弱/抗挫差"标签**：把正常反应当缺陷
- **全权代做**：剥夺练习、强化"我不行"
- **只批评没做到**：打击信心、更不敢试
- **一步要求到位**：难度超能力、反复挫败
- **忽视发育落后**：把能力问题当"态度问题"

## 边界

- 本条针对正常的畏难情绪；伴发育迟缓、极端退缩遵评估
- "帮忙"是搭桥不是代做，火候要拿捏
- 挫折耐受随成长与经验逐步增强

## 就医红线

- **畏难伴整体发育迟缓、精细动作明显落后**——发育评估
- **遇到任何困难都极端情绪崩溃、无法安抚**——儿保/心理评估
- **因怕失败而长期回避一切新活动、退缩**——就医评估
- 伴精神差、进食睡眠异常——及时就诊（卫健委《3岁以下婴幼儿健康养育照护指南（2022）》，2026-10-04 核对）

## 代价与风险提示

- 要接受"各种反应都无对错"，家长先放平心态
- 拆解任务、给针对性指导，需要观察与耐心
- 表扬要焦点在"做到的"，措辞讲究
- 不代做、不指责，陪着一起解决的度要拿捏
