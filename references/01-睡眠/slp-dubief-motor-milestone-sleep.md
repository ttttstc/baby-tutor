# 白天学会新动作、夜里起来练——翻身爬站走的前几周睡眠会乱，白天多练把技能练熟，夜里「站起来了坐下不去」的游戏别奉陪

## 解决的问题

宝宝这几天特别兴奋——刚学会了翻身（或刚会爬、刚会站），白天一刻不闲地练，翻过来翻过去，笑得咯咯的。你正为他高兴，晚上麻烦来了：半夜他醒了，闭着眼睛也在翻身，翻过去又翻不回来，卡在那里大哭；你过去帮他翻回来，刚睡下他又翻过去。或者他会站了，半夜爬起来扶着栏杆站着哭，坐又坐不下去，非等你去把他放倒。一连好几晚，睡眠乱成一锅粥。

你开始怀疑：是不是白天让他玩太疯、太兴奋所以夜里睡不好？还是最近换了奶粉、出了牙？婆婆说「孩子在长本事，睡不好正常，忍忍就过去了」，你半信半疑——忍哪一周是个头？

Precious Little Sleep 第 12 章有一节叫「Baby Learns Cool New Stuff（宝宝学会酷炫新技能）」，第 7 章续篇还专门讲「宝宝在对睡眠『站起来』抗议」。作者点破一个规律：**新技能需要在白天和夜里练习，而宝宝偏偏挑小睡和睡觉的时间练**。好消息是：这通常是**几天到一两周**的事，等技能练熟，睡眠会自己回来。

## 核心判断

睡眠乱与「刚学会某个大动作」时间吻合，多半就是里程碑现象，不是作息或喂养出了问题。**解法是「白天帮他练熟 + 夜里不陪玩」**：白天搭好安全环境让他把翻身/坐/站练到自动化，夜里那个「站起来—坐下不去—等人来放倒」的循环，**别奉陪**——你每次进去放倒，都在把这个游戏强化成新习惯。同时**翻身期务必重查睡眠安全**（能否自主翻身决定襁褓的去留）。

## 机制

1. **新技能会「抢占」睡眠时间练习。** 作者观察：宝宝学会新技能后，会**在小睡和夜里醒来时反复练习**——大脑在巩固动作模式，醒来就想试。表现为「夜里不固定时间乱醒」「闭着眼也在爬」。
2. **技能「半生不熟」时最容易卡壳。** 会翻身但翻不回来、会站但坐不下去，是典型的「学了一半」阶段——人被卡在半路，只能哭求助。等动作双向都熟练，卡壳消失。
3. **「站起来」会固化成要人陪的游戏（第 7 章续篇）。** 作者把人分三型：还站不起来的、能站但坐不回去的、站坐都会的。**「能站不能坐」的宝宝最麻烦**——他会把自己拉起来卡住，你进去帮他放倒，他立刻又弹起来（Jack in the Box），很快学会「站着=爸爸/妈妈来陪我玩」。要打破它，得**白天先教会他「坐回去」**，夜里你才有底气不奉陪。
4. **翻身带来安全变量的变化。** 学翻身（尤其能翻成俯卧）意味着襁褓的安全前提消失——见红线。

## 诊断信号

**月龄判断**：多见于 4-12 个月（翻身 4-7 个月、坐 6-8 个月、爬 7-10 个月、站/扶走 8-12 个月）。**何时递减失效**：若睡眠乱与动作出现时间不吻合，或持续超过几周，别全赖里程碑，另找原因。

1. 睡眠乱与新动作出现**时间高度吻合**（前后几天）
2. 夜里频繁翻/爬/站，常**卡在半路**哭
3. 白天格外兴奋、不停练动作
4. 夜里醒来时间**不固定**，与平时习惯对不上
5. 白天可观察到该技能「半生不熟」

**排除项**：是不是同时有分离焦虑（见 slp-dubief-separation-anxiety）？是不是恰逢睡眠倒退节点（见 slp-dubief-sleep-regression）？

## 正常范围与个体差异

- **持续时间**：通常**几天到一两周**，随技能熟练自然消退。
- **强度差异**：有的宝宝几乎不受影响，有的每学一个新动作就乱几天；翻身和「站」是两种最典型的「乱觉」里程碑。
- **「学两遍」式的卡壳**：翻身、坐、站都有「会一半」的阶段，卡壳期长短因人而异。
- **正常现象**：半夜闭眼做爬行/蹬腿动作、翻身卡住哭，都属常见，不是梦游或疾病。

## 实操方法

1. **白天主动「加练」，把技能练到自动化。** 每天多次让宝宝在**软垫/地毯**上练目标动作：
   - 会翻但翻不回 → 辅助他练习**翻回来**
   - **「能站不能坐」的站坐练习（作者的具体做法）**：把他扶站在沙发/软椅旁，鼓励他自己坐下；把喜欢的玩具/零食放到地上，让他「只有坐下才够得到」；每天多次练，直到你确信他能自己坐回去。
2. **夜里不奉陪「站起游戏」。** 技能练熟后，宝宝可能仍会站起来邀请你玩。**礼貌拒绝**：
   - 第一次他「卡住」时，**只示范、不代劳**：拉着他的手、让他屈膝坐到或躺下（**不要直接把他放倒**，那会让他以为「被放倒」是技能本身，混淆训练）。
   - 示范一次后离开，「站起游戏」你的部分到此为止。
3. **若他坚持站着，甚至站着睡着** → 可以**蹑手蹑脚进去轻轻把他放平**（睡着时成功率最高）；他若醒，用固定的话重申「该睡了」，可拍背/抚肚**不超过 1 分钟**即离开——**待太久就是在奖励站立**。
4. **翻身卡壳期**：短期可以多次进房帮他翻回来（安全前提下），但同样**别把「帮他翻」变成整夜的陪玩**；白天把「翻回来」练熟是根治。
5. **重查睡眠安全**：能自主翻身后——
   - **停止襁褓**（见 slp-dubief-power-tools 红线）；
   - 入睡仍**仰卧放下**，但**他若自己翻成某个睡姿，可让他保持**；
   - 床内清空，确保无窒息风险物。
6. **别在里程碑期硬推进睡眠训练**：作者提醒，可与新技能错开，等动作熟练再继续训练；训练中遇到新技能卡壳，先处理卡壳。

## 备选计策

1. **「睡袋替代襁褓」**——适合刚能翻身的宝宝：用睡袋（可含手臂或过渡型）替代襁褓，既保暖又保留部分包裹感，避免翻身被困。
2. **白天「专项练习时段」**——适合动作卡壳明显的宝宝：每天固定几段「练习时间」，用玩具引导反复练那半个动作，加速自动化。
3. **夜视监护观察**——适合焦虑型父母：用夜视仪确认翻身卡壳时宝宝是在「求助」而非危险（脸朝下闷住才需立即处理），减少不必要的整夜进房。
4. **翻身期多次协助的临时妥协**——适合卡壳严重的小月龄：短期接受「一夜帮几次」，但把它当临时过渡（作者容忍「倒退期用救急办法」），白天猛练、通常几天就好。

## 决策规则

**怎么算有效**：
- 卡壳次数逐晚减少、白天动作更熟练
- 夜里「站起游戏」你示范后不放倒、宝宝自己坐回/躺回的频次增加
- 睡眠随技能熟练逐步回稳（几天到一两周）

**坚持多久再评估**：以「天到周」计；白天加练通常几天见效。

**出现什么信号换方向/就医**：
- 睡眠乱与动作无关、或持续数周 → 另找原因（倒退/分离焦虑/联结）
- 卡壳伴随呼吸危险（脸闷住） → 立即处理/就医
- 白天运动能力**倒退**或**明显左右不对称** → 就医评估

## 反模式

1. **每次站起来就进去把他放倒**——把「站起」强化成「爸妈来陪玩」的游戏，固化新习惯。
2. **只夜里应付、白天不练**——不把动作练熟，卡壳会一直拖。
3. **帮倒忙地「代劳」**——直接把他放倒，混淆了「被放倒」和「自己会坐/躺」，训练无效。
4. **翻身了还用襁褓**——安全红线，见红线节。
5. **把里程碑期睡眠乱当作息/喂养问题反复折腾**——方向错了，白折腾还错过白天加练的窗口。
6. **在新技能正乱时硬推睡眠训练**——效果差，建议错开。

## 边界

- **翻身安全线**：**能自主翻身 = 立即停襁褓**（不因人而异）。入睡仰卧放下，但允许他自选的睡姿维持。
- **月龄**：主要 4-12 个月；更小的翻身/惊跳另见 slp-dubief-power-tools。
- **与分离焦虑的区分**：若醒来是「找人」式的黏人哭（而非在做动作卡壳），偏分离焦虑，见 slp-dubief-separation-anxiety。
- **与发育倒退/倒退节点的区分**：若睡眠乱无动作关联，见 slp-dubief-sleep-regression。
- **早产儿**按矫正月龄看里程碑。

## 就医红线

以下先就医：

- **睡眠中呼吸暂停、面色青紫/苍白** → 急诊
- **小月龄翻身成俯卧又无法转回、有窒息风险** → 立即处理；若反复且月龄小，就诊评估
- **白天运动能力倒退**（原本会的动作变差）或**明显左右不对称** → 就诊评估神经/肌肉
- **持续哭闹伴抓耳、发热** → 就诊排查中耳炎等
- **体重不增、进食变差伴睡眠崩坏** → 就诊
- **任何月龄发热 ≥38℃（3 月龄内）** → 立即就医

## 代价与风险提示

- **白天加练的时间成本**：需要看护人陪练、准备安全软垫环境。
- **夜里「不奉陪」的哭闹耐受**：改掉「站起游戏」的头几晚会有抗议，需要狠下心。
- **训练被拖慢**：里程碑期常需暂停/调整睡眠训练，进度延后。
- **短期协助成本**：翻身卡壳期可能一夜多次进房，大人睡眠受影响（当临时过渡处理）。
- **安全变量**：翻身期必须重新校准襁褓/床内布置的安全。
