# 摇椅里摇睡的宝宝要转crib，别直接搬——先让他「醒着进摇椅」自己睡着，再逐档降速到静止、把摇椅挪到crib边，最后才换床

## 解决的问题

宝宝是「运动迷」——只有摇椅（或秋千、吊床）摇着，他才肯睡、才睡得着。可你慢慢发现：椅一停就醒，有时整夜得开着；他人越来越大，快装不下了；你也担心上班后托育不会给他摇。你想把他挪到 crib，可又不敢——怕直接抱过去就全崩，一夜回到解放前。

Precious Little Sleep 第 11 章专门有一节讲「怎么、何时把宝宝从摇椅里请出来」。作者的思路不是「某天突然宣布改朝换代」，而是**用一条阶梯，一级一级把「摇动」和「睡前自己睡着」这两件事拆开**。

## 核心判断

从摇椅转 crib **不能一步到位**，要走一条六级的阶梯：**先让宝宝在「醒着」状态下被放进摇椅、自己摇着睡着（不能跳过）；再逐档降低摇速直到完全不摇；再让他睡在静止的摇椅里；把摇椅挪到 crib 旁边（同一位置感）；最后才放进 crib**。每一档如果顺利就继续降；如果不顺，就**退回上一档、等一周再试**——上周不行的，下周常常就成了。

## 机制

**为什么要一条阶一阶来，而不是直接换床？** 摇椅同时供给两样东西：**运动**（安抚）和**地点/姿势**线索。直接把宝宝从「摇动+摇椅」的环境扔进「静止+crib」，等于一次撤掉两个强线索，反弹自然大。阶梯的作用是把它们**分开撤**：先用「醒着进摇椅自己睡着」证明他能自主入睡（撤掉「靠摇晃入睡」这一步），再逐档把运动量归零，再单独处理地点，最后合并到 crib。

**为什么「退回一周再试」是关键**：作者的经验是，孩子的适应能力是动态的——**同一件事，上周做不到，下周可能就是巨大成功**。所以阶梯里每一档都内置了「失败 → 等一周 → 重试」的循环，而不是「失败就放弃」。

## 诊断信号

**月龄判断**：大多数宝宝只需要摇椅很短一段时间，到 **3-4 个月**就大多能转回 crib 睡。**何时递减失效**：如果宝宝**已经会在摇椅里翻身**，就不能再「慢慢等」——见「边界」与「就医红线」，安全优先。

自查：
1. 只有摇动时才睡、停了就醒，甚至整夜开着
2. 已接近/超过 3-4 个月、体型快装不下
3. 上班后托育不给摇（结构性问题，需要尽快过渡）
4. 你在摇摆椅上感到「被绑住」，一动都不敢动
5. 孩子会翻身却还在摇椅里睡（安全红灯）

## 正常范围与个体差异

- **大多数宝宝到 3-4 个月能回 crib 睡**：作者说，多数宝宝只需要摇椅很短时间。
- **怎么判断他「准备好了」**：没有「翻译器」，只能**测**——照阶梯走；**顺利，说明他本来就行了；不顺，就等一周再来**。
- **个体差异**：运动依赖越深、月龄越大，降速的每一档越容易卡；有的宝宝几乎无痛过渡，有的每一档都要反复。
- **安全红线不随个体差异变化**：会翻身后仍长期在摇椅里睡，风险不因「他很依赖」而降低。

## 实操方法

照作者的六级阶梯（**顺序不能跳**）：

1. **把宝宝「醒着」放进摇椅**。成功戒摇摆的第一步，是让他在**清醒**状态下进摇椅、然后在摇椅里自己睡着——**最好你没被他看见**。**这一步不能跳。**
2. **给足睡眠线索**。理想的画面是：他在摇椅里睡时已经带着其他线索——固定的就寝时间、好的睡前程序、白噪音，可能还有襁褓。
3. **逐档降速**。把摇椅速度**降一档**。如果他照睡得好，继续降，直到**完全不摇**。若他在更低档睡不好，就**把速度加回去，等一周再试**（上周不行的，下周常常就成）。
4. **让他睡在「不动的摇椅」里**。目标是他在**静止的摇椅**里睡着。
5. **把摇椅挪到 crib 旁边**。让他先熟悉「和 crib 同一个位置」。
6. **放进 crib**。作者无法保证无泪，但通常只是些「换了景」的小抱怨（**第一晚大约 20 分钟**）。

**贯穿全程的两条**：
- **每一档顺利就前进，不顺就退回上一档、等一周重来**。
- **先「醒着睡着」这关过了，后面的降速和换地点才有基础**。

## 备选计策

1. **先降速、后换地点**——适合运动依赖极深的家庭：把「运动量」和「地点」彻底分开处理，减小一次性变化。
2. **摇椅贴 crib 过渡**——适合位置敏感型：第 5 步多做几天，让孩子把「摇椅位置」和「crib 位置」认成同一个地方。
3. **白噪音 + 襁褓补线索**——适合线索单薄的家庭：做减法的同时，用其他强线索补位（见 slp-dubief-power-tools）。
4. **安全前提下的「限定使用」**——只适合**仍能被安全固定、无法翻身**的情形：若孩子会翻身，禁用此计，改走安全方案（见红线）。

## 决策规则

**怎么算有效**：
- 能接受更低的摇速、甚至不摇也能睡
- 能在静止的摇椅里睡着
- 顺利从摇椅挪到 crib（第一晚抱怨约 20 分钟，之后递减）
- 不再必须整夜开着摇椅

**坚持多久再评估**：**每一档观察约一周**；不顺就退回上一档，下周重试。

**出现什么信号换法/停**：
- 某一档连续一周都失败 → 退回上一档稳住，或先在那档多停几天
- 孩子已会在摇椅里翻身 → **立即停用摇椅睡觉**，走安全方案
- 换 crib 后出现大量惊醒/倒退 → 退回「静止摇椅贴床」几天再进

## 反模式

1. **直接从摇椅抱进 crib**——一次撤两个线索，反弹最大。
2. **跳过「醒着进摇椅」**——没这步，后面降速只是「换个地方继续摇」，根基不稳。
3. **某一档失败就放弃整条阶梯**——应该「退回上一档、等一周重试」。
4. **会翻身后仍靠摇椅维持睡眠**——安全性压倒一切，不能拿安全换进度。
5. **降速时一步到位**——一档一档降，别跳级。
6. **忽略其他线索**——只拆摇椅而不补白噪音/程序/襁褓，孩子无处依托。

## 边界

- **月龄**：多数 3-4 个月可转 crib；阶梯适用于更早或更晚仍依赖摇椅的宝宝。
- **会翻身 = 安全红线**：一旦宝宝能在摇椅/秋千里翻身，就不应再在摇椅里睡觉（AAP：在摇椅、车座、推车里睡着，应尽快移到平坦仰卧的睡眠表面）。
- **早产儿**按矫正月龄。
- **托育约束**：若托育不给摇，过渡要提前、按阶梯走，别等上班前一天才动手。
- **不能保证无泪**：作者明说换 crib 可能有抱怨（第一晚约 20 分钟），属正常。

## 就医红线

- **宝宝在摇椅/秋千中下颌贴胸、头后仰、呈塌陷姿势，或面色异常/呼吸不畅** → 立即停止摇椅睡眠并就医
- **宝宝已会在摇椅中翻身** → 立即停用（安全风险），并重新审视睡眠表面是否平坦安全
- **睡眠中打鼾憋醒、呼吸暂停** → 就诊评估（见 slp-dubief-sleep-apnea）
- **斜睡/软面导致头型明显偏斜** → 就诊，并保证清醒时俯趴时间
- **3 月龄内发热 ≥38℃、精神差** → 就医

## 代价与风险提示

- **慢**：逐档降速、每档等一周，可能拖几周。
- **哭声**：「醒着进摇椅」和「换 crib」两关最可能引出哭。
- **反复**：每一环都可能退步重来，考验耐心。
- **安全账不可省**：会翻身后，速度与安全冲突时，永远安全优先。
