# 3 个月宝宝"应该会"俯卧抬头 45°——"双腿支撑、拉坐头不后仰"只是发育程度，别当训练项做

## 解决的问题

宝宝满 3 个月了。你在月龄表上看到"拉坐时头部不后仰""双腿支撑一点重量"，心想这是不是新的训练目标，赶紧抓着宝宝练拉坐、扶着站。其实你可能误解了这张表：有些项目**只是医生观测到的发育程度，不是让你拿来训练的**。

原书把 3 个月的能力分四档，其中两档明确标注"仅代表发育程度，不建议做此训练"。

## 核心判断

**3 个月时，宝宝"应该会"：俯卧时抬头 45°。"很可能会"：将两只手握在一起。"也许会"：竖抱时保持头部稳定；俯卧抬头 90°；发出尖叫声；笑出声；抓住引逗他的玩具（如拨浪鼓）；视线随人或物追至 180° 的范围。"甚至会"：双腿支撑一点重量（此动作仅代表发育程度，不建议做此训练）；拉坐时头部不后仰（同样仅代表发育程度，不建议训练）；俯卧抬胸；拒绝别人把玩具拿走。** 关键提醒：**"双腿支撑""拉坐头不后仰"是发育程度的反映，不是给家长照着练的动作。**

## 机制

**四档概率与"仅代表发育程度"的含义**：同 2 个月，"应该会/很可能会/也许会/甚至会"对应约 90%/75~90%/50~75%/25~50% 的宝宝能做到（四档百分比含义见 cui-bk-milestone-interpretation，该书 p44）。3 个月表里，**"双腿支撑一点重量""拉坐时头部不后仰"这类被标为"仅代表发育程度、不建议做此训练"**——它们是体检时医生观测神经运动发育的指标，不是家长日常该反复做的训练动作（原因见 cui-bk-motor-no-rush）。

**3 个月能观察到什么**：
- 大运动：抬头高度上到 45°（"应该会"）乃至 90°、俯卧抬胸（"也许会/甚至会"）。
- 精细与抓握：两手相握（"很可能会"）、抓拨浪鼓（"也许会"）、拒绝别人把玩具拿走（"甚至会"）。
- 社交与视觉：竖抱头部稳定、尖叫声、笑出声、追视 180°（"也许会"）。

## 诊断信号

**月龄判断**：本条针对满 3 个月的足月健康宝宝（infant-3-4-months）。**递减/失效**：4 个月后技能表升级；早产儿需按矫正月龄评估。若"应该会"的俯卧抬头 45° 到下一个月龄仍完全做不到，按红线处理（并与 cui-bk-no-head-lift 配合排查）。

用本条：不清楚 3 个月该会什么、想按表练动作。**不适用**：某单项晚几天——按概率理解。

## 正常范围与个体差异

- "应该会"（约 90%）：俯卧时抬头 45°
- "很可能会"（75%~90%）：将两只手握在一起
- "也许会"（50%~75%）：竖抱头部稳定；俯卧抬头 90°；尖叫声；笑出声；抓拨浪鼓；追视 180°
- "甚至会"（25%~50%）：双腿支撑一点重量（仅代表发育程度、不建议训练）；拉坐头不后仰（仅代表发育程度、不建议训练）；俯卧抬胸；拒绝别人把玩具拿走
- 适用对象：足月健康宝宝；早产儿用矫正月龄
- 个体差异：同一技能出现时间有早有晚

## 实操方法

1. **逐项对照四档**：先看"应该会"的俯卧抬头 45° 是否具备。
2. **趴着练抬头**：清醒时多俯卧（抬头靠趴练，不靠拉坐/扶站）。
3. **提供抓握与追视机会**：给轻巧玩具，逗宝宝抓、看。
4. **不练"双腿支撑/拉坐"**：这两项是发育程度指标，不当作训练项。
5. **长期记录对照**：按月记下各项技能出现时间。
6. **早产儿换算矫正月龄**：按预产期折算再对照。
7. **整体看，不揪单项**：某项晚几天不等于迟缓。

## 备选计策

- **"四档概率"法**：按 90/75~90/50~75/25~50 理解——适用所有家长
- **"只练趴、不练拉坐站"法**：以俯卧为核心练习——适用想促进大运动又不超前
- **"矫正月龄"法**：早产儿按预产期折算——适用早产儿家庭

## 决策规则

- **怎么算"正常"**：多数技能按概率节点出现、整体符合月龄 → 正常
- **坚持多久再评估**：以月为单位持续对照
- **出现什么信号换法**：俯卧抬头 45° 到下一个月龄仍完全做不到 → 请医生评估（见 cui-bk-no-head-lift）
- **何时需就医**：见红线

## 反模式

- **把"甚至会"当训练目标**：如抓着宝宝练拉坐、扶站支撑——不恰当
- **把"应该会"当及格线**：约 10% 稍晚属正常
- **拿自家宝宝和别人家比**：徒增焦虑
- **早产儿用足月表对照**：应折算矫正月龄
- **明显缺失却"再等等"**：应尽早就医评估

## 边界

- 本条用于 3 个月技能的参考对照，不替代医生对具体宝宝的发育评估
- 早产儿、高危儿遵医嘱随访，用矫正月龄
- "双腿支撑/拉坐头不后仰"仅作体检观测指标，不做日常训练
- 具体里程碑内容以 CDC/卫健委标准为准

## 就医红线

- **3 个月仍完全不能俯卧抬头、头颈完全无力**——就医评估
- **双眼不追视、对逗引无反应**——就医
- **不会发出哭声以外的任何声音**——就医
- **肢体松软或僵硬异常**——就医
- **技能倒退（原有能力丧失）**——立即就医

## 代价与风险提示

- 要理解"甚至会"里部分仅代表发育程度，需知识避免误练
- 长期逐项记录需耐心
- 不超前训练需顶住"早练早好"的压力
- 真落后需及时与医生沟通
