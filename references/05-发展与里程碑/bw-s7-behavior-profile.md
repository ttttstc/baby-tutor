# 第七阶段的行为构成数据

## 解决的问题

"多陪孩子"——听到这句话，你是不是有点心虚：孩子一整天到底在干什么？他常常自己玩、偶尔发呆，是不是陪伴不够？是不是该像传说中那样"整天陪着他"？怀特用家庭观察数据回答了"2~3 岁孩子一天都花在哪"。

## 核心判断

**从 1 岁生日开始，"与人相关的行为就开始增加，而与人无关的行为则随之减少"。快到 1 岁生日时，全部行为中约 10% 与人相关；2 岁左右变成 **20% 社会行为 / 80% 非社会行为**；到 3 岁，社会行为比例**接近 30%**。主要非社会行为与第六阶段相似（探索物体特性、练简单技能），但重要性相对下降——18~21 个月约 **18%** 的清醒时间用于对小物体的这两种行为，到 2 岁半降到 **14%**。"凝视"行为在第 3 年**大大减少**（1 岁近 17% → 2 岁 14% → 3 岁 6~7%），但"在听人说话时的凝视"反而**增加**（1 岁 6% 多 → 2 岁半 11%）。非任务行为（发呆）随婴儿期结束而**减少**（第 2 年 10~12% → 第 3 年 7~8%）。社会体验方面：**最常见的是"试图保持别人的注意"（约 90% 是对妈妈）**，2 岁左右占清醒时间约 6%、2 岁半约 4%；其次是"遵从父母简单要求"约 3%、"获得别人注意"约 2.5~3%、"获得成人帮助"约 2%、"拒绝提议"约 1~1.5%——而这五种社会体验**总共花的时间仍少于孩子探索小物体和练习运动技能的时间**。所以，**"一个 3 岁孩子的生活并不像有些人所说的那样是从早到晚坐在妈妈身旁的"。**

## 机制

**为什么"社会行为只占少数"**：怀特给出的数字很关键——2 岁 20%、3 岁近 30% 是社会行为，其余大部分时间孩子"对客观世界进行探索并练习运动技能"（p233、p237）。他强调："在头 3 年当中，在孩子醒着的大部分时间里，他会对客观世界进行探索并练习运动技能。从全职父母的角度来看，宝宝与他们亲密接触的时间要多得多，但在心理时间和实际时间之间存在着很大的差距。"（p237）也就是说，**"感觉上一直在陪"和"数据上其实多数时间在自主探索"是两回事。**

**为什么"凝视减少、听人说话凝视增加"**：怀特观察到第 3 年凝视行为"大大减少"，而与之相关的"在听人说话时的凝视行为"有所**增加**——"由于第七阶段是语言能力有极大发展的时期，因此这个阶段的孩子对语言所表现出来的极大兴趣也就不足为奇了"（p233-234）。即：**注意力从"盯着看世界"转向"听着学语言"**。

**为什么"非任务行为减少"**：怀特说"空闲时间或非任务行为通常会在第 3 年有所减少"，从第 2 年的 10~12% 下降到 7~8%；"与之类似的'消磨时间'状态在这一时期也会减少"。他认为这"反映出一个事实，即在婴儿期结束后，孩子发生意外的可能性有所减少，因此他们的活动范围不再经常受到限制，父母也不再对他们进行严密的看护"（p234）。即：**活动自由了、有事可做了，发呆自然减少。**

**为什么"保持他人注意"是最常见社会体验**：怀特说第七阶段孩子"最常见的社会体验是他试图保持其他人的注意——保持社会接触"，而这个"人"在通常情况下（大约 90% 的时间）"就是孩子的妈妈"；2 岁约占清醒时间 6%、2 岁半降到 4%（p234）。这与"孩子越长大越不黏人"的趋势一致——**保持社会接触的时间随年龄下降。**

**为什么"五种社会体验加起来还不及探索"**：怀特明确指出，"上述五种社会体验总共占据的时间少于孩子对小物品进行探索和练习运动技能所花的时间"（p237）。他还说，占日间时间的非社会行为种类相对较少——"以上所讨论的七种行为总共占据 3 岁儿童 53% 左右的时间。在 2 岁半的时候，这七种行为占据 47% 左右的时间"，这种差异"反映出随着时间一个月一个月地过去，孩子的行为变得越来越复杂，他们的行为种类也越来越丰富"（p234）。

## 诊断信号

**月龄判断**：本条管 **24~36 个月**（第七阶段）。

用本条：孩子很大一部分时间在自己探索/玩；你担心"陪得不够/他黏我太多"；孩子偶尔发呆；你想知道 2~3 岁的"正常行为构成"；你听说"孩子该整天围着妈妈"。

## 正常范围与个体差异

怀特书内数据：

- **社会行为占比**：1 岁约 `10%` → 2 岁 `20%` → 3 岁近 `30%`（p233）。
- **小物体探索/掌握**：18~21 个月约 `18%` → 2 岁半 `14%`（p233）。
- **凝视**：1 岁近 `17%` → 2 岁 `14%` → 3 岁 `6~7%`；听人说话凝视 `6%+`→`11%`（p233-234）。
- **非任务行为**：第 2 年 `10~12%` → 第 3 年 `7~8%`（p234）。
- **社会体验**：保持他人注意（约 `90%` 对妈妈）2 岁 `6%`/2 岁半 `4%`；遵从简单要求约 `3%`；获得注意约 `2.5~3%`；求帮助约 `2%`；拒绝提议约 `1~1.5%`（p234、p237）。
- **合计**：七种行为占 3 岁约 `53%`、2 岁半约 `47%`（p234）。

个体差异：行为构成有个体差异；早产儿按矫正月龄。

## 实操方法

1. **别被"整天陪"的说法绑架**：孩子大部分时间在自主探索/练技能（p237）。
2. **保证"有质量的互动"**：与他谈当下、回应请求（见 bw-s6-language-input）。
3. **给充分自由探索**：小物体、运动技能是他的主课（p233）。
4. **随年龄安排同龄机会**：社会行为占比在上升（p233，见 bw-s7-learning-goals）。
5. **区分"发呆"**：短暂非任务行为属正常，随自由活动而减少（p234）。

## 备选计策

- **"陪得不够"焦虑的家长**：看数据——多数时间他在自主探索，不必"全程陪"（p237）。
- **"孩子太黏"的家长**：保持社会接触随年龄下降，属正常趋势（p234）。
- **"整天围着妈妈转"的期待**：不符实际，放宽心（p237）。

## 决策规则

- **怎么算"在轨"**：有充分探索/运动、有互动与同龄机会、发呆在合理区间——即在轨。
- **坚持多久**：整个第 3 年。
- **出现什么信号换思路/求助**：非任务行为长期偏高、3 岁仍几乎无同龄兴趣、长时间发呆/无探索——发育评估。

## 反模式

- **以为"孩子该整天围着妈妈"**：数据不支持（p237）。
- **因"他在自己玩"而愧疚**：自主探索是他最重要的事（p233）。
- **忽视"同龄兴趣上升"的趋势**：3 岁社会行为占比在增加（p233）。
- **把持续发呆当正常**：需评估（见 bw-s6-nonsocial-behavior）。

## 边界

- 本条为怀特的观察与方法论，非机构指南；占比来自其家庭观察样本。
- 行为占比个体/情境差异大，不宜机械套用。
- 早产儿按矫正月龄。
- 本条不含发育障碍的诊断。

## 就医红线

（2026-10-04 校准）

- **非任务行为长期明显偏高、持续发呆**——发育评估
- 3 岁仍几乎无同龄兴趣、完全回避其他孩子——发育评估
- 长时间无探索、对周围无兴趣——发育评估
- 任何月龄能力倒退——尽快就医

## 代价与风险提示

- 理解"孩子大部分时间在自主探索"能减轻陪伴焦虑。
- 但要保证有质量的互动与同龄机会。
- 非任务行为偏高/无探索时需评估。
