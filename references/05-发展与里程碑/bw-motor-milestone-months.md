# 从竖头到走路的运动时间表——头8个月"七坐八爬"只是大致规律

## 解决的问题

游乐场上最常见的社交事故：对方妈妈随口一句"他家六个月就满地爬了"。你家快八个月，还坐得挺稳就是不肯动。回家路上你已经搜起了"学步车辅助走路"和"婴儿体操课"。

怀特给出的答案，是把"正常范围"放宽到让你松手，同时把"练"的收益说清楚——**大运动的时间表主要由成熟决定，个体差异以周乃至月计；大人被证明有用的是"安排环境"和"陪玩"，不是架着胳膊练**。

## 核心判断

**从竖头到走路是一条固定顺序的能力链，但每个环节的时间窗都很宽：白己的观察里，4 个月头能控制、5 个半月前学会仰卧到俯卧的翻身、6 个月开始练坐、7 个月坐稳、7.5~8 个月开始爬行、8 个月左右能主动移动、9~10 个月能自己站起来。个别更早（不满 6 个月会爬、不满 8 个月会走）或更晚（7.5~8 个月还不会移动）都属正常，先停止攀比。要警惕的不是"慢"，是"单项触窗上沿且其他项也落后"或"倒退"。**

## 机制

**顺序为什么固定**：大运动按竖头→翻身→坐→爬→站→走的次序出现，因为脑区从下往上、身体从中心往外、运动皮层从头到脚依次成熟，宝宝同时受"肌肉力量渐长"和"视觉-平衡-动机"协同的驱动（p87-88、p91）。（作者基于发展研究的描述，非 RCT。）

**为什么快慢差这么多**：怀特反复说明，技能获得的早晚"并没有太大意义"；宝宝比别的宝宝早一两个月会伸手够物也"没有什么非常值得高兴的"。他把"移动能力"视为跨越第五阶段的门槛，并明确其时间弹性——"通常在 8 个月左右出现，尽管有的宝宝可能早几个星期，甚至晚几个月"。

**为什么"练"加速不了**：怀特没有像双胞胎实验那样给数据，但他给出一致的立场——驱动控制的获得是"无需干预的"；宝宝自己会反复练习新技能直到熟练，大人要做的是提供机会而非代劳。他提醒某些书和节目声称能帮助发展，"在我看来这种帮助是没有必要的，这些能力的发展是必然的"。

**为什么"憋太久"也值得注意**：怀特指出，若宝宝 7.5~8 个月仍不移动，你会发现"和他一起生活是一件更加使人疲惫的事情"，且对这种较晚学会爬行的宝宝，"要防止他的过度依赖和过度需求的性格相对较难"——意思是晚没关系，但要注意用主动陪玩、提供刺激来对冲，而不是干等。

## 诊断信号

**月龄判断**：本条管 0~15 个月的大运动链。0~2 个月竖头；2~4 个月俯卧抬头抬胸；4~6 个月翻身；6~8 个月坐；7~9 个月爬；8~10 个月主动移动；9~10 个月自己站。15 月龄还没走稳仍可能正常。

用本条：宝宝单个里程碑落后 1~2 个月你在犹豫要不要加练；家里在架走扶坐；你在考虑学步车/体操课。

## 正常范围与个体差异

怀特书内贯穿 0~8 个月的运动观察：

| 能力 | 白己书内时间点 |
|---|---|
| 新生儿抓握力 | 约 0.9 千克 |
| 俯卧抬头 45° | 6~8 周 |
| 俯卧抬头 90°（垂直） | 14 周 |
| 头能旋转 180° | 14 周 |
| 仰卧→俯卧翻身 | 5 个半月之前学会（第 4/5 个月开始练） |
| 两腿踢、脚抵压时用力蹬 | 第三阶段 |
| 脖子背部够力（可用弹跳椅） | 约 4 个半月 |
| 开始练坐 | 6 个月 |
| 坐得较稳 | 7 个月 |
| 开始爬行 | 7.5~8 个月 |
| 能站起（坐姿到站） | 8 个月左右 |
| 自己站起来 | 9~10 个月 |
| 主动移动（爬/挪/滚） | 8 个月左右（±数周~数月） |

关键宽口径：**不满 6 个月会爬、不满 8 个月会走"并不常见"但存在；7.5~8 个月不移动也正常**。第 9 章的运动能力表（表 A-1）与"头部控制 4 个月"与上表一致。

## 实操方法

1. **把上面的表贴在家里，焦虑时对照的是"正常窗口"不是同龄人**。
2. **提供自由活动的地面**：铺地垫、把家做成"可以随便翻爬"的地方，让宝宝在清醒时段自主练习。
3. **在"边缘技能"上给一点点挑战**：看到他正努力翻身/够物/扶站时，把玩具放到"再使点劲就能够到"的位置，你自己出兴致，让他出力。
4. **想给腿部刺激就用弹跳椅**：4 个半月起脖子背部够力后可用，赤脚、脚踩硬面、双脚着地（见 bw-jumper-walker-use）。
5. **不架走、不扶坐、不拉着"遛"**：这些"练"没有证据支持，还可能干扰宝宝自己的平衡学习。
6. **反复练新技能时别打断**：那是发育本身，提供机会即可。
7. **7.5~8 个月仍不移动时**：不必催练，但要加强主动陪玩和刺激，对冲可能出现的高依赖需求。

## 备选计策

- **坚持"七坐八爬"的老人**：用怀特"正常范围很宽（8 个月还不动也正常）"的原话回应，把力气换成为宝宝布置活动空间。
- **已经买了学步车的家庭**：见 bw-jumper-walker-use——学步车不是完全不能用，但要限时、要在看护下用，且会爬后停用。
- **体操/早教课诱惑**：怀特说这类课程能带来乐趣、也让新手父母拓宽观念，但"如果声称有教育意义，不要轻信"。

## 决策规则

- **怎么算"正常推进"**：不用日历验收单项，看趋势——过去 6~8 周里是否在往链条下一环使劲。
- **坚持多久再评估**：单项落后先给 6~8 周观察窗，同时保住自由活动时间。
- **出现什么信号换思路/就医**：单项触窗上沿无趋势、多项同时落后、动作倒退、双侧明显不对称——直接儿保评估。

## 反模式

- **拿同龄人当考卷**：宽窗之下，"隔壁六个月会爬"对你家孩子没有预测力。
- **架走扶坐"遛"**：基础大运动训练被证明加速不了，还可能磨掉兴趣。
- **为"练走路"买学步车当主要手段**：见 bw-jumper-walker-use，学步车的定位是"减少无聊的道具"而非"学步训练器"。
- **看到宝宝费力就去扶一把**：挣扎本身是训练，你要做的是确保环境安全、递上兴致。
- **把"晚"归因为带得不好**：白己说这些能力"必然"发展，环境只影响快慢的小幅空间。

## 边界

- 本条为白己书内观察/方法论，非机构指南；月龄为大致落点，个体差异可达数周乃至数月。
- 早产儿按矫正月龄。
- "正常范围宽"止焦虑，不是拖延就医的借口——红线数字优先。
- 青少年及病理性的运动问题（脑瘫等康复训练）属专科，本条不涉及。

## 就医红线

（2026-10-04 依 CDC/AAP 口径校准）

- **6 月龄竖头仍不稳**——儿保评估
- **8 月龄不能独坐**——评估
- **12 月龄既不爬也不扶站、多项同时落后**——评估
- 任何月龄运动能力倒退——尽快就医
- 双侧动作明显不对称、肌张力异常（过僵或过软）——尽快评估

## 代价与风险提示

- 放弃"加练"要扛住 2~4 个月的亲戚评论和比较焦虑，把表贴冰箱是对冲。
- 拆掉"架走"意味着看护方式要重排，自由活动空间需要一次性投入。
- "憋太久"的家庭（7.5~8 个月不移动）要额外投入主动陪玩，对冲高依赖需求。
- 本条不含任何付费课程的必要性——怀特本人对"教育意义"的课程持保留态度。
