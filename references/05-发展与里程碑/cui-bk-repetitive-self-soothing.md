# 宝宝撞头、摇头、揪自己头发多是正常——自我安抚/节奏感/出牙期致，护好磕碰处别强行纠正

## 解决的问题

宝宝最近行为越来越"怪"：一会儿用头撞婴儿床的栏杆，一会儿摇头晃脑，吃奶的时候还伸手揪自己的头发，揪得挺用力的样子。你越看越担心：是不是缺钙？是不是神经系统有问题？要不要赶紧纠正、制止？

原书把这些归到"怪异小动作"里，先给结论：**一般情况下，这些动作都是正常的。**

## 核心判断

**这个月龄段出现的撞头、摇头、拉扯头发等，大多是正常行为：撞头摇头可能与节奏感增强、体会被轻摇的感觉、出牙期转移疼痛、睡觉时缓解疲惫、或怕黑/学走路/看护人变化等压力有关，可能持续几周几个月甚至一年以上，大多 3 岁左右自行改掉，无须干预；拉扯头发多发生在吃奶时，是自我安抚、获取安全感的方式，一般随成长自行消失。对发育正常的宝宝，这些行为与其精神和身体没有关系——只要日常精神好、饮食睡眠生长曲线正常，家长完全不必担心，也无须过度关注或强行纠正，否则很容易适得其反。但要在易磕碰处包软垫保护安全。**

## 机制

**撞头、摇头为什么会发生**（p288）：书里列了几类可能——宝宝**节奏感增强**，听到音乐就会随之摇晃身体；也有宝宝通过摇晃身体或摇头，**体会一种被父母轻摇的感觉**；如果正处在**出牙期**，可能用撞头**转移出牙的疼痛感**；此外有的宝宝会在**睡觉时**撞头、摇头，以**缓解白天积累的疲惫感**；对于正在承受**怕黑、学走路、看护人变化等生活压力**的宝宝，也会出现持续的撞头或摇头。

**为什么说它"正常"**（p288）：对发育正常的宝宝而言，这些行为与其精神和身体没有关系。如果宝宝**日常精神状态良好，饮食、睡眠、生长曲线等均正常，家长完全不必担心**，无须过度关注或强行纠正——**否则很容易适得其反**。

**为什么拉扯头发也是自我安抚**（p288）：宝宝卷、拉自己的头发**多发生在吃奶时**，这给正在吸吮的宝宝带来足够多的安抚、获取安全感。事实上，小宝宝会通过各种奇怪的举动进行自我安慰，拉扯头发就是其中之一。虽然有些自我安慰行为在妈妈看来未免过激，但**通常都是无害的**，一般**随成长自行消失**，不需要过多干涉。

**安全与就医的分界**（p288）：即便这些动作不需要太多干预，家长仍应注意保护安全——比如在**婴儿床、墙面等容易磕碰的地方包上柔软的垫子**，避免宝宝用力过大对头部造成损伤。另外，**如果宝宝在摇头、撞头的同时出现其他异常行为，并且伴随发育迟缓等问题，家长则需及时带宝宝就医检查。**

## 诊断信号

**月龄判断**：本条覆盖出现这类重复性动作的婴幼儿期（约 infant-6-9-months 到 child-2-3-years）。**不适用**：同时出现其他异常行为且伴发育迟缓——按红线就医。

用本条：宝宝反复撞头/摇头、吃奶揪头发、家长担心缺钙或神经系统问题。**不适用**：伴其他异常行为或发育迟缓——见红线。

## 正常范围与个体差异

- 出现时间：这个月龄段突然出现，属常见
- 可能诱因：节奏感、被轻摇的感受、出牙期、睡前疲惫、生活压力
- 持续时长：几周或几个月，甚至一年或更长
- 转归：大多 3 岁左右自行改掉
- 拉扯头发：多在吃奶时，属自我安抚，随成长消失
- 判断：精神好、饮食睡眠生长曲线正常 → 不必担心
- 红线：伴其他异常行为且发育迟缓；自伤致头部损伤

## 实操方法

1. **先看整体**：只要精神好、吃睡和生长曲线正常，就不必担心。
2. **不强行纠正**：过度关注或强行制止容易适得其反。
3. **不贴"病"的标签**：这些动作与其精神身体没有关系，别急着归因缺钙等。
4. **做好安全防护**：婴儿床、墙面等易磕碰处包软垫，防头部损伤。
5. **应对揪头发**：揪得严重可暂时把头发剪短；喂奶时握住小手；或给一个毛绒玩具供他拉扯。
6. **疏导情绪、给安全感**：多观察、及时疏导不良情绪、有效陪伴。
7. **盯住异常**：若同时出现其他异常行为并伴发育迟缓 → 就医。

## 备选计策

- **"安全防护"法**：包软垫防磕碰——适用所有出现此类动作的宝宝
- **"替代物"法**：给毛绒玩具转移拉扯——适用"揪头发严重"的宝宝
- **"观察+陪伴"法**：多疏导情绪、多陪伴——适用"动作伴情绪压力"的宝宝

## 决策规则

- **怎么算"正常"**：精神、吃睡、生长曲线正常，仅见这类重复动作 → 正常，观察
- **坚持多久再评估**：随月龄观察，多可随成长自行消失（大多 3 岁左右）
- **出现什么信号换法/就医**：同时出现其他异常行为、伴发育迟缓或自伤致伤 → 就医
- **何时必须就医**：见红线

## 反模式

- **把撞头摇头直接当缺钙/癫痫**：发育正常时与精神身体无关
- **强行制止、过度关注**：容易适得其反
- **不包软垫**：用力过大可能造成头部损伤
- **揪头发就用打骂制止**：无必要，应先疏导与替代
- **忽略"伴其他异常"的信号**：若有异常行为+发育迟缓要就医

## 边界

- 本条用于解读这类重复动作，不替代对神经系统/发育问题的医学评估
- 有神经系统疾病、发育迟缓、自伤行为的宝宝遵专科医嘱
- 若与睡眠、情绪问题交织，可结合相应条目

## 就医红线

- **撞头/摇头同时出现其他异常行为且伴发育迟缓**——及时就医检查
- **重复动作导致头部或身体损伤**——就医
- **伴随精神反应明显异常、抽搐**——立即就医
- 伴发热、精神差——及时就诊（卫健委《3岁以下婴幼儿健康养育照护指南（2022）》危重症识别，2026-10-04 核对）

## 代价与风险提示

- 要忍住不强行纠正，接受"可能持续几个月甚至更久"
- 要在婴儿床、墙面等易磕碰处做防护，增加准备
- 要留心观察是否伴其他异常，家长需持续上心
- 不干预到"自行消失"，需要长期耐心与情绪稳定
