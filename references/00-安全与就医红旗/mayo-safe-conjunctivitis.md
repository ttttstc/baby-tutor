# 宝宝眼睛红、黄绿眼屎把眼皮糊住，多半是感染性结膜炎——先分清细菌/病毒/过敏，别乱滴眼药水，抗生素要按疗程滴完

## 解决的问题

早上宝宝一睁眼你就发现不对：一只眼睛红红的，眼角糊着一层黄绿色的分泌物，眼皮被粘在一起，得用湿毛巾一点点擦开才能睁开眼。孩子怕光，动不动就眨眼、揉眼。你第一反应是"上火"，家里老人说要滴点母乳或菊花水清清火；翻抽屉又找出一瓶以前剩下的眼药水，想着"都是眼睛发炎，先滴两滴看看"。可又担心：这会不会传染？会不会是别的大毛病？

原书把红眼病（结膜炎，conjunctivitis）放在"常见疾病和关切"里。它讲清了关键的一点：**红眼病是结膜（眼球与眼睑相连部分表面的一层透明膜）发生了炎症或感染，通常由细菌或病毒引起，也可能由过敏导致**——病因不同，处理方法完全不同，所以"先分清是哪一种"比"赶紧点药"更重要。这条帮你认准症状、做对护理、守住就医边界。

## 核心判断

**白眼球和眼睑发红 + 分泌物多（从稀水样到黄绿黏稠）+ 早上眼睑被糊住，是结膜炎的典型画像；病因分细菌、病毒、过敏三种，处理各不同——病毒感染靠自身走完周期，细菌感染要用抗生素（遵医嘱），过敏要用抗过敏的眼药水（由医生决定）。分泌物约两天会改善，但发红可能持续几天，抗生素必须按处方疗程用完以防复发。它通过接触传染，护理的核心是清洁 + 隔离 + 洗手。**

## 机制

- **结膜炎是什么**：红眼病是眼球与眼睑相连部分表面一层透明的膜（结膜）发生了炎症或感染。
- **三种病因**：通常由细菌或病毒感染引起；病毒来源通常与导致普通感冒的病毒相同；也可能由过敏导致。
- **分泌物为什么有清有稠**：结膜炎会让眼睛里形成黏液或"物质"，从稀水样的到黄绿色黏稠的都有；其中**细菌感染更容易带来浓稠的绿色分泌物**——这提示分泌物性状可以帮助判断病因方向。
- **为什么早上会糊住眼睛**：睡眠时分泌物积在眼睑之间，醒来时眼睑会粘在一起，得洗干净才能睁开。
- **为什么怕光眨眼**：患结膜炎的宝宝在明亮灯光下会感到不适，或频繁眨眼睛。

## 诊断信号

**月龄判断**：结膜炎在婴幼儿各阶段都可能出现，本条覆盖 0-7 天到 5-6 岁。它常与感冒同期发生（病毒性与感冒病毒同源）；月龄越小，眼部分泌物越需要医生判断，因为新生儿眼部问题更需谨慎对待。

用这条的处境特征：
- 一只眼或双眼的**白眼球和眼睑发红**；
- 眼睛里有**黏液或分泌物**，从稀水样到黄绿色黏稠都有；细菌感染更常是**浓稠的绿色分泌物**；
- 醒来时**眼睑被分泌物粘住**，需要洗净才能睁开；
- 在**明亮灯光下不适**，或**频繁眨眼**；
- 常在同一时期有感冒等上呼吸道症状。

## 正常范围与个体差异

- 病程：急性结膜炎通常持续时间跟感冒差不多，**通常在一星期左右**，但有时会持续**两到三个星期**。
- 传染性：在传染期，结膜炎通过**接触**传染。
- 病因不同、过程不同：病毒感染需要时间走完自己的一个周期；细菌感染可以通过抗生素治疗；过敏引起的则由医生建议用过敏人群适用的特定眼药水。
- 用药后的变化：不论用药膏还是药水，**眼部分泌物的情况会在差不多两天时间内得到改善**，然而**发红的情况可能会持续几天**——分泌物先好转、红消退得慢，属于常见经过。

## 实操方法

1. **先认症状**：对着一只眼或双眼看——白眼球和眼睑是否发红、分泌物是稀水样还是黄绿黏稠、早上是否糊住眼、是否怕光眨眼。
2. **清洁分泌物**：用干净的棉花球（**每只眼睛都用一个新的**）和温水清洗宝宝的**外眼睑**；也可以用毛巾和热水。擦拭要**从内到外**，以免把感染带到未受感染的眼睛。
3. **做好隔离**：因为结膜炎通常会传染，你和其他照顾者要采取预防措施——患结膜炎的婴儿应该有**自己的浴巾和毛巾**，在家和在外都是如此；你接触孩子眼睛的分泌物后要**仔细洗手**。
4. **判断何时打电话**：出现眼睑发红肿胀、发热或开始生病、耳部感染症状，或开始治疗后似乎没有改善——给医生打电话。
5. **细菌感染遵医嘱用抗生素**：细菌感染的情况下，医生可能建议使用抗生素眼药水或眼药膏；按医生建议使用抗生素，**直到完成处方规定的疗程**，以防止感染复发。**不自行购买/使用眼药水**。
6. **上药时两人合作更顺手**：上药前先洗手（另一个人也应该这样做）；为避免污染药物，**不要让涂药器的顶部触碰任何表面，包括婴儿的眼睛**；用完用干净毛巾擦净涂药器顶部并拧紧瓶盖；触摸宝宝眼睛后洗手。
7. **眼药水的上法**：将宝宝放躺下来，轻轻拉下眼睑形成一个小袋，当宝宝眨眼时药水会散布到眼睛里。
8. **药膏的上法**：把患眼的下眼睑下拉形成一个小袋，挤一小条细细的药膏进去（除非医生另有要求）；松开下眼睑，再轻移上眼睑盖住眼睛，将眼睑合住一会儿。

## 备选计策

- **"两人上药"法（适合小月龄、不配合的宝宝）**：一人固定头和手、另一人上药，比一个人手忙脚乱安全得多（原书：在给宝宝的眼睛上药膏或药水时，两人合作会更容易）。
- **"药膏或药水二选一"（适合怕点药水的家庭）**：药膏涂抹后会让孩子的视线**模糊约 20 分钟**，但一些家长觉得**药膏比药水更容易使用**——可以问医生是否能用膏剂。
- **"单眼单棉球"装备法（适合有多孩或卫生顾虑的家庭）**：固定准备两包棉球或两只小碗，左眼右眼各用各的，物理上杜绝把一侧分泌物带到另一侧（原书：每只眼睛都用一个新的）。
- **"专用毛巾"隔离法（适合全家共用毛巾的家庭）**：给患病宝宝单独配一套浴巾和毛巾，用后单独清洗，减少传给家人的机会。

## 决策规则

- **怎么算有效**：分泌物的量减少、性状变清，眼睑不再糊住——原书给的观察是分泌物一般两天内改善。
- **坚持多久再评估**：抗生素要按处方**用完整个疗程**，不因症状好转就停；病毒性结膜炎则等它走完自身周期（约一周，有时 2-3 周）；期间发红可能持续几天，属正常。
- **出现什么信号换下一条/就医**：眼睑发红肿胀、发热或开始生病、出现耳部感染症状、或开始治疗后似乎没有改善 → 给医生打电话。

## 反模式

- **随手滴家里的眼药水/抗生素眼药水**：结膜炎病因分细菌、病毒、过敏，用错药不但无效还可能掩盖病程；抗生素要由医生评估后用。
- **用同一根棉球或毛巾擦两只眼睛**：把感染从一只眼搬运到另一只眼——规范是每只眼都用新的、从内到外擦。
- **症状好转就停抗生素**：必须按处方疗程用完，否则感染容易复发。
- **共用毛巾浴巾**：结膜炎通过接触传染，共用个人用品是常见的传播途径。
- **涂药器顶部碰到眼睛或桌面**：污染药物，规范是涂药器顶部不碰任何表面，用完擦净拧紧。
- **忽略传染防护**：接触孩子的眼部分泌物后不洗手，会把病原体带给家人和别的孩子。

## 边界

- 本条管感染性/过敏性结膜炎的识别、家庭护理与用药纪律，不替代医生的病因判断和处方。
- 分泌物多不等于是结膜炎：鼻泪管阻塞、倒睫等非感染性原因也会让眼睛泪汪汪、有分泌物，但通常**不红不肿**（可参照 safe-xiami-eye-ear-signals）。
- 病因不同、流程不同：病毒性靠自愈、细菌性用抗生素、过敏性用抗过敏眼药水（由医生决定）——家庭端不要自行归类下药。
- 月龄出界：学龄后反复发作、或伴视力下降的眼部问题——走专科评估，本条的"感染护理"框架不适用。

## 就医红线

（tier-1；征象来自原书"红眼病（结膜炎）"节）

- **眼睑发红、肿胀** → 给医生打电话。
- **发热或者开始生病** → 给医生打电话。
- **出现耳部感染的症状** → 给医生打电话。
- **开始治疗后似乎没有改善** → 给医生打电话。
- **新生儿（0-7 天）出现眼部红肿或脓性分泌物** → 建议尽早就医由医生评估（蒸馏者注：此为小月龄安全提示，非本节原文；可与 safe-xiami-eye-ear-signals 及产科新生儿眼部处理相互参照）。

## 代价与风险提示

- **耐心账**：结膜炎常与感冒同期，通常一周、有时两三周才完全好，急不来。
- **用药纪律**：抗生素必须按疗程用完，症状好转也不能自己停，否则可能复发。
- **操作成本**：给小月龄宝宝上眼药水/眼膏要两人配合、注意不污染药物，是持续的耐心活。
- **传染防护**：要为患病宝宝单配毛巾、勤洗手，家务和心理负担都会增加。
