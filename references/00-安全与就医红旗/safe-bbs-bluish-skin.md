# 皮肤发蓝（cyanosis）是"组织缺氧"的信号——只有手/脚发蓝多是受冷或衣带太紧，暖一暖就恢复；新生儿吃奶时口周一圈蓝白也正常。但"全身发蓝""唇和舌发蓝+呼吸有杂音""脸发蓝+发热"要立即就医；"不能呼吸/说话/咳嗽"立即打 911

## 解决的问题

孩子大哭时突然憋住气，脸先是通红，接着变成灰蓝色，还差点瘫倒——这一幕能把家长吓坏。或者天冷时他的手指脚趾发紫；又或者他喘着喘着，嘴唇发青了。这些"发蓝"到底哪种要紧、要不要马上送医院？

这条要回答的正是这个具体场景。AAP 把皮肤发蓝叫**发绀（cyanosis）**，它意味着**底层组织没有获得足够的氧气**。发蓝的部位和伴随症状，决定了它是"暖一暖就好"还是"立刻急救"。

## 核心判断

**只有局部（一只手或一只脚）发蓝、且能暖回来**：多因**紧衣或绷带压迫血流**，或**受冷**——保暖后肤色恢复，通常不必紧急处理。**新生儿吃奶时口周一圈蓝白色**，喂完就消失，是**完全正常**的。

但出现下面几条要**立即联系医生**：**全身发蓝**、**嘴唇和舌头一起发蓝并伴呼吸有杂音**、**面部发蓝伴发热**。如果孩子**发蓝且不能呼吸、说话或咳嗽**——**立即拨打 911**。

关于**屏气发作（breath-holding spell）**：孩子大哭屏气、脸从红转灰蓝、甚至跌倒"像晕过去"或抽搐，**看起来可怕，但多半无害**——即使最倔强的幼儿也**无法憋气到伤害自己**；一旦失去意识，本能反射会让他重新正常呼吸。**不要约束他、不要强行让他呼吸**；若期间**晕倒或抽搐，则要联系医生**。

## 机制

- **发绀意味着什么**：皮肤发蓝说明底层组织**缺氧**。
- **为什么局部发蓝多没事**：只在一只手/脚时，常是**紧衣、绷带**减少了血流；**受冷**也会让唇、指、趾发蓝——**暖起来后肤色会恢复**。
- **为什么新生儿口周蓝白正常**：很幼小的婴儿在**喂奶时**常出现口周蓝白圈，**喂完消失**——这是正常的。
- **为什么大面积发蓝危险**：如果蓝色覆盖**身体很大一部分**，可能说明宝宝**极度缺氧**，需要立即医疗处理。
- **屏气发作的真相**：家长往往比孩子更害怕；发作是孩子用憋气表达强烈情绪，本身通常无害。
- **基础病**：部分**先天性心脏病**患儿会一直血氧偏低、看起来发绀——需与心脏科医生商定可接受的血氧范围与监测方法；**methemoglobinemia**（高铁血红蛋白血症）是罕见的、可家族遗传的状况，会让皮肤发蓝。
- **证据强度**：以上为 AAP 机构性口径（tier-1）。

## 诊断信号

适用窗口：0-6 岁全段，新生儿与婴儿尤需分辨"正常口周蓝白圈"与"真发绀"。

用这条的处境特征：
- **全身或大面积**发蓝。
- **唇、舌**发蓝，或**呼吸有哨音/杂音**。
- **面部发蓝且发热**。
- **哭泣屏气**、脸由红转灰蓝、甚至晕倒/抽搐。
- **吃奶/玩耍/运动时**发蓝、指甲也蓝。

## 正常范围与个体差异

- **局部发蓝**：仅手或脚，因紧衣/绷带或受冷，**暖后恢复**。
- **新生儿口周蓝白圈**：喂奶时出现、**喂后消失**，正常。
- **屏气发作**：多无害；孩子最终会找到更建设性的方式表达怒气。
- **先心病患儿**：可能常年发绀，血氧"目标范围"由专科设定。
- **个体差异**：是否有心肺基础病，决定发蓝的意义与处理。

## 实操方法

1. **看范围**：只有手/脚发蓝 → 松开紧衣/绷带、保暖，观察是否恢复。
2. **看伴随**：全身发蓝、唇舌发蓝 + 呼吸杂音、面部发蓝 + 发热 → 按红线立即就医。
3. **不能呼吸/说话/咳嗽** → **立即拨打 911**，并按年龄执行急救/CPR 流程。
4. **受冷发蓝** → 擦干、用毯子包裹或移到温暖的房间；若很冷，可放入**温水（微温）**浴；平时按气温给孩子穿衣以预防低体温（hypothermia）。
5. **屏气发作时** → **保持冷静、确保安全、不约束、不强迫呼吸**，也**不要小题大做或迁就他的要求**（否则会强化发作）；事后不额外给关注。
6. **屏气发作期间晕倒或抽搐** → 联系医生，排除躯体原因；若医生怀疑情绪问题，可能转心理专业。
7. **基础病孩子** → 按心脏科医生设定的血氧范围与监测方法管理。

## 备选计策

- **保暖 + 松衣法（适合局部发蓝）**：先排除压迫与寒冷。
- **冷静不强化法（适合屏气发作）**：不约束、不迁就、事后不渲染。
- **急救/CPR 预案（适合气促/窒息风险）**：家长学会按年龄的急救流程。
- **专科共管（适合先心病患儿）**：与心脏科设定血氧目标。

## 决策规则

- **怎么算有效**：局部发蓝保暖后恢复、口周蓝白圈喂后消失——正常。
- **坚持多久再评估**：局部发蓝观察数分钟到暖回来；屏气发作是"等它过去"。
- **出现什么信号换下一条**：全身发蓝、唇舌发蓝 + 呼吸杂音、面部发蓝 + 发热、不能呼吸/说话/咳嗽、屏气发作伴晕倒/抽搐 → 立即就医/911。
- **安全一票否决**：不能呼吸立即呼救。

## 反模式

- **把全身发蓝当"受冷"**：大面积发蓝提示严重缺氧。
- **屏气发作时约束孩子或强迫他呼吸**：物理上做不到，且有害。
- **对屏气发作过度反应、迁就要求**：会强化发作。
- **忽视"发蓝 + 呼吸有杂音/发热"**：可能是 croup、哮喘、肺炎等。
- **先心病患儿脱离专科管理**：血氧目标需专科设定。

## 边界

- **性质边界**：本条以"皮肤发蓝"为主轴；以呼吸困难为主轴见 breathing-difficulty 条。
- **月龄边界**：新生儿要区分"正常口周蓝白圈"与真发绀。
- **共病**：croup、哮喘、肺炎、先心病、屏气发作都可表现为发蓝。
- **不替代急救**：不能呼吸/说话/咳嗽时，第一步是呼救。

## 就医红线

（tier-1；征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

**立即联系医生：**
- **全身皮肤发蓝**。
- **嘴唇和舌头一起发蓝，并伴呼吸有杂音**。
- **面部发蓝，并伴发热**。

**立即拨打 911/当地急救：**
- **孩子发蓝且不能呼吸、说话或咳嗽** → 立即呼救，并按年龄执行急救/CPR 流程。

**其他：**
- **屏气发作期间晕倒或抽搐** → 联系医生（排除躯体原因）。
- **孩子哭到屏气、晕过去、又很快恢复** → 咨询医生（多为良性屏气发作）。
- **犬吠样咳嗽 + 费力且有杂音的呼吸**（croup）→ 立即 911/急诊。
- **口周发蓝 + 喘鸣**（可能哮喘等呼吸问题）→ 立即 911。
- **婴儿皮肤发蓝、感冒咳嗽加重一两天、呼吸急促困难、拒食烦躁**（支气管炎）→ 立即 911 或联系医生。
- **唇周发蓝 + 发热 + 病态 + 呼吸急促**（支气管肺炎）→ 立即联系医生。
- **吃/玩/运动时发蓝、指甲/唇/舌/黏膜发蓝**（心肺循环问题）→ 联系医生并可能转专科。
- **晕厥并失禁、且既往有抽搐**（癫痫）→ 联系医生。

## 代价与风险提示

- **分辨成本高**：正常口周蓝白圈与真发绀外观相近，靠范围与伴随症状区分。
- **屏气发作的心理消耗**：看着惊险，家长要练就"冷静不强化"的定力。
- **基础病长期管理**：先心病患儿需与专科长期共管血氧。
- **急救门槛**：不能呼吸立即呼救，意味着平时要备好急救知识。
