# 磕破嘴唇先清水冲洗再冰敷，10~15 分钟还流血不止就就医；牙磕掉一块留尖边要磨平，几天后牙疼/位移/牙缝见粉红小点要查牙神经

## 解决的问题

孩子撞到桌角、门槛，或者坠床时脸朝下，最容易磕破的就是嘴——嘴唇裂开、满嘴是血，看着吓人。石头、铅笔还可能磕到或戳到牙齿，把门牙磕掉一小块。家长往往一边心疼一边纠结：这点小伤要不要跑医院？会不会影响以后换牙？

原书对嘴和牙的外伤给了很明确的分层：**嘴唇小裂口 → 家庭处理；裂口较大或 10~15 分钟止不住血 → 就医；牙齿轻微磕碰多不用看牙医，但出现特定信号必须及时就医**。判断的关键是几个可观察的门槛。

## 核心判断

**嘴唇受伤：小裂口先清水冲洗、再冰敷（缓解疼痛+尽快止血）；裂口较大或 10~15 分钟仍出血不止，就医。若怀疑伤口与咬到电线有关，就医时如实告知（怕烫伤被延误）。牙齿：轻微磕碰多不用看牙医；但牙齿磕掉一块留下尖边/尖端要请牙医磨平或填充；牙龈出血要就医；牙齿磕伤几天后仍疼、明显位移伴牙龈肿胀、或牙缝见粉红色小点（可能牙神经受损），应及时就医，以免影响恒牙生长。**

## 机制

**为什么先冲洗再冰敷**：清水清洗裂口是清创；冰敷既缓解疼痛，又能收缩血管、尽快止血。

**为什么设"10~15 分钟"阈值**：小裂口常在短暂按压/冰敷后止血；持续 10~15 分钟仍不止，说明出血较多，需医生处理。

**为什么咬电线要特别告知**：如果嘴唇伤口其实是咬到电线造成的烫伤，外观可能像普通裂口，**延误烫伤处理**。如实告知医生能避免误判。

**为什么牙齿尖边要磨平**：磕掉一部分后留下的锋利边缘或尖端会持续伤害口腔软组织，需牙医磨平或填充。

**为什么"牙缝见粉红小点"要就医**：磕伤几天后仍疼痛、牙齿明显位移伴牙龈肿胀、或牙缝中出现粉红色小点，**可能是牙神经受到损伤的表现**，需及时治疗以免影响恒牙生长。

## 诊断信号

**月龄判断**：本条覆盖 0-6 岁全段。学步/幼儿期磕碰口腔、牙齿最集中。

用本条的处境：
- 嘴唇小裂口、轻微出血 → 家庭处理
- 嘴唇裂口大、或 10~15 分钟仍流血 → 就医
- 口腔/舌磕碰或刺伤、少量出血 → 含冰块/冰棒，舌出血用纱布捏紧
- 牙齿磕掉一块留尖边、牙龈出血 → 就医/看牙医
- 磕伤几天后牙疼、牙齿位移、牙缝见粉红小点 → 及时就医

## 正常范围与个体差异

- 大多数嘴巴磕碰不会造成严重伤害
- 嘴唇小裂口、轻微出血属家庭可处理范围
- 牙齿轻微磕碰大多数情况不需要看牙医
- 出现尖边、牙龈出血、牙疼/位移/粉红小点，则超出家庭范围，需就医

## 实操方法

1. **嘴唇小裂口 + 轻微出血**：先用**清水清洗裂口**，然后**冰敷**（缓解疼痛、尽快止血）。
2. **裂口大 / 10~15 分钟不止血**：**及时带孩子去医院**，由医生处理。
3. **怀疑咬电线**：就医时**如实告知医生**，以免嘴巴的烫伤被延误。
4. **口腔/嘴唇磕碰或刺伤轻微肿痛/少量出血**：让孩子**含冰块或用冰棒**缓解疼痛、及时止血。
5. **舌头出血**：用**干净的纱布或毛巾捏紧伤口**止血。
6. **铅笔/细木棍等锐物刺伤嘴唇且 10~15 分钟不止血**：**立即带孩子就医**。
7. **牙齿轻微磕碰**：多不需看牙医，观察即可。
8. **牙齿磕掉一块、留尖边/尖端**：请**牙医磨平或填充**，避免伤到口腔。
9. **牙龈出血**：请**医生检查**出血位置和原因。
10. **牙齿磕伤几天后仍疼 / 明显位移伴牙龈肿胀 / 牙缝见粉红小点**：**及时就医**，防影响恒牙。

## 备选计策

- **"冰棒止血"**：嘴唇/口腔轻微伤让孩子含冰棒——适用"孩子能含住、肯配合"的情况
- **"计时止血"**：从受伤起计时，看是否 10~15 分钟内止住——适用"判断要不要跑医院"的家庭
- **"如实告知医生"**：怀疑咬电线/异常致伤时主动说明——适用"伤因不确定"的家庭

## 决策规则

- **怎么算"家庭能处理"**：嘴唇小裂口 + 轻微出血 + 短时止住 → 家庭处理；牙齿仅轻微磕碰 → 观察
- **坚持多久再评估**：嘴唇/口腔出血 10~15 分钟仍不止 → 就医；牙齿损伤观察数日
- **出现什么信号换法/就医**：裂口大、止不住血、锐物刺伤、牙尖边、牙龈出血、牙疼/位移/粉红小点 → 就医
- **何时停止自行处理**：出血不止、伴随其他外伤 → 就医

## 反模式

- **嘴唇一直流血只捂着不冲洗**：应先清水清洗 + 冰敷
- **牙齿磕掉尖边不当回事**：持续划伤口腔，需磨平
- **把牙齿磕伤后的牙疼当"正常，忍忍就好"**：可能是牙神经损伤，需就医
- **咬电线致伤不告知医生**：延误烫伤判断
- **用锐器自己处理口腔伤**：可能加重损伤

## 边界

- 本条为口腔/牙齿外伤的现场处理与就医指征；牙齿固定、修复由牙医完成
- 乳牙外伤可能影响恒牙发育，出现牙神经信号不要拖
- 若口腔出血伴意识/呼吸异常，优先按急救处理
- 有出血性疾病的孩子口腔出血标准更严，遵专科医嘱

## 就医红线

**出现以下任一情况，立即/及时就医**（p548-549，卫健委 2022 交叉，2026-10-04 核对）：

- **嘴唇裂口较大，或 10~15 分钟后仍出血不止**——及时就医
- **铅笔/细木棍等锐物刺伤嘴唇且 10~15 分钟不止血**——立即就医
- **怀疑伤口与咬电线有关**——就医并如实告知医生
- **牙齿磕掉一块、留下尖锐边缘/尖端**——看牙医磨平或填充
- **牙龈出血**——请医生检查出血位置和原因
- **牙齿磕伤几天后仍疼痛**——及时就医
- **牙齿明显位移并伴牙龈肿胀**——及时就医
- **磕伤的牙缝中看到粉红色小点**——可能牙神经受损，及时就医

## 代价与风险提示

- 嘴唇伤要忍住"先捂着看看"的冲动，先冲洗再冰敷
- 牙齿小磕碰"要不要看"的门槛需拿准，过度就医与漏诊之间要把握
- 牙神经信号出现必须及时就医，拖延可能影响恒牙
- 咬电线致伤要如实告知，可能被追问看护细节
