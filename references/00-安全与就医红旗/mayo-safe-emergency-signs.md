# 这十一种情况别犹豫，直接走急诊——流血不止、中毒、抽搐、呼吸困难、头部受伤、无反应……电话打不通就抱孩子去最近的急救机构

## 解决的问题

凌晨三点，孩子突然抽搐、怎么叫都没反应；或者被开水烫了一大片；又或者从床上滚下来磕到了头。你的脑子一片空白，指纹解锁都抖得解不开手机：**这到底要不要去医院？120 打不打？**

婴儿不会用语言告诉你哪儿疼，所以有时很难把严重的疾病，从那些常见的、在家就能应对的小病里区分出来。这一条给你一份"立刻走急诊"的清单和动作，帮你在最慌的几分钟里，做一个**不需要犹豫**的决定。

## 核心判断

**出现下列任一种情况，都不是"再观察看看"的事：流血不止、中毒、抽搐、呼吸困难、头部受伤、无反应、突然没力气或动不了、大的伤口和大面积烧伤、脖子强直、尿血便血或持续腹泻、皮肤或嘴唇呈蓝色紫色或灰色——立即拨打 120（美国 911）或当地急救电话；电话打不通，就把孩子带到最近的急救机构。**

## 机制

- **为什么这些小月龄更危险**：宝宝的血容量相对较少，无法承受失去和大孩子或成人同样的血液量。如果不加处理，动脉大量出血严重者能在几分钟内造成死亡。
- **为什么"无反应/抽搐/呼吸困难"是分钟级**：宝宝缺氧的时间越长，永久性脑损伤和死亡的风险就越大。这类情况没有家庭观察窗。
- **为什么"脖子强直"要单列**：它常提示脑膜炎等中枢神经感染，和普通"落枕、脖子不舒服"完全不是一回事——和发热同时出现时更需要警惕（在多个疾病条目中把"脖子强直"列为急症征象）。
- **为什么"中毒"要单列、且处理方式因物质而异**：几乎所有非食品物质食入过多都有毒，但不同物质的毒性差异很大；一些物质或药物即便很小剂量，对幼儿的危险程度也远高于成人。所以"要不要催吐、怎么处理"必须交由中毒热线或急救人员判断。
- **为什么大面积烧伤不能泡冷水**：原书特别提醒——不要把大面积严重烧伤的伤口置于冷水中，这可能造成体温过低、血压下降、血液循环迟缓，从而引发休克；轻度烧伤才用流动冷水降温。
- **为什么要把征象汇总成一张清单**：婴儿在疼痛时无法用语言告诉你，家长很难逐病判断。一张跨系统的清单，比一一去想"他是不是得了 X 病"更快、更不容易漏。

## 诊断信号

本条适用于 0-6 岁全月龄。用这条的处境特征：**突发、进展快、你拿不准是不是"要紧了"**；出现清单上任何一项；家里没人能冷静地做判断；赶上深夜、离医院远、或一个人带孩子。婴儿真正需要急诊的情况相当罕见——清单是为了在罕见情况真发生时不出错，不是让你日常惶惶。

## 正常范围与个体差异

- **判断出血严重程度看"失血速度"**：严重出血多因伤到动脉（流出快）；缓慢且稳定地流出深红色血，一般伤到静脉或毛细血管。
- **婴儿柔软的骨头不像大孩子那样容易骨折**；但坠落的力量、高度和接触到的表面，是决定伤害程度的重要因素——头部受伤仍要在 24 小时内持续观察行为变化。
- **轻度烧烫伤**可在降温、清洁后居家处理；**大面积或三级/二级重度烧伤**属于急诊。
- **烧烫伤按程度分级**：一度烧伤只影响表皮层（皮肤泛红或轻微肿胀）；二度烧伤会有水泡、皮肤发红得厉害、中到重度肿胀和疼痛；三度烧伤伤及皮肤各层，看起来发白或烧焦，因神经受损痛感反而不明显。这一分级决定了哪些能在家处理、哪些是急诊。
- 偶尔奇怪的抖动或不平稳的动作，尤其是沉睡中的婴儿，**不是惊厥**；有节奏地抽动、同时对呼唤无回应、意识不到环境，才是惊厥。

## 实操方法

1. **先逐条过清单**：流血不止 / 中毒 / 抽搐 / 呼吸困难 / 头部受伤 / 无反应 / 突然没力气或动不了 / 大的伤口和大面积烧伤 / 脖子强直 / 尿血、便血、持续性腹泻 / 皮肤或嘴唇呈蓝色紫色或灰色。命中任一条 → 走第 2 步。
2. **拨打急救电话**：立即拨打 **120**（美国 911）或当地急救电话。说清**地址、孩子月龄、发生了什么、现在什么状态**。
3. **打不通就出发**：如果无法电话寻求急救帮助，就把孩子带到**最近的急救机构**。
4. **同步做现场处置**（按具体情形）：
   - **流血不止** → 用干净的纱布或无菌纱布垫**直接紧压伤口**，直到流血停止；不要先清理伤口或抠出嵌入的异物；止血后紧紧包扎固定，可能的话抬高出血处；仍止不住就压住向该区域供血的主要血管并呼救。
   - **中毒** → 把孩子搬离毒源，**立即拨打中毒救助热线**；把药瓶/容器放在面前以便描述物质与摄入量；**不要擅自给孩子催吐或喂任何东西**，除非中毒热线或急救人员让你这么做。
   - **抽搐** → 让孩子侧卧在不会摔下来的地方，靠近观察安慰，把周围坚硬尖锐物体拿开，解开紧绷束缚的衣物；**不要限制或干扰孩子的动作，不要往嘴里放任何东西**。
5. **保持冷静、看好孩子**：你的冷静观察，是救护到来前最有用的动作。
6. **到院带齐信息**：发生时间、症状变化、已做的处置、用过的药或吃过的可疑物，一并告诉医护。

## 备选计策

- **提前备好急诊路线（适合所有家庭）**：在例行体检时问清"如果宝宝需要急诊护理，该做什么、去哪里就诊"；把急救电话存进手机；学包括**心肺复苏**在内的基本急救方法。
- **中毒专线优先（适合疑似误服的家庭）**：把中毒救助热线的号码存在手机里，并让帮忙照看孩子的人也知道这个号码在哪；疑似吞食，先拨热线。
- **多人分工（适合有两人以上在场的家庭）**：一人拨电话/叫车，一人守孩子做现场处置。若你是唯一施救者而必须做心肺复苏，先做约 2 分钟（5 个循环）再打电话；有其他人在场，就让对方立刻拨打电话求助。

## 决策规则

- **怎么算有效**：带着清晰信息，在第一时间到达可以救治的地方。目的不是"在家确诊"，是**不错过分钟级的救治窗口**。
- **坚持多久再评估**：不适用——清单命中即为"立即"，没有家庭观察窗。
- **出现什么信号换下一条**：一旦清单命中，你心里那句"要不要再等等、是不是小题大做"**本身就是红线**——出发。

## 反模式

- **把"无反应/抽搐/呼吸困难"当成"睡着了/闹脾气/闹觉"再观察**：这几项是分钟级，观察就等于延误（缺氧越久，永久脑损伤和死亡风险越大）。
- **中毒后擅自催吐或喂东西**：原书明确"不要给宝宝服用任何东西，除非中毒热线建议你这么做"——做法因物质而异，乱催吐可能造成更大伤害。
- **流血时先"清理伤口里的异物"再止血**：原书要求**直接紧压伤口**止血，不要先尝试清理或抠出嵌入异物。
- **头摔了看当时哭没哭就放心**：原书要求 24 小时内持续观察行为变化，出现异常立即求助。
- **打电话前先四处找信息、耽误叫车**：先拨号，把地址和状态一次说清。

## 边界

- 本条是"要不要走急诊"的**汇总统筹式清单**。具体病因的识别与现场处置另有专条：呼吸维度的识别与阈值见 **safe-resp-distress**（呼吸窘迫专条），气管异物/窒息的现场急救见 **safe-pei-airway-fb**（气管异物专条）。
- 清单不穷尽所有急症。**拿不准、你直觉不对，就去看**（相信你作为父母的直觉）。
- 现场急救（止血、心肺复苏、海姆立克法等）有标准手法，本条只给入口；动手细节以急救培训与对应专条为准。

## 就医红线

（tier-1；清单照录本书原文第十六章「何时寻求急诊护理」）

以下任一情况 → **立即拨打 120（美国 911）或当地急救电话**：

- **流血不止**（动脉大出血几分钟可致命）
- **中毒**
- **抽搐**
- **呼吸困难**
- **头部受伤**
- **无反应**
- **突然没力气或动不了了**
- **大的伤口和大面积烧伤**
- **脖子强直**
- **尿血、便血、持续性腹泻**
- **皮肤或嘴唇呈蓝色、紫色或灰色**

**无法电话求助 → 把孩子带到最近的急救机构。**

## 代价与风险提示

- 清单式急诊意味着你会为"可能虚惊"跑很多趟——这是分钟级救治窗口的固定成本。
- 学会判断和现场急救（止血、心肺复苏）需要提前投入学习，平时用不上，用上时就是救命。
- 深夜、离医院远、独自带娃都会放大决策压力，要提前把路线和叫车方式想好。
- "相信直觉就去"会额外花掉时间与金钱，换来的是不错过极少数致命情况。
