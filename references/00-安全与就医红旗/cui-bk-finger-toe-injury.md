# 手指脚趾被夹了/砸了——冷水泡 15~30 分钟（每 5~10 分钟停一次防冻伤）、抬高、别泡甲脱落；迅速肿胀变形要考虑骨折

## 解决的问题

孩子玩推拉门、抽屉，或者关车门时夹到了手指，指甲下面很快变成一片紫黑，手指也肿了起来。家长第一反应常是"热敷消肿"或者"干脆把翘起来的指甲拔掉"——这两个都是错的。原书对手指/脚趾受伤的处理分得很细：**挫伤、甲内出血、甲开裂、甲脱落**，各有各的做法，其中浸泡时长、防冻伤、能不能泡冷水都有明确规矩。

## 核心判断

**手指/脚趾挫伤（夹伤）：先冷水中浸泡 15~30 分钟，为防止冻伤应每隔 5~10 分钟间断一次，待温度恢复正常再继续；抬高肿胀部位助消肿。若短时间内迅速肿胀、出现畸形或影响活动，要考虑骨折。被车轮辐条、电风扇叶等旋转物击打致挫伤，应立即就医。甲内出血：按压或泡冰水，未缓解就医。甲开裂：贴创口贴。甲脱落（半脱或全脱）：及时就医，别自己扯、也别泡冷水。**

## 机制

**为什么冷水要泡 15~30 分钟且间断**（p551）：冷敷收缩血管、减轻肿胀疼痛；但持续浸泡会导致**冻伤**，所以要每隔 5~10 分钟间断一次，等温度恢复再继续。

**为什么抬高患处**（p551）：抬高肿胀的手指或脚趾**有助于消退肿胀**。

**为什么甲内出血要按压/泡冰水**（p551-552）：按压指（趾）甲可加快出血、**缓解甲内压力、减轻疼痛**；孩子忍不了按压的疼，可泡冰水。缓解不了则就医。

**为什么甲脱落不能泡冷水、不能硬扯**（p552）：甲缺损或缺失使**甲床失去保护，容易发生感染**，故不泡冷水；未完全脱落时**切勿刻意扯掉**，通常会自然脱落。因此甲脱落应就医处理，避免自行处理不当造成感染。

## 诊断信号

**月龄判断**：本条覆盖 0-6 岁全段。会走、爱玩门/抽屉的幼儿期高发。

用本条的处境：
- 被推拉门、抽屉、车门夹到手指/脚趾 → 按挫伤处理
- 出现指（趾）甲下出血、发黑 → 甲内出血处理
- 指甲表面出现裂痕 → 甲开裂处理
- 指甲半脱落/完全脱落 → 就医
- 被旋转物（辐条、扇叶）打到 → 立即就医
- 迅速肿胀、畸形、影响活动 → 考虑骨折

## 正常范围与个体差异

- 轻度挫伤经冷水浸泡 + 抬高可逐步消肿
- 甲开裂未贯穿：贴创口贴、随甲生长修剪即可
- 甲贯穿性开裂、甲半脱/全脱：超出家庭范围，需就医
- 指甲缺损/缺失时不能泡冷水

## 实操方法

1. **挫伤（夹伤）先冷水泡**：将受伤的手指或脚趾**浸泡在冷水中 15~30 分钟**；**每隔 5~10 分钟间断一次防止冻伤**，待温度恢复正常后再继续。
2. **抬高患处**：把肿胀的手指或脚趾**抬高**，帮助消肿。
3. **疑骨折**：若**短时间内迅速肿胀、出现畸形或影响正常活动**，考虑骨折，按 cui-bk-fracture 处理。
4. **旋转物击打**：因**车轮辐条、电风扇叶等快速旋转物**打成挫伤，**立即带孩子就医**。
5. **甲内出血**：**按压指（趾）甲**加快出血、缓解甲内压力、减轻疼痛；孩子忍不了可**泡冰水**。**出血未缓解 → 就医**。
6. **甲开裂**：表面有裂痕但未完全开裂 → **贴创口贴**，待甲长好后修剪；裂痕贯穿整个甲 → **剪掉并磨平边缘撕裂部分、贴创口贴**，直到长好。
7. **甲脱落**：半脱落或完全脱落都**及时就医**；**切勿刻意扯掉**（通常自然脱落）；**不要泡冷水**（甲床失去保护、易感染）。

## 备选计策

- **"间歇冷水泡 + 抬高"**：轻度夹伤的居家首选——适用所有家庭
- **"冰敷替代长泡"**：不方便久泡时用冰袋（隔毛巾）冷敷——适用"孩子不肯泡"的情况（冰敷做法见 cui-bk-cold-heat-compress）
- **"就医处理甲脱落"**：甲半脱/全脱——适用所有家庭

## 决策规则

- **怎么算"家庭能处理"**：轻度挫伤、未贯穿的甲开裂 → 家庭处理；甲内出血缓解后可观察
- **坚持多久再评估**：冷水浸泡按 15~30 分钟执行；甲内出血按压/泡冰水后仍出血 → 就医
- **出现什么信号换法/就医**：迅速肿胀/畸形/影响活动（疑骨折）、旋转物击打、甲内出血未缓解、甲脱落 → 就医
- **何时停止自行处理**：甲床失去保护（甲缺损/脱落）→ 停止泡冷水，就医

## 反模式

- **夹伤后马上热敷**：加重肿胀，应先冷敷
- **冷水一直泡不间停**：可能冻伤，应每 5~10 分钟间断
- **把翘起的指甲硬拔掉**：可能损伤甲床、感染
- **甲脱落后仍泡冷水**：甲床失去保护，易感染
- **把迅速肿胀变形当普通肿**：可能是骨折
- **旋转物击打后在家处理**：应就医

## 边界

- 本条为手指/脚趾挫伤与甲损伤的现场处理；骨折、甲脱落的最终处置由医生完成
- 疑骨折时按 cui-bk-fracture 处理，勿自行复位
- 若伴开放性伤口、出血，先止血包扎
- 有凝血问题的孩子甲内出血标准更严，遵专科医嘱

## 就医红线

**出现以下任一情况，立即/及时就医**（p551-552，卫健委 2022 交叉，2026-10-04 核对）：

- **手指或脚趾短时间内迅速肿胀、出现畸形或影响正常活动**——考虑骨折，就医
- **被车轮辐条、电风扇叶等旋转物击打致挫伤**——立即就医
- **指（趾）甲内出血经按压/冰水未缓解**——就医
- **指（趾）甲半脱落或完全脱落**——及时就医（勿自己扯、勿泡冷水）
- **甲开裂贯穿整个指甲**——按甲开裂处理，必要时就医

## 代价与风险提示

- 冷水泡要断断续续防冻伤，比"一直泡"费心
- 甲内出血只能按压/泡冰水，缓解不了还得跑医院
- 甲脱落不能自己扯、也不能泡冷水，必须就医
- 分不清是否骨折时按骨折保守处理，可能白跑
