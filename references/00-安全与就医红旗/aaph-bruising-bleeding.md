# 孩子身上的瘀斑，小腿上磕出来的多数不用管，但这几种要查——不明原因或不寻常部位（臀/脸/肩/背）、便血、易瘀斑伴苍白疲惫、针尖样瘀点或大块紫癜，可能指向凝血障碍、血小板减少甚至白血病，也可能提示受虐

## 解决的问题

给孩子换衣服时，你发现身上多了一块青。小腿上那几块你心里有数，是跑跳磕的；可后背这块、肩膀这块，想不起来什么时候碰的。你开始往回数这几天孩子有没有喊累、有没有脸色不对，越数越不安。老人说"孩子皮实，磕磕碰碰正常"，可你就是放不下——这到底是正常磕碰，还是身体出了毛病？

原书第 19 章"出血和瘀斑"把这件事讲得很清楚。先说背景：**瘀斑是受伤后皮下出血形成的蓝黑色区域**，随着皮下组织愈合颜色会慢慢改变；幼儿好动、运动时受伤导致小腿上的瘀斑，**不需要担心**。真正需要警惕的是另一组——**出现在臀部、脸上、肩膀、背部的无法解释的瘀斑**，以及伴随其他症状的出血。辨认这组信号，就是本条要做的事。

## 核心判断

**看瘀斑要不要紧，看三点：部位、原因、伴随症状。** 小腿上、能对上磕碰、孩子健康的瘀斑 → 不用管；**出现在臀/脸/肩/背等不寻常部位、或你完全说不清怎么来的、或伴大小便带血、或伴肤色异常苍白疲惫、或是针尖样瘀点/大块紫癜** → 需要就医评估（可能是凝血障碍、特发性血小板减少、过敏性紫癜，甚至白血病）。另外，**孩子不愿告诉你瘀斑怎么来的、或身上多处形状奇怪的瘀斑、孩子变得胆小孤僻**，要警惕受虐，必须联系医生，必要时由相关部门介入保护（p42-43）。

## 机制

- **为什么受伤后瘀斑正常**：健康孩子弄破皮肤后，流血会在几分钟内停止、凝结成"痂"保护伤口；头皮血管丰富，受伤会流很多血，也属正常。
- **为什么"流血不止/意识改变"是内脏出血信号**：若伤口经紧急处理后仍流血不止，或孩子**意识水平下降、剧烈疼痛（含头痛）、身体某部位移动困难、肤色泛白、出汗或水肿**，提示可能有内脏出血，要马上送医。
- **为什么"针尖瘀点/大块紫癜"要查**：白血病是儿童最常见的癌症（占儿童肿瘤 1/3），多数孩子会发热或肤色苍白，许多有**瘀点（针尖大小、按压不褪色）和紫癜（更大块、凸起、按压不褪色）**，提示皮肤层或更深出血。
- **为什么"易瘀斑+苍白+疲惫"指向全身病**：反复容易瘀斑、同时脸色苍白、无精打采、爱发脾气，可能是一种全身性疾病（如白血病）的表现（p43 决策表）。
- **为什么"黏膜小伤口流血几小时/几天"要查凝血**：出血性疾病或凝血因子缺乏（如血友病、血管性血友病，均为遗传性）会表现为黏膜伤口长时间流血。
- **为什么"Trendelenburg/受虐"要看整体**：无法解释、部位不寻常、形状奇怪的瘀斑，以及孩子胆怯孤僻、不愿解释，是受虐的警示组合；书明确"不要忽视虐待儿童的可能性，尤其是当孩子不愿意告诉你瘀斑是如何来的时候"（p42-43）。

## 诊断信号

**本条适用于 0-6 岁所有年龄段**。用这条的处境特征：发现说不清来历的瘀斑；瘀斑位置在躯干/面部/臀部而非小腿；孩子伴苍白/疲惫/发热；有便血或尿血；身上有小红点；孩子变得胆怯、不愿说出瘀斑来源。

## 正常范围与个体差异

- 幼儿好动，运动/磕碰后小腿出现瘀斑属正常，不需要治疗（p42-43）。
- 良性瘀斑：部位在四肢暴露处、能对上外伤、孩子健康活泼、单个或少量。
- 需警惕：不寻常部位（臀/脸/肩/背）、无法解释、数量多或形状怪、伴出血或其他症状。
- 瘀点/紫癜：按压不褪色（区别于普通红疹），提示皮肤/深层出血，需就医。
- 个体差异：有凝血障碍家族史、已知血小板问题的孩子阈值更低。

## 实操方法

1. **先问"部位"**：小腿等暴露处、能对上磕碰 → 良性；臀/脸/肩/背、说不清来历 → 记下并准备就医。
2. **扫"立刻打电话/就医"清单**：无法解释的瘀斑或不寻常部位瘀斑；大小便带血；小伤口长时间流血；很容易瘀斑伴肤色异常苍白、疲惫；月经量很大。
3. **扫"马上送医"信号**：伤口经紧急处理后仍流血不止；意识水平下降；剧烈疼痛（含头痛）；身体某部位移动困难；肤色泛白、出汗或水肿 → 内脏出血嫌疑。
4. **区分"瘀点/紫癜"与普通疹**：按压不褪色的针尖样小红点=瘀点，更大的凸起不变白=紫癜，需就医。
5. **按伴随症状分流**：便中带血 → 可能肛裂/肠胃炎/肠套叠/息肉；针尖瘀点或大块紫癜+近期生病 → 可能特发性血小板减少；腿上脚踝不明瘀斑+胃痛+关节肿大一触痛 → 可能过敏性紫癜；从托儿所/保姆回家多处奇怪瘀斑+胆小孤僻 → 考虑受虐。
6. **记录并保存证据**：拍下瘀斑位置、数量、出现时间、孩子状态，供医生判断，必要时作为受虐评估依据。
7. **别自行处理出血性疾病**：疑似凝血问题不擅自用药，交由医生检查（验血）。

## 备选计策

- **拍照+记录**（适用：反复出现瘀斑的家庭）：记录能帮医生判断是良性磕碰还是病理，也便于追踪变化。
- **验血**（适用：疑似血小板/凝血问题）：医生会安排血液测试（血常规、凝血功能等）来确认。
- **联系托育机构核实**（适用：怀疑来源不明的家庭）：弄清瘀斑可能的发生场景，作为评估线索。
- **受虐疑似时通知相关部门**（适用：确认受虐）：书明确若确认孩子受到虐待，要通知相关部门，孩子会受到保护。

## 决策规则

- **什么算"看"档**：小腿等暴露处、能对上外伤、孩子健康 → 不治疗，观察。
- **什么算"叫"档**：不明原因/不寻常部位瘀斑、便血、易瘀斑伴苍白疲惫、瘀点紫癜 → 打电话给儿科医生，预约检查。
- **什么算"急"档**：流血不止、意识改变、剧痛、肢体不能动、面色泛白出汗 → 马上送医；瘀斑面积不断变大伴呕吐/发热/昏睡 → 立刻就医。
- **换路线信号**：瘀斑数量增多、范围变大、出现新部位、伴发热 —> 立即升级就医。

## 反模式

- **把"腿上炎症性瘀斑"和"躯干不明瘀斑"一视同仁**：前者多为正常磕碰，后者需要评估。
- **用"上火/血热/缺维生素"解释针尖瘀点或大块紫癜**：可能掩盖血小板或白血病问题（p42-43）。
- **忽略"便血"/"黏膜长期流血"**：可能是肛裂、息肉、肠套叠，或出血性疾病。
- **对孩子的瘀斑来源不追问**：书明确不要忽视虐待可能，尤其孩子不愿解释时（p42-43）。
- **自行用止血药/补剂**：可能干扰检查与判断。
- **只看瘀斑不看整体**：要结合孩子是否有苍白、疲惫、发热、精神差等全身表现。

## 边界

- 本条管瘀斑与出血的识别分流；具体病因诊断（血小板减少、白血病、凝血因子缺乏等）由医生完成。
- "儿童虐待"的认定不由家长或本条目下结论，仅按原书提示"不要忽视可能"，实际由医生与相关部门处理（p42-43）。
- 有明确凝血障碍、血小板疾病、近期血液病治疗史的孩子，出血处置遵自己的专科医生。
- 头部外伤引起的出血/瘀斑走 aaph-head-injury；单纯鼻出血走 aaph-nosebleed。

## 就医红线

**立即就医/马上送医（tier-1，p42-43，2026-10-04 校准）**：
- **无法解释的瘀斑**，或在不寻常部位（臀/脸/肩/背）出现瘀斑
- **大小便带血**
- **小伤口引起长时间流血**；黏膜上的小伤口持续流血几小时或几天
- **很容易瘀斑并伴肤色异常苍白、疲惫**（可能全身性疾病/白血病）
- **大量针尖大小瘀点，或大块紫癜，且近期生病**（可能血小板减少）
- **瘀斑面积不断变大，伴呕吐、发热、昏昏欲睡、精神恍惚、脾气暴躁** → 可能严重细菌感染或受虐
- 伤口经紧急处理后**仍流血不止**，或伴**意识水平下降、剧烈疼痛、某部位移动困难、肤色泛白、出汗或水肿** → 内脏出血嫌疑，马上送医
- **多处或形状奇怪的瘀斑，孩子胆小孤僻、不愿解释来源** → 虐待可能，联系医生并由相关部门介入
- 月经量很大

## 代价与风险提示

- 为"不明瘀斑"做检查多半虚惊一场，但这是排除血小板/白血病等严重问题的必要成本。
- 面对"受虐可能"是沉重的心理负担，但忽略它意味着孩子可能持续受伤害。
- 记录与追踪瘀斑需要细心和时间，随意观察容易漏掉"数量增多/范围变大"的趋势。
- 未确诊出血性疾病前不使用止血药/补剂，孩子要带着症状等待检查。
