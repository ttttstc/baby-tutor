# 疑似骨折别搬动孩子——听到断裂声/局部变形/不能承重/剧痛就是信号；必须移动时先垫软布、再用尺子杂志固定好

## 解决的问题

孩子跑跳时摔了一跤，胳膊或腿很快肿起来，你一碰他就哭得撕心裂肺，甚至那条腿根本不敢承重站。这时候家长常常本能地想"赶紧抱起来送医院"——但原书明确提醒：**如果孩子疑似骨折，不要移动孩子**。不当的搬动可能造成更大的痛苦、更严重的伤害。

骨折是儿童常见的意外伤害。判断其实有章可循，而现场处理的核心不是"复位"，是"别乱动 + 正确固定 + 尽快就医"。

## 核心判断

**骨折的判断：一般受伤时会听到断裂的声音，之后局部可能出现形态异常，不能活动或无法承重，并有非常剧烈的疼痛、孩子持续哭闹。（这些症状也可能是脱臼导致的。）处理上：疑似骨折不要移动孩子，等候急救医生；必须移动时，先在骨折部位垫上软布保护皮肤、确保不阻碍血液循环，再用尺子/杂志/书籍等固定；没有合适物品时可用自己的手臂夹住伤肢。紧急处理后尽快就医。**

## 机制

**为什么不能移动**（p551）：疑似骨折时随意移动会**造成更大的痛苦、更严重的伤害**——尤其可能让断端移位、伤及血管神经。所以首选是等候急救。

**为什么固定前要垫软布、要顾血液循环**（p551）：直接固定硬物会压迫皮肤；固定过紧会**阻碍血液循环**。所以"垫软布保护皮肤 + 确保血液循环不受阻"是固定前的两个要点。

**为什么"断裂声 + 形态异常 + 不能承重 + 剧痛"成套出现**（p550）：这些是原书给出的骨折判断线索。但要注意：**同样症状也可能是脱臼**（p550）——所以家长不必自行确诊，按"疑似骨折"的保守处理即可。

## 诊断信号

**月龄判断**：本条覆盖 0-6 岁全段。会走、好动的幼儿期高发。

用本条的处境：
- 孩子摔倒/磕碰后，受伤部位迅速肿胀
- 受伤时听到断裂的声音
- 局部形态异常、不能活动或无法承重
- 孩子剧烈疼痛、持续哭闹
- 无法区分是骨折还是脱臼 → 仍按骨折保守处理

## 正常范围与个体差异

- 无断裂声、能活动承重、疼痛可控，多为轻伤，可观察
- 出现断裂声/形态异常/不能承重/剧痛，按疑似骨折处理
- 同样症状也可能是脱臼（见 cui-bk-dislocation-pulled-elbow），不由家长确诊
- 经医生妥善处理，骨折经过一段时间休养可以愈合（p551）

## 实操方法

1. **疑似骨折 → 不要移动孩子**：以免造成更大痛苦和更严重的伤害，**等候急救医生到来**。
2. **必须移动时先垫软布**：在骨折部位垫上软布**保护皮肤**，**确保不会阻碍血液循环**。
3. **固定伤肢**：用**尺子、杂志、书籍**等物品将受伤部位**固定好**。
4. **没有固定物时**：家长可**用自己的手臂夹住伤肢**临时固定。
5. **尽快就医**：先行紧急处理后，**尽快带孩子就医**。
6. **不确定就保守处理**：分不清骨折还是脱臼时，按"别乱动 + 固定 + 就医"处理。

## 备选计策

- **"原地等候急救"**：伤情重、无法安全搬运时首选——适用"能叫到急救"的家庭
- **"就地取材固定"**：尺子/杂志/书籍做夹板——适用"必须自行送医"的家庭
- **"手臂夹住伤肢"**：无固定物时的应急——适用"手边无物、需即刻移动"的家庭

## 决策规则

- **怎么算"疑似骨折"**：断裂声 / 形态异常 / 不能活动承重 / 剧痛持续哭闹，任一 → 按疑似骨折处理
- **坚持多久再评估**：疑似即固定并就医，不在家等待观察
- **出现什么信号换法/就医**：出现固定后肢端发凉、发紫、麻木（可能血液循环受阻）→ 调整/立即就医
- **何时停止自行处理**：伤情重、无法安全搬运 → 等候急救

## 反模式

- **马上抱起/背起疑似骨折的孩子送医**：断端移位、加重伤害
- **固定时不垫软布、绑得过紧**：压迫皮肤、阻碍血液循环
- **自行复位/揉捏肿胀处**：加重损伤
- **把"能活动一点"当作没骨折**：不全骨折也可能有活动度
- **只观察不就医**：确诊与处理需医生
- **把脱臼当成骨折反复固定**：两者症状相似，交由医生鉴别
- **固定后不查肢端循环**：应观察发凉/发紫/麻木

## 边界

- 本条为疑似骨折的现场处理；具体诊断、复位、固定由医生完成
- 若伴开放性伤口、大出血，先止血包扎再固定（见 cui-bk-cut-puncture-wound）
- 若伴意识/呼吸异常，优先按急救处理（见 cui-bk-cpr）
- 有骨质疏松/骨骼疾病的孩子遵专科医嘱

## 就医红线

**出现以下任一情况，立即就医/等候急救**（p550-551，卫健委 2022 交叉，2026-10-04 核对）：

- **受伤时听到断裂的声音**——按疑似骨折处理，就医
- **局部形态异常**——就医
- **不能活动或无法承重**——就医
- **剧烈疼痛、持续哭闹**——就医
- **固定后肢端发凉、发紫、麻木**——立即就诊（可能血液循环受阻）
- **分不清骨折还是脱臼**——就医

## 代价与风险提示

- 要忍住"马上抱起送医院"的本能，可能因此更煎熬
- 必须移动时要找软布、固定物，事发时未必手边就有
- 固定手法有讲究，绑松了起不到固定、绑紧了阻碍循环
- 伤情重时等候急救而非自行搬运，需要克制与判断
- 固定后要盯肢端循环，一人既要照护孩子又要观察，容易顾此失彼
