# 中耳炎是幼儿最常见感染之一，2 岁前多数孩子至少得过一次——AAP 现行立场是"能等则等"：2 岁以上、轻症（48 小时内起病）先观察 48-72 小时、按需止痛；但"剧痛 + 发热≥102.2℉（39℃）且已病 48 小时""6-23 月双耳感染""恶化或 48-72 小时无改善""耳后疼痛 + 耳朵外翘"要联系医生

## 解决的问题

孩子先感冒了两天，然后半夜哭着抓耳朵、还有点发烧。你判断"是不是中耳炎"，又纠结要不要吃抗生素——听说医生现在常常"不给药、先观察"，可你怕耽误。

这条要回答的正是这个具体场景。AAP 指出：**中耳炎（otitis media，中耳发炎）是幼儿常见感染**，**多数幼儿 2 岁前至少得过一次**；**2 岁及以下更常见**，因为他们的免疫系统还不成熟、又接触大量病菌；此外幼儿**细小的咽鼓管**（连接中耳与咽部的通道）让感染物容易停留或上达中耳。好消息是——**随着孩子长大、咽鼓管成熟，这类病会逐渐减少**。

## 核心判断

**AAP 现行立场已经从"所有中耳炎都用抗生素"转向"分级处理、能等则等"：2 岁以上、轻症（症状在 48 小时内出现）先采用"观察等待（wait-and-see）"、按需用对乙酰氨基酚或布洛芬止痛**。但下面这些要用药或就医：**重度（剧痛 + 发热 ≥102.2℉/39℃、且已病至少 48 小时）→ 抗生素**；**6-23 个月、双耳感染（即便起病 <48 小时、热 <102.2℉）→ 抗生素**；**恶化或 48-72 小时无改善 → 抗生素**。

两条预防要点：**别让宝宝躺着独自喝完奶瓶**（配方奶等液体可经咽鼓管上流、为细菌制造温床）；**避免二手烟**（会增加上呼吸道感染、支气管炎、中耳炎风险）。

## 机制

- **为什么幼儿易得**：免疫未成熟 + **咽鼓管又短又平**，感染物易滞留或上达中耳；功能受损还会改变耳内压力，**导致中耳积液、鼓膜膨出**。
- **为什么常先有感冒**：还不会说话的婴幼儿，中耳炎通常**先有上呼吸道感染**，其"前驱信号"包括夜间哭闹、白天烦躁、发热（≥100.4℉/38℃）、食欲下降。
- **为什么婴儿吃奶会哭**：吸吮会改变耳内压力，**耳感染的婴儿吃奶时常因疼痛而哭**。
- **为什么要控制抗生素**：儿科医生担心**抗生素过度使用与细菌耐药**上升有关，因此修订了中耳炎的治疗：把抗生素留给真正需要的情况，减少非必要治疗。若不必要地用药，新的耐药菌株可能出现，抗生素最终可能失效。
- **中耳积液（otitis media with effusion）**：急性中耳炎症状消退后，耳内常残留液体，可**持续数月、多数自行消失**，随后听力恢复正常。
- **游泳耳不是中耳炎**：**游泳耳（otitis externa）是外耳道（从外耳到鼓膜那段）的感染**，属另一种病。
- **证据强度**：以上为 AAP 机构性口径（tier-1）；wait-and-see 为 AAP 现行推荐。

## 诊断信号

适用窗口：以 6 个月-6 岁幼儿/学龄前儿童为主。

用这条的处境特征：
- 先有**感冒**（流涕、咳嗽、轻热或结膜炎），随后耳痛。
- 婴儿**夜间哭、吃奶时更哭**、白天烦躁、发热、食欲差。
- 大孩子**拉/抓耳朵、会说耳朵疼**。
- 耳朵**流液、听力变差**。
- **反复发作**，或**耳后疼痛、耳朵外翘**。

## 正常范围与个体差异

- **普遍性**：多数幼儿 2 岁前至少一次中耳炎；2 岁以下更常见。
- **自限与积液**：急性症状消退后耳内积液可**持续数月、多数自行消失**。
- **反复中耳炎定义**（AAP）：**6 个月内发生 3 次**，或**1 年内 4 次（其中 1 次在前 6 个月）**。
- **置管**：反复中耳炎伴**听力损失征象**时，医生可能建议**鼓膜置管（tympanostomy tubes）**——把细管植入鼓膜帮助防止积液。**AAP 不推荐用预防性抗生素**减少复发（效果不佳）。
- **随龄改善**：反复中耳炎的倾向**随孩子长大而减少**。
- **个体差异**：年龄、单/双耳、症状严重度、病程长短决定是否用药。

## 实操方法

1. **判断严重度与病程**：是"轻度、48 小时内起病"还是"剧痛 + 高热 + 已病 ≥48 小时"？
2. **遵 AAP 分级处理**：
   - **>2 岁、轻症、<48 小时** → **观察等待**（wait-and-see），**按需止痛**。
   - **重度（剧痛 + 发热 ≥102.2℉/39℃ + 已病 ≥48 小时）** → 抗生素。
   - **6-23 月、双耳感染** → 抗生素（即便 <48 小时、热 <102.2℉）。
   - **恶化或 48-72 小时无改善** → 抗生素。
3. **止痛**：耳上放**温垫**、按医嘱用**对乙酰氨基酚或布洛芬**——这仍很重要，帮孩子撑过免疫系统对抗感染的过程。
4. **观察窗口**：观察等待也要**在 48-72 小时内密切盯**，恶化就升级。
5. **外耳道炎（游泳耳）**：耳朵疼、拉耳垂更痛、有分泌物、近期常游泳/泡水 → 联系医生，可能需滴耳液。
6. **别躺着喂奶**：避免宝宝躺着独自喝完奶瓶。
7. **避二手烟**：家庭戒烟、至少禁室内吸烟。
8. **反复者**：与医生讨论是否需置管。
9. **按红线就医**：见红线。

## 备选计策

- **观察等待 + 止痛（适合 >2 岁轻症）**：减少不必要抗生素。
- **抗生素（适合重度/双耳/婴幼儿/无改善）**：按医生指征。
- **鼓膜置管（适合反复 + 听力损失）**：手术防积液。
- **预防组合（适合所有家庭）**：别躺喂、避二手烟。

## 决策规则

- **怎么算有效**：48-72 小时内疼痛与发热减轻、听力恢复——方向对。
- **坚持多久再评估**：以 **48-72 小时**为观察节点——无改善或恶化即升级。
- **出现什么信号换下一条**：耳后疼痛 + 耳朵外翘、眼睑红肿热痛 + 发热、耳道流液、高热、听力下降 → 立即联系。
- **用药纪律**：抗生素按医生指征，不自行服用。

## 反模式

- **所有中耳炎都要抗生素**：AAP 已改为分级处理。
- **"观察等待"却不盯着**：48-72 小时内必须能升级。
- **不给止痛**：中耳炎疼痛明显，止痛是必要环节。
- **躺着喂奶**：增加中耳炎风险。
- **二手烟暴露**：增加感染风险。
- **把游泳耳当中耳炎**：一个是外耳道、一个是中耳，处理不同。
- **反复中耳炎只靠预防性抗生素**：AAP 不推荐（效果不佳）。

## 边界

- **性质边界**：本条管中耳炎的识别与分级处理；外耳道炎、耳外伤、异物另论。
- **月龄边界**：越小（6-23 月）越倾向抗生素；2 岁以下更常见。
- **共病**：中耳积液、鼻窦炎、腺样体问题可与中耳炎并存。
- **不替代诊断**：需医生检查鼓膜判断。

## 就医红线

（tier-1；数值与征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

**联系医生（孩子耳痛并伴以下）：**
- **耳朵流出液体（discharge）**。
- **耳朵周围肿胀**。
- **头痛**。
- **发热 ≥102.2℉（39℃）**。
- **头晕**。
- **听力下降**。
- **眼睛周围/眼睑红肿热痛、难以睁眼、流泪、发热**（眶周蜂窝织炎）→ **立即联系**（未治疗可致严重、持久损害）。
- **耳后疼痛、耳朵向外翘起**（乳突炎）→ **立即联系**。
- **耳内异物** → 别掏，联系医生取出。
- **耳内昆虫** → 多数会自行爬出；否则联系医生。
- **游泳耳（外耳道炎）** → 联系医生，可能需滴耳液。

**用药指征（由医生判断）：**
- 重度（剧痛 + 发热 ≥102.2℉ + 已病 ≥48 小时）→ 抗生素。
- 6-23 月、双耳感染 → 抗生素。
- 恶化或 48-72 小时无改善 → 抗生素。

## 代价与风险提示

- **"观察等待"的看护成本**：家长要在 48-72 小时内密切盯，随时准备就医。
- **反复发作的手术成本**：置管需手术与随访。
- **预防的长期功课**：别躺喂、避二手烟要长期坚持。
- **抗生素观念冲突**：要接受"能等则等"的新立场，而非"有感染就吃药"。
