# 孩子磕到头，先看他"会不会动、清不清醒、耳鼻流不流东西"——失去意识、抽搐、肢体无力、耳鼻流液或流血、言行异常打急救；困倦、很难唤醒、持续头痛或呕吐打电话给医生；没有这些，在家冷敷并观察 24-48 小时

## 解决的问题

孩子从沙发上翻下来，后脑勺磕在地板上，"咚"的一声，你心都揪起来了。他哭了两声就不哭了，还能自己站起来。你抱着他反复问"疼不疼、认识妈妈吗"，又想马上冲医院做个 CT，又怕白折腾。老人说"孩子摔摔长长，睡一觉就好"，可你不敢让他睡——万一睡着就没醒过来呢？

原书第四章"基础急救·头部受伤"给了一个很实用的定心丸：**儿童尤其幼儿头部受伤几乎无法避免，但受伤程度往往没有你担心的那么严重，大多数情况下都是轻伤、不会有严重问题**。真正要做的，是**弄清这次受伤是需要医学关注，还是只需大人的安抚**。

## 核心判断

**孩子磕到头，判断要不要就医看两组信号：出现"失去意识、抽搐、肌肉无力或反应迟钝、无法移动某个部位、耳朵或鼻腔有分泌物或流血、言行异常" → 拨打急救电话；出现"受伤后困倦、很难唤醒、持续头痛或呕吐" → 打电话给儿科医生。** 若都没有，孩子清醒、能走能说能吃，冷敷缓解水肿并在 **24-48 小时**内仔细观察。另外：**可疑头部严重撞击，即使当时意识清醒，但出现记忆严重丧失、无法辨认方向、语音改变、视力变化、恶心反胃** → 也要拨打急救或打电话给医生。

## 机制

- **为什么大多数头部外伤是轻伤**：孩子好动、头相对身体较重，磕碰几乎无法避免；但多数撞击能量有限，不伤及脑组织。
- **为什么"失去意识/抽搐/肢体无力/耳鼻流液"是重症信号**：这些提示可能有颅内出血、颅底骨折（耳鼻流液/流血）或脑实质受损，属于急救范畴。
- **为什么"困倦/难唤醒/持续头痛呕吐"要打电话给医生**：头部受伤后出现嗜睡、唤醒困难、持续头痛或呕吐，提示颅内压可能升高，需要医生评估。
- **为什么"意识清醒但记忆丧失/看错方向/语音改变/视力变化/恶心"也要就诊**：这组是脑震荡的表现；脑震荡指大脑功能受到暂时或永久影响，需要儿科医生仔细评估和监测，**确保在孩子恢复所有活动（包括上学和体育活动）之前症状完全消除**。
- **为什么"24-48 小时"是观察期**：颅内出血等症状可能在受伤后数小时才显现，书要求在 24-48 小时内仔细观察有无更严重创伤的迹象。
- **为什么"怀疑头颈肩严重受伤时不要移动"**：错误搬动可能造成进一步伤害（脊髓损伤），此时应叫救护车。

## 诊断信号

**本条适用于 0-6 岁所有头部撞击场景，越小的婴儿越应谨慎**。用这条的处境特征：孩子从床上/沙发上/婴儿车上摔下来；磕后想睡不确定要不要叫醒；磕后呕吐；耳朵/鼻子流血或流液；家里纠结要不要做检查。

## 正常范围与个体差异

- 儿童尤其幼儿头部受伤几乎无法避免，大多数是轻伤、不会有严重问题。
- 轻伤表现：哭闹后能安静、能正常活动、无呕吐、意识清醒、能互动。
- 需警惕：失去意识、抽搐、肢体无力、耳鼻流液/流血、言行异常、困倦难唤醒、持续头痛或呕吐。
- 脑震荡：即使意识清醒也可能发生，表现为记忆丧失、方向感丧失、语音/视力改变、恶心反胃。
- 个体差异：婴儿不会表达，摔伤后异常哭闹、嗜睡、拒奶都要提高警惕。

## 实操方法

1. **立刻扫"打急救电话"清单**：失去意识；抽搐；肌肉无力、反应迟钝或无法移动某个部位；耳朵或鼻腔有分泌物或流血；言行异常。任一命中 → 拨打急救电话。
2. **扫"打电话给医生"清单**：困倦；很难唤醒；持续头痛或呕吐。任一命中 → 打电话给儿科医生。
3. **扫脑震荡信号**：意识清醒但记忆严重丧失、无法辨认方向、语音改变、视力变化、恶心反胃 → 拨打急救或打电话给医生。
4. **无危险信号时家庭处理**：对外伤消毒、包扎，用冷敷缓解水肿；在孩子抱怨头痛时可按需使用对乙酰氨基酚或布洛芬（剂量遵医嘱/说明书），并持续观察 24-48 小时。
5. **怀疑头/颈/肩严重创伤时不要移动**：不要擅自抱起搬动，叫救护车送医。
6. **观察期重点盯**：意识（能否叫醒、互动）、活动（四肢是否对称有力）、呕吐、头痛、耳鼻有无流液流血。
7. **防再次受伤**：恢复活动（尤其复课和体育）前确保症状完全消除，由医生评估。

## 备选计策

- **叫醒检查**（适用：孩子磕后想睡、家长不放心）：观察期内可定时轻唤确认能被唤醒，若很难唤醒或反应异常 → 就医。
- **就医带记录**（适用：摔伤经过记不清的家庭）：写下摔的高度、着地部位、当时的反应、之后每次呕吐/嗜睡的时间，给医生参考。
- **居家防伤布置**（适用：反复摔头的家庭）：婴儿设施系安全带、换衣台托后脑勺、不用学步车、装楼梯门与窗户护栏、家具固定，见 safe-aap-injury-proofing。
- **运动戴头盔 + 安全座椅后座**（适用：大孩子）：球类运动戴合适头盔、乘车坐安全座椅后座并系好。

## 决策规则

- **什么算"看"档**：无急救/医生信号，孩子清醒能互动 → 冷敷 + 观察 24-48 小时。
- **什么算"叫"档**：困倦、难唤醒、持续头痛或呕吐、或脑震荡信号 → 当天打电话给医生评估。
- **什么算"急"档**：见下节红线。
- **换路线信号**：观察期内出现任一新信号、或呕吐/嗜睡加重 → 立刻升级就医。

## 反模式

- **磕完头马上"抱起猛摇/晃"**：怀疑头颈肩严重创伤时移动会造成进一步伤害。
- **磕后一律让孩子睡、不叫醒**：若为异常嗜睡、难唤醒，可能延误就医；观察期应能唤醒。
- **把脑震荡当"没破皮就没事"**：脑震荡可无外伤却影响功能，需评估且恢复活动前症状要完全消除。
- **忽视耳鼻流液/流血**：可能提示颅底损伤，属急救。
- **无危险信号也坚持做 CT**：多数为轻伤，是否影像由医生定；过度检查非必要。
- **症状未消就返校/复课体育**：脑震荡需症状完全消除后经医生评估再恢复。

## 边界

- 本条管头部撞击后的观察与就医分级；是否脑震荡、是否需要影像由医生评估。
- 有凝血障碍、近期头部手术、抗凝治疗的孩子阈值更低，撞头即应就医。
- 婴儿头外伤表现不典型，异常哭闹/嗜睡/拒奶/前囟膨隆都要就医，不套用大孩子的自述信号。
- 头部外伤伴颈椎/脊柱受伤嫌疑时，处置以"不移动+叫救护车"优先。

## 就医红线

**拨打急救电话（tier-1，p228，2026-10-04 校准）**：
- **失去意识**
- **抽搐**
- **肌肉无力、反应迟钝，或无法移动某个部位**
- **耳朵或鼻腔有分泌物或流血**
- **言行异常**
- 怀疑头部、脖子、肩膀受到严重创伤 → **不要移动，叫救护车**

**打电话给儿科医生**：
- **困倦**；**很难唤醒**
- **持续头痛或呕吐**
- 头部受伤后（即使意识清醒）出现**记忆严重丧失、无法辨认方向、语音改变、视力变化、恶心反胃**（脑震荡嫌疑）

**居家观察**：无上述信号者，冷敷 + 消毒包扎，**24-48 小时**内仔细观察有无更严重创伤迹象

## 代价与风险提示

- "观察 24-48 小时"意味着不能马上安心，要持续盯两组信号，对家长是心理消耗。
- 学会区分"正常犯困"与"危险嗜睡/难唤醒"需要经验，拿不准时应就医。
- 怀疑头颈肩重伤时"不移动、叫救护车"和"赶紧抱起"的直觉相反，需要事先知道才做得到。
- 一些就医最后是"轻伤回家观察"，但这一趟是排除颅内损伤的必要成本。
