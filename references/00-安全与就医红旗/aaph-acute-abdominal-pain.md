# 孩子肚子疼，最怕的是"3 小时不好转、从肚脐转移到右下腹、吐绿水"——这三种是阑尾炎/肠梗阻的信号，立刻打电话就医；单纯腹痛伴腹泻呕吐多是肠胃炎，可先在家补液观察

## 解决的问题

孩子捂着肚子说疼，没一会儿吐了一口，全家人围上来：奶奶说饿着了、吃点东西就好，爷爷说是不是吃坏了、拉一拉就没事，你伴侣已经去拿车钥匙。你不敢拍板——万一只是肠胃炎，半夜跑一趟急诊白折腾；万一是阑尾炎，拖到天亮可能就穿孔了。你手里没有任何一把尺子，只有"孩子疼得厉害不厉害"这一个模糊的感觉。

原书第 9 章"急性腹痛"给的正是这把尺子。它先讲清楚一件事：急性腹痛**来势汹汹**，而且原因从完全良性到会危及生命都有（p20）。所以关键不是猜病因，而是先认出"必须马上就医"的那几张面孔——阑尾炎、肠梗阻、疝气/睾丸扭转——其余的按肠胃炎、便秘、压力性腹痛分头处理。

## 核心判断

**孩子腹痛，先看"是不是急腹症"：持续 3 小时以上不好转、疼痛从肚脐转移到右下腹、呕吐物呈绿色、腹股沟或睾丸肿痛、1 岁以下婴儿异常痛苦哭闹——出现任一条立刻打电话就医，且在检查前不要给孩子吃任何东西；如果只是肚子疼伴腹泻呕吐、孩子还能喝水、疼一阵能缓，多半是肠胃炎，可先补液在家观察，48 小时不好转再就医。** 分水岭是"持续时间+疼痛走向+呕吐物颜色"，不是"孩子哭得多凶"。

## 机制

- **为什么阑尾炎要抢时间**：阑尾是大肠与小肠交界处的袋状物，发炎后必须尽快切除，否则会破裂、引发在腹腔扩散的腹膜炎（一种严重感染）；术后几乎都能很快康复、不留后遗症（p20）。所以"早发现"是阑尾炎唯一的安全边界。
- **为什么"脐周→右下腹"是关键信号**：阑尾位于右下腹，发炎早期疼痛常先出现在肚脐周围，之后转移并固定到右下腹（p21 决策表）——这个"转移"是家长在家就能捕捉的线索。
- **为什么"持续 3 小时"是阈值**：良性的肠胃炎/功能性腹痛多在一阵后缓解、随呕吐腹泻排出而减轻；阑尾炎、肠梗阻的疼痛会**持续或加重**，不会自行好转。书把"3 小时"作为"该打电话给儿科医生"的判定线（p20-21）。
- **为什么绿色呕吐物危险**：呕吐物呈绿色提示胆汁反流，可能意味着肠梗阻（肠内容物无法通过），书把"呕吐物带绿色"直接列为肠梗阻信号，要求立刻打电话且检查前禁食（p20-21）。
- **为什么疝气/睾丸肿痛要马上**：腹股沟疝嵌顿会阻断肠道供血、睾丸扭转会切断睾丸血供，都是外科急症，书要求马上住院（p21）。
- **为什么不能先吃止痛药**：镇痛药会掩盖疼痛的位置与程度，让医生难以判断是不是阑尾炎；书明确"未经儿科医生检查同意，不要给腹痛孩子服用镇痛药"（p20）。

## 诊断信号

**本条适用于 0-6 岁所有腹痛场景**。1 岁以下婴儿不会说疼，表现为异常哭声、把腿屈向肚子（p20）；会说话的孩子能指出位置与走向。用这条的处境特征：孩子喊肚子疼但你分不清轻重；疼的位置在变；伴随呕吐或腹泻；家里对"去不去医院"分歧；孩子不愿让你碰肚子。

## 正常范围与个体差异

- 大多数腹痛不需要特殊治疗、会自行消失（p20）。
- 良性走向：疼一阵缓解、随呕吐/排便减轻、孩子整体状态尚可。
- 需要警惕的走向：持续不缓解或加重、位置转移固定、伴绿色呕吐或血便、伴高热或腹股沟肿胀。
- 慢性腹痛（反复持续 1 周以上）多为功能性，胃痛常在 1-2 小时内消失，只要成长和体检正常、无特定部位、无相关症状，通常不是需要马上治疗的疾病（p22）。
- 4 岁以上孩子反复抱怨腹痛而查不出疾病，常与压力相关（p21-22）。

## 实操方法

1. **计时并记录疼痛走向**：问清"从什么时候开始疼""最开始疼在哪、现在疼在哪"。若从肚脐转移到右下腹 → 高警示（p21）。
2. **扫"立刻打电话"清单**（p20）：1 岁以下婴儿很痛苦（异常哭声、把腿屈向肚子）；持续腹痛 ≥3 小时；腹股沟或睾丸肿痛；呕吐/腹泻 3 小时后仍持续腹痛；呕吐物绿色或粪便/呕吐物带血。任一命中 → 立即打电话给儿科医生。
3. **检查前禁食**：疑似阑尾炎或肠梗阻时，在医生检查前不给孩子吃任何东西（p21）。
4. **不给止痛药**：未经医生检查同意不擅自服镇痛药（p20）。
5. **若判断是肠胃炎**：6 个月以下继续母乳或配方奶；大一些的孩子给电解质溶液 + 少量正常饮食（p21）；用 safe-aap-diarrhea-ors 的口服补液法。
6. **设复评点**：症状 48 小时未改善 → 咨询儿科医生（p21）。
7. **按伴随信号分流**：伴高热/尿床/尿痛/尿有气味 → 可能尿路感染；腹痛与便秘相关 → 便秘；3 岁以上伴喉咙痛 → 可能链球菌咽炎（p21）。这些走"叫"档由医生定夺。

## 备选计策

- **"禁食观察"**（适用：怀疑阑尾炎、等待就医的家庭）：检查前只给清水，不给食物，避免加重或干扰判断（p20-21）。
- **"喝水试验"**（适用：想区分功能性腹痛与外科腹痛的家庭）：书指出腹痛孩子若想喝水，可提供足够多清水（p20）；能安稳喝水、疼痛缓解倾向良性，但不能用它排除外科情况。
- **急诊/住院**（适用：确诊阑尾炎或绞窄疝的家庭）：一经确诊可能需要住院、进一步检查甚至手术（p21）。
- **腹痛日记**（适用：反复发作的慢性腹痛家庭）：记时间、诱因、部位、程度、伴随症状，帮医生找触发原因（p22-23）。

## 决策规则

- **什么算"看"档**：单次腹痛、伴腹泻呕吐、疼一阵能缓、孩子能喝水、精神尚可 → 在家补液观察。
- **什么算"叫"档**：腹痛持续 3 小时以上、或伴尿路感染嫌疑、或与便秘相关且突发 → 当天打电话给儿科医生。
- **什么算"急"档**：见下节红线。
- **换路线信号**：观察中出现"持续 3 小时不好转""疼痛转移右下腹""吐绿色""加发热""腹股沟肿" → 立刻升级就医；48 小时未改善 → 从在家观察升级为咨询医生。

## 反模式

- **先喂止痛/退烧药再观察**：掩盖症状，妨碍判断阑尾炎（p20）。
- **强迫腹痛的孩子吃东西**：可能加重外科情况，且干扰"检查前禁食"（p20）。
- **拿"饿了/吃坏了"解释所有腹痛**：漏掉阑尾炎、肠梗阻、嵌顿疝这些外科急症。
- **只盯哭得凶不凶**：良性腹痛也可能哭得厉害，外科腹痛也可能一时安静；要看持续时间、走向与呕吐物颜色。
- **把"吐了绿的"当普通吐奶**：绿色呕吐物是肠梗阻信号，必须立刻就医（p21）。
- **腹痛伴腹股沟/睾丸肿痛还当肚子问题看**：那是嵌顿疝/睾丸扭转，需要马上住院（p21）。

## 边界

- 本条管"肚子疼"的通用分诊；肠套叠的"阵发性剧烈哭闹+果酱样血便"走 aap-safe-intussusception，发热的分级走 safe-aap-fever-ladder。
- 慢性/反复腹痛（>1 周）多为功能性，但持续加重、体重减轻、便血、痛醒的情况需就医评估（p22-23）。
- 有疝气、既往腹部手术史、免疫缺陷的孩子阈值更低，遵自己的儿科医生。
- 新生儿期的"腹痛"多表现为哭闹，需与肠绞痛、肠套叠区分，月龄越小越倾向早看。

## 就医红线

**立即打电话给儿科医生/就医（tier-1，p20-21，2026-10-04 校准）**：
- 1 岁以下婴儿很痛苦：异常哭声、把腿屈向肚子
- 孩子持续腹痛 **3 小时或以上**
- **腹股沟或睾丸肿胀疼痛**（嵌顿疝/睾丸扭转）→ 马上住院
- 呕吐或腹泻 3 小时后仍持续腹痛
- **呕吐物呈绿色**，或粪便/呕吐物带血 → 肠梗阻嫌疑，立刻打电话，检查前禁食
- 腹痛从**肚脐转移并固定到右下腹**（阑尾炎嫌疑）→ 检查前禁食
- 腹痛伴体温 >38.3℃ + 尿床/尿频/尿痛/尿有气味 → 尿路感染嫌疑
- 进入"急"档的通用信号（意识改变、呼吸困难、发绀等）见 aaph-symptom-triage

## 代价与风险提示

- "3 小时"窗口要求你计时并盯走向，比"疼得厉害就去"多一道纪律。
- 检查前禁食要对抗孩子的饥饿哭闹和老人"喂点东西压压"的坚持。
- 不擅自用止痛药，孩子要带着疼等待就医——用忍耐换判断准确。
- 走家庭观察若误判，可能延误阑尾炎；因此观察必须配复评点，一旦升级信号出现立即就医。
