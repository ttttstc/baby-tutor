# 什么时候能回托班——通用规则是"退烧就能回"；但疱疹性龈口炎要等病变愈合、水痘要等全部结痂(约1周)、细菌性结膜炎/脓疱疮/癣要用药24小时、疥疮/头虱/蛲虫要治1次

## 解决的问题

宝宝烧退了、精神也回来了，你准备送他回托班，却被老师拦下："再观察一天""大便成形了吗""眼睛还红不红。"你一边觉得孩子明明好了，一边又怕传染给别人、怕给老师添麻烦。到底什么时候能回？

其实返托有相对统一的标准，核心就一句话：**有发热的，退烧就能回；没有发热但持续时间长、或有皮损/腹泻/寄生虫的，要看各自的"清除标准"。**

## 核心判断

**通用规则：孩子退烧（体温恢复正常）就可以回托班/游戏小组，因为发热期是多数传染病传染性最强的时候。** 但有几类例外要按疾病各自标准：**疱疹性龈口炎**等口腔病变愈合、**水痘**等全部皮疹结痂（约 1 周）、**细菌性结膜炎/脓疱疮/癣**用药满 24 小时、**腹泻类**（肠胃炎/食物中毒/贾第虫）等大便成形、**疥疮/头虱/蛲虫**完成首次治疗即可返托。判断依据是**是否还有传染性**，不是"好得透不透"。

## 机制

- **为什么"退烧"是通用卡点**：发热说明免疫系统正在与病原体激烈交战、病原体正在复制，传染性最强。退烧后传染性显著下降，这也是"有发热默认有传染性"这条通行的由来。
- **为什么各病标准不同**：传染途径不同——呼吸道病（感冒、流感、哮吼、手足口）主要靠飞沫，退烧即大幅降低风险；而水痘、疱疹靠直接接触皮损/唾液，必须等病变失去传染性（结痂/愈合）；腹泻类靠粪便排出，要等大便成形；寄生虫类（疥疮、头虱、蛲虫）要在"首次治疗"后才停止传播。
- **为什么有的病"看着好了还传染"**：如传染性红斑（第五病）在出疹前就已最可能传染，出疹时反而不再传染；这类病无法靠"症状消失"判断，只能按各自规律。
- **为什么托班标准常比家长预期更严**：老师面对一群孩子，为避免群体暴发，往往采取更保守的门槛（如腹泻停后满 48 小时）。

## 诊断信号

**月龄判断：本条覆盖出生到 12 个月，6 个月后入托的孩子最常用到。** 适用情形：孩子生病后，你或老师要判断"能不能回、什么时候回"。请按下表逐项对照孩子**当下**的状态。

## 正常范围与个体差异

按疾病对照"是否可返托"（Rx=处方药；OTC=非处方药）：

| 疾病 | 处理 | 何时可返托 |
|---|---|---|
| 普通感冒 | 无 | 退烧后 |
| 流感 | ± 抗病毒药 | 退烧后 |
| 哮吼 | ± 激素药 | 退烧后 |
| 手足口 | 无 | 退烧后 |
| 疱疹性龈口炎 | 无 | 病变愈合后 |
| 病毒性结膜炎（红眼） | 病毒无需药 | 眼睛清亮后 |
| 细菌性结膜炎 | 抗生素眼药水 | 用药满 24 小时后 |
| 肠胃炎（肠胃型感冒） | 无 | 大便成形后 |
| 病毒性皮疹 | 无 | 视具体感染而定 |
| 水痘 | ± 抗病毒药 | 全部皮疹结痂后（约 1 周） |
| 传染性红斑（第五病） | 无 | 出疹后即不再传染，可返托 |
| 脓疱疮 | 抗生素 | 用药满 24 小时后 |
| 食物中毒 | 视病原而定 | 大便成形后 |
| 贾第虫 | 抗寄生虫药 | 大便成形后 |
| 癣 | 抗真菌药 | 用药满 24 小时后 |
| 疥疮 | 外用灭疥药 | 完成 1 次治疗后 |
| 头虱 | 非处方洗剂 | 完成 1 次治疗后 |
| 蛲虫 | 非处方驱虫药 | 完成 1 次治疗后 |

补充：诺如病毒（norovirus）**症状消失 48 小时**后可返托；普通感冒的传染性集中在**头 3-4 天（通常有发热时）**，之后"只是鼻涕"即可回游戏小组。

## 实操方法

1. **先量体温**：有发热的，等**完全退烧**（不是"吃了退烧药不烧"）再考虑返托。
2. **对号入座**：在上表找到孩子的病名，核对"何时可返托"这一列。
3. **看皮损/粪便/眼睛**：水痘看是否全部结痂；腹泻看大便是否成形；结膜炎看眼睛是否清亮、是否已用药满 24 小时。
4. **寄生虫类按治疗算**：疥疮、头虱、蛲虫完成**首次治疗**即可返托，不必等"彻底没虫"。
5. **提前和托班沟通**：不同机构门槛可能更严（如腹泻满 48 小时），提前发消息确认，避免白跑。
6. **保留处方/用药记录**：涉及"用药满 24 小时"的病，返托时可能被要求确认已用药。

## 备选计策

- **"稳妥优先"家庭**：比标准再多观察半天到一天，减少被退回的尴尬（成本是多请假）。
- **"工作优先"家庭**：达到标准即返托，前提是孩子精神好、能正常吃喝。
- **"二胎/多孩"家庭**：注意大宝可能把病带回家（详见 b411-safe-cold 二胎更易病的机制），返托前也让全家做好手卫生。

## 决策规则

- **怎么算可以返托**：命中上表对应的"何时可返托"条件（多数是退烧）。
- **坚持多久再评估**：若孩子回托后又发热、或症状加重，重新按红线处理、暂停返托。
- **出现什么信号换路线**：发热反复、腹泻再次水样、皮损新发 → 不要返托，先就医。

## 反模式

- **"看着好了"就送**：没到标准的病（如水痘未结痂、腹泻未成形）仍会传染。
- **把"吃药退烧"当"退烧"**：药效一过又烧，仍具传染性。
- **腹泻刚好就送**：肠胃炎/食物中毒/贾第虫要等大便成形；诺如还要满 48 小时。
- **提前给寄生虫"清零"才敢送**：疥疮/头虱/蛲虫完成首次治疗即可，不必等彻底。
- **忽略"出疹前就传染"的病**：传染性红斑出疹时已不传染，之前反而最危险。

## 边界

- 各托幼机构标准可能比本条更严，**以孩子所在机构的实际规定为准**。
- 免疫缺陷、早产或有慢性病的患儿，返托判断应更保守、遵医生意见。
- 本条给的是"传染性"维度的返托门槛，不涉及孩子是否已恢复到能上托班的体力状态。

## 就医红线

（tier-1，2026-10-05 校准）
- **仍发热** → 不能返托；若 3 月龄内发热 ≥100.4°F（38℃），立即就医。
- **发热超过 4 天不退，或退烧后又发热** → 就医。
- **腹泻仍是水样便、带血或黏液** → 就医并暂缓返托。
- **水痘皮损出现红肿扩大或退烧后又发热** → 警惕继发细菌感染，就医。
- **眼睛分泌物增多、眼睑肿胀** → 就医。
- **精神差、拒食、脱水** → 就医，不论哪种病。

## 代价与风险提示

- 严格返托标准意味着家长要更频繁请假在家照看，误工成本真实。
- 各机构口径不一，家长需反复沟通，容易产生与老师的摩擦。
- 有些病具有"无症状期传染性"，再严格也可能无法完全避免群体传播。
- 提前返托被退回，会造成孩子、家长、老师三方的时间浪费。
