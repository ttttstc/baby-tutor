# 小腿上磕出来的瘀斑多数不用管，但这几种要查——不明原因或异常部位（臀/脸/肩/背）的瘀斑、便血或血尿、轻伤出血超过几分钟、易瘀斑伴苍白乏力；针尖样瘀点（petechiae）或大片紫癜（purpura）要立即联系医生，可能指向凝血障碍、血小板减少甚至白血病，也可能提示受虐

## 解决的问题

给孩子洗澡时，你又发现一块淤青。孩子整天跑跑跳跳，小腿上青一块紫一块似乎很正常；可这次的位置有点怪——在背上，你想不起来他什么时候磕的。老人的态度是"小孩哪个不磕碰、长大就好了"。可你也听过"淤青多可能是血液病"的说法，心里没底。

这条要回答的正是这个具体场景。AAP 指出：**活跃幼儿小腿上的瘀斑（多因小磕碰），以及运动伤后的瘀斑，通常不必担心**；但**不明原因、或出现在异常部位（屁股、脸、肩、背）的瘀斑，需要及时评估**——它们可能指向凝血问题、血小板减少，甚至**白血病**，也可能是**受虐**的信号。

## 核心判断

**先分清两种瘀斑：活动磕碰出来的（尤其小腿）、与运动有关——通常没事；不明原因、或长在屁股/脸/肩/背的——要尽快评估。** 更要立即联系医生的两类：**针尖样、按压不褪色的红点（petechiae，瘀点）**，和**较大、按压也不褪色的紫癜（purpura）**。它们提示皮肤层内出血，可能与**血小板减少**或**白血病**相关。

另外几条硬线：**大便或小便带血**、**轻伤（如小切口）出血时间超过几分钟**、**容易瘀斑同时伴苍白、乏力**、**月经过多**——都要联系医生。原书特别提醒：**不要忽视受虐的可能**，尤其在**孩子不愿说瘀斑从何而来**、或从托儿所/保姆处回来时带来**数量异常或形状怪异**的瘀斑、又显得恐惧退缩时。

## 机制

- **两个词的区别**：**出血（hemorrhage）**指血从身体组织（如皮肤）或腔体（如口、鼻、直肠）流出；**瘀斑（ecchymosis）**指血漏到皮下。
- **正常凝血过程**：健康孩子破皮后，**几分钟内**应止血、形成血凝块（结痂），覆盖伤口。**头皮**血管丰富、伤口可能特别容易出血。
- **为什么瘀斑颜色会变**：受伤后的瘀斑呈青紫色，随皮下组织愈合**缓慢变色**——这是正常过程。
- **为什么异常瘀斑危险**：可能与**感染、某些药物、影响免疫系统的疾病、凝血因子缺乏**，以及**罕见的癌症**相关。
- **为什么要警惕白血病**：白血病是**最常见的儿童癌症、占所有儿童癌症的 1/3**；多数患病孩子会**发热和苍白**，许多会出**petechiae（针尖样、压不褪色）和 purpura（较大、压不褪色）**，这些可出现在身体任何部位。
- **其他可能**：ITP（感染后血小板减少）、HSP（过敏性紫癜，累及皮肤/关节/肠道/肾）、血友病/von Willebrand 病（家族性）、严重细菌感染、药物反应。
- **证据强度**：以上为 AAP 机构性口径；"petechiae/purpura 需紧急评估"是通行做法。

## 诊断信号

适用窗口：0-6 岁全段。

用这条的处境特征：
- 瘀斑**多在小腿**、孩子活泼好动——多正常。
- 出现**不明原因或异常部位**（臀/脸/肩/背）的瘀斑。
- **便血、尿血**。
- **轻伤出血超过几分钟**不止。
- **针尖样红点 / 大片紫癜 / 瘀斑伴苍白乏力**。

## 正常范围与个体差异

- **正常瘀斑**：小腿上（尤其活跃幼儿）、运动伤后的瘀斑，**通常不构成问题**。
- **正常出血**：破皮后**几分钟内**应止血结痂。
- **异常出血的界限**：任何部位伤口**出血超过几分钟**（尤其已做急救处理仍不止），应看儿科医生。
- **药物影响**：某些药（如抗生素）可致针尖样瘀斑 + 呕吐，需换药。
- **个体差异**：血友病、von Willebrand 病**在家族中遗传**；有家族史者更需警惕。
- **虐待警示**：不明瘀斑 + 孩子不愿说来源 + 异常数量/形状 + 恐惧退缩，需评估并保护孩子。

## 实操方法

1. **区分类型**：先看瘀斑是否**解释得通**（磕碰/运动）、是否在小腿；再看有没有**异常部位/不明原因/针尖样红点**。
2. **观察出血**：轻伤后若**几分钟内**止血，多正常；**超过几分钟仍出血**（尤其急救后）就医。
3. **识别 petechiae/purpura**：针尖样或较大的红/紫点、**按压不褪色**，可出现在任何部位——立即联系医生。
4. **记录伴随症状**：发热、苍白、乏力、便血/尿血、关节肿痛、腹痛、意识改变。
5. **按红线就医**（见红线）。
6. **怀疑虐待时**：联系医生；若确认受虐，将通知相关部门并采取措施保护孩子——**孩子的安全优先**。

## 备选计策

- **家庭记录法（适合偶发瘀斑）**：拍照、记录位置与当日活动，帮助判断是否"解释得通"。
- **紧急联系医生（适合 petechiae/purpura、异常/不明瘀斑）**：尽快评估。
- **急诊（适合意识改变、剧痛、活动困难、苍白出汗肿胀）**：提示可能内出血。
- **保护儿童优先（适合疑似虐待）**：联系医生并配合保护措施。

## 决策规则

- **怎么算有效**：正常瘀斑随愈合变色、几天内消退——方向对。
- **坚持多久再评估**：普通瘀斑以数天为节点；**异常/不明瘀斑立即评估**。
- **出现什么信号换下一条**：petechiae/purpura、意识改变、扩展性瘀斑伴发热呕吐、疑似虐待 → 立即就医。
- **安全一票否决**：疑似虐待时，孩子的安全高于一切顾虑。

## 反模式

- **把异常/不明瘀斑一律当"磕碰"**：可能延误凝血/血液病诊断。
- **忽视针尖样红点或紫癜**：这是紧急评估信号。
- **忽视便血/尿血**：需查出血来源。
- **忽视"出血不止"**：可能提示凝血问题。
- **把疑似虐待当"家务事"不报**：孩子的安全优先。
- **自行停药/换药**：药物相关瘀斑需医生评估换药。

## 边界

- **性质边界**：本条聚焦"瘀斑/出血提示的系统性原因"；外伤止血现场处置见 wound 条。
- **月龄边界**：全 0-6 岁适用；婴儿不明瘀斑尤其要警惕。
- **共病**：白血病、ITP、HSP、血友病、严重感染都可表现为异常出血/瘀斑。
- **不替代诊断**：需化验（血常规、凝血）判断。

## 就医红线

（tier-1；征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

**立即联系医生/急诊：**
- **针尖样、按压不褪色的瘀点（petechiae）或较大、按压不褪色的紫癜（purpura）** → 立即联系医生（可能白血病/ITP）。
- **petechiae 伴近期患病，或出现大片扩展的瘀斑** → 联系医生；若**剧烈头痛或意识改变** → 去急诊。
- **扩展的瘀斑 + 发热、呕吐，且孩子嗜睡、恍惚或烦躁** → 立即联系医生并去急诊（严重细菌感染/受虐）。
- **从托儿所或保姆处回来，带有异常数量或形状怪异的瘀斑，且孩子恐惧或退缩** → 立即联系医生（警惕受虐）。
- **服药期间出现针尖样瘀斑并伴呕吐** → 立即联系医生（可能需换药）。
- **孩子意识改变、剧烈疼痛（含头痛）、肢体活动困难、苍白、出汗或肿胀** → 立即评估（可能内出血）。

**尽快联系医生：**
- **不明原因、或出现在异常部位（臀/脸/肩/背）的瘀斑** → 联系医生。
- **大便或小便带血** → 联系医生。
- **轻伤（小切口）出血超过几分钟** → 就医。
- **容易瘀斑，同时伴异常苍白、乏力** → 联系医生（警惕白血病等全身性疾病）。
- **黏膜（如鼻腔）出血持续数小时至数天** → 联系医生（可能血友病/von Willebrand 病）。
- **月经过多** → 联系医生。
- **腿和脚踝出现不明瘀斑，并伴腹痛、关节肿胀压痛** → 联系医生（可能过敏性紫癜）。

## 代价与风险提示

- **排查成本**：抽血化验、可能的血液科转诊，是往返与焦虑的固定成本。
- **"该不该担心"的拉扯**：多数瘀斑无害，但异常信号外观相近。
- **揭露虐待的艰难**：若怀疑受虐，家长要承担举报与保护孩子的压力。
- **家族史随访**：血友病/von Willebrand 病家族需长期管理。
