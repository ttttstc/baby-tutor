# 孩子肚子疼，最怕"连续疼满 3 小时""从肚脐转到右下腹""吐黄绿色（胆汁）东西"——这三样提示阑尾炎/肠梗阻，立刻联系医生；单纯腹痛伴呕吐腹泻多是肠胃炎，可先补液、48 小时没改善再找医生

## 解决的问题

孩子突然捂着肚子喊疼，越疼越厉害，额头冒汗，还不让你碰他的肚子。你一边想"是不是吃坏了肚子"，一边又怕"万一是阑尾炎"。到底什么时候可以再等等、什么时候必须马上送医院？能不能先给他吃片止痛药？

这条要回答的正是这个具体场景。AAP 指出：孩子腹痛原因很多，**大多数肚子疼会自己好、不需要特殊处理**，但家长必须认得那些提示"少见而严重"的原因——阑尾炎、肠梗阻、嵌顿疝、睾丸扭转、尿路感染。判断它们的关键，是**疼痛持续的时间、部位，以及有没有黄绿色呕吐物。**

## 核心判断

**急性腹痛看三条硬线：连续疼满 3 小时、疼痛"从肚脐转到右下腹"、吐黄绿色（胆汁样）东西。** 出现任一条，立即联系医生；后两条尤其指向阑尾炎或肠梗阻，拖延代价大。反之，**单纯的腹痛伴腹泻/呕吐，多数是肠胃炎，可先补液观察，48 小时没改善再联系医生。**

护理上有两条"别做"：**别强迫他吃东西**（但让他想喝就喝清液）；**别擅自给止痛药**（除非医生检查后同意）——止痛药会掩盖症状，让判断变难。若怀疑阑尾炎，**就诊前不要给他吃喝**。

## 机制

- **为什么多数腹痛没事**：孩子的腹痛可能来自任何生理或情绪原因，多数会自行消失，不需要特殊治疗。
- **为什么阑尾炎危险**：阑尾是大肠与小肠交界处的虫样小囊。当症状与检查提示阑尾炎时，应尽快切除；否则可能**破裂导致腹膜炎**（一种蔓延全腹的危险感染）。及时手术后，孩子通常恢复很快、无后遗症。
- **为什么"吐绿水"是警报**：黄绿色（胆汁样）呕吐物提示消化道梗阻，需要立即评估。
- **为什么腹股沟/睾丸肿痛要急**：可能是嵌顿疝（切断肠道血供）或睾丸扭转，都是急症。
- **为什么大多肠胃炎能等**：病毒性肠胃炎多自限；小于 6 个月继续喂母乳/配方奶，大孩子补电解质并少量恢复饮食，48 小时无改善再联系医生。
- **证据强度**：以上为 AAP 机构性诊疗口径（tier-1）。

## 诊断信号

适用窗口：0-6 岁各月龄（本题为通用急症识别）。婴幼儿无法描述疼痛，靠"痛苦征象"判断。

用这条的处境特征：
- 腹痛**突然发生、持续不退**。
- 孩子**不让轻按腹部**（拒按）。
- 疼痛**从脐周转右下腹**。
- 伴**呕吐/腹泻/发热**。
- 家人在讨论"热敷还是就医""要不要先吃止痛药"。

## 正常范围与个体差异

- **多数腹痛**会自行缓解，不需要特殊处理。
- **肠胃炎**：通常 48 小时内改善；小于 6 个月的婴儿继续喂奶，大孩子补电解质 + 少量正常饮食。
- **功能性/反复腹痛**属另一主题（慢性腹痛），不在本条。
- **UTI 组合征**：体温 >101°F（38.3℃）、尿痛/尿频/尿有异味/新出现尿床（此前已干爽数月）中**至少 2 项**，提示尿路感染。
- **个体差异**：婴儿（<1 岁）不会描述，**异常哭闹、腿往肚子上缩**就是"痛苦征象"，需按急性腹痛对待。

## 实操方法

1. **不强迫进食，但别禁水**：孩子想喝就让他喝清液；不要硬塞食物。
2. **不给止痛药**：未经医生检查并同意，不要给对乙酰氨基酚等止痛药（会掩盖病情；>3 个月且不吐、不脱水才可由医生判断）。
3. **观察并记录**：疼痛的**起病时间、时长、部位、是否转移、伴随症状**（呕吐物颜色、大便性状、尿的情况、体温）。
4. **按阈值决定动作**（见红线）：连续 ≥3 小时、转移性右下腹痛、吐绿、便血、腹部拒按、腹股沟/睾丸肿痛 → 立即联系医生。
5. **怀疑阑尾炎时**：就诊前**不给孩子吃喝**，等医生检查。
6. **肠胃炎时**：<6 个月继续母乳/配方；大孩子给电解质饮料 + 少量正常饮食；48 小时无改善联系医生。改善后给清液、尽早恢复饮食。
7. **UTI 组合征**：出现 ≥2 项（发热 >101°F、尿痛/尿频/异味/新尿床）→ 联系医生，可能需化验并用药。

## 备选计策

- **记录—观察法（适合症状轻、可观察的家庭）**：先记录时间/部位/伴随，用红线做判断依据。
- **电话分诊（适合拿不准或离医院远的家庭）**：先打给儿科/急诊分诊，按指示决定观察还是出发。
- **禁食禁水等待评估（适合怀疑阑尾炎）**：就诊前不给孩子吃喝，利于检查与可能的处理。
- **补液观察 48 小时（适合典型肠胃炎）**：按上面步骤补液，设 48 小时节点。

## 决策规则

- **怎么算有效**：腹痛缓解、能进食、无发热与呕吐——方向对，继续观察。
- **坚持多久再评估**：肠胃炎以 **48 小时**为节点；腹痛本身以**连续 3 小时**为硬线。
- **出现什么信号换下一条**：连续 ≥3 小时、转移性右下腹痛、吐绿、便血、拒按、腹股沟/睾丸肿痛 → 立即就医。
- **用药纪律**：止痛药只在医生检查并同意后使用。

## 反模式

- **擅自热敷/揉肚子当治疗**：可能让孩子更痛，也掩盖判断（原书警告勿强迫进食、按医嘱行动）。
- **先吃止痛药再观察**：掩盖症状，延误阑尾炎等诊断。
- **怀疑阑尾炎还给孩子吃喝**：增加误吸与处理风险。
- **把"吐绿水""便血"当肠胃炎硬扛**：提示梗阻/出血，需立即评估。
- **忽视婴儿的"痛苦征象"**：<1 岁异常哭闹 + 腿往肚子缩，就是腹痛的可能表现。
- **把 UTI 组合征当普通肚子疼**：≥2 项即需化验与治疗。

## 边界

- **性质边界**：本条管"突然发作"的急性腹痛识别；一周以上、时好时坏的反复腹痛见 chronic 条。
- **月龄边界**：婴儿不能自述，靠行为征象；越小的宝宝越倾向按红线就医。
- **共病**：腹痛可与呕吐、腹泻、发热叠加，需综合判断。
- **不替代诊断**：阑尾炎、肠梗阻等需影像与化验确诊。

## 就医红线

（tier-1；数值与征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

- **1 岁以下婴儿出现提示腹痛的痛苦征象**（异常哭闹、腿往肚子上缩）→ **立即联系医生**。
- **连续腹痛 ≥3 小时** → **立即联系医生**。
- **腹痛伴腹股沟或睾丸肿胀、疼痛** → 立即联系医生（嵌顿疝/睾丸扭转）。
- **呕吐或腹泻后 3 小时仍有腹痛** → 联系医生。
- **吐出黄绿色（胆汁样）物质，或呕吐物/大便带血** → **立即联系医生**（肠梗阻/出血）。
- **疼痛从脐周转移到右下腹、且连续 ≥3 小时** → 立即联系医生（警惕阑尾炎）。
- **体温 >101°F（38.3℃），并出现"尿痛、尿频、尿有异味、新发尿床"中至少 2 项** → 联系医生（尿路感染）。
- **拒绝让人轻按腹部、且腹痛超过 3 小时** → 联系医生。

## 代价与风险提示

- **判断成本高**：大多数腹痛没事，但你要为少数急症保持高警觉，容易被"要不要去医院"反复折磨。
- **孩子忍痛的煎熬**：不给止痛药、甚至禁食禁水，家长看着心疼，但这是安全所需。
- **48 小时观察的拉扯**：肠胃炎也要设节点复评，不能一味等。
- **就医门槛**：多条红线意味着不少夜晚要跑急诊。
