# 孩子喊头疼，最危险的不是疼本身，而是"伴脖子僵硬 + 高热 39℃、睡醒就疼、越来越频繁还吐"——这几种要马上就医；感冒、紧张、吃冰引的头疼多是良性，休息 + 按需止痛即可；突发剧痛或伴意识改变也属急症

## 解决的问题

孩子说头疼，是你最常听到、也最拿不准的抱怨之一：是感冒、是没睡好、是压力大，还是脑子里长了东西？要不要拍片子、要不要去医院？

这条要回答的正是这个具体场景。AAP 指出：**头痛是儿科医生最常遇到的三种复发性疼痛症状之一**（另两种是肚子痛和耳朵痛）。它分为**原发性**（不由底层疾病引起，如紧张性头痛、偏头痛）和**继发性**（有底层诱因，从良性的病毒感染、咖啡因戒断，到少见但严重的脑瘤）。**在超过 90% 的病例中，儿科医生靠体检 + 病史就能分类**，很少需要大量检查，只有极少数头痛提示严重问题。

## 核心判断

**多数头痛是良性的**——休息、补水、饿了就吃、病好了，疼痛常常自行消失；对乙酰氨基酚或布洛芬也多能缓解。但要就医的情形很明确：**头痛 + 异常嗜睡或意识模糊、不愿前屈脖子、反复睡醒时头痛（无其他病）、烦躁、拒绝喝水、体温 >102℉（39℃）、呕吐但无腹泻、肌肉无力或协调丧失**。

其中最紧急的两组合：**高热 + 嗜睡烦躁 + 脖子僵硬 + 怕光**——警惕**脑膜炎**，**立即就医**；**头痛越来越频繁、躺下或睡醒时加重、走路笨拙、呕吐**——需排除**脑瘤**等，**尽快就医**。此外，**突发剧烈头痛**也要当急症处理。

## 机制

- **头痛的分类**：**原发性**（紧张性、偏头痛）不因底层疾病；**继发性**有诱因，从良性（病毒、咖啡因戒断）到严重（脑瘤）。
- **为什么多数能自行缓解**：多因疲劳、缺水、饥饿、紧张或病毒感染——补足休息、水分、食物、等病过去，头痛就消。
- **偏头痛特征**：反复头痛、两次之间有**无症状间隔**，痛呈**搏动性、常在一侧**，伴**恶心/呕吐、腹痛、视觉或感觉先兆（闪光、手脚发麻）**，**睡一觉可缓解**，且**家族有偏头痛史**。
- **为什么记日记有用**：记录日期、时间、时长、部位、严重度，以及发病前吃的食物、压力事件等诱因，有助于找出并规避触发因素。
- **诱因**：激素变化、某些食物、压力等。
- **证据强度**：以上为 AAP 机构性口径（tier-1）。

## 诊断信号

适用窗口：以能自述头痛的幼儿与学龄儿童为主。

用这条的处境特征：
- 头痛伴**感冒/发热/咽痛**。
- **情绪紧张或疲劳**时头痛。
- **睡醒就头痛**、反复出现。
- 头痛 **+ 呕吐（但无腹泻）**。
- 头痛 **+ 脖子硬、怕光、高热**。

## 正常范围与个体差异

- **良性头痛**：感冒、紧张、疲劳、饥渴所致，多可缓解。
- **冷饮头痛**：吃冰淇淋/冷饮时因敏感神经引起，**无害、自行消退**。
- **紧张性头痛**：像"紧箍"一样的钝痛、非搏动性，常与情绪压力有关。
- **偏头痛**：有特征 + 家族史，多可在家管理；很多患儿在被医生检查、排除严重问题后，头痛反而**更少、更轻**。
- **咖啡因戒断**：青少年突然减咖啡因后 1-2 天出现，**1-2 周**消失。
- **个体差异**：是否为偏头痛、是否有诱因，决定处理。

## 实操方法

1. **看危险信号**：颈硬 + 高热 + 怕光 + 嗜睡 → 立即就医（脑膜炎）。
2. **记录头痛日记**：时间、时长、部位、严重度、发病前饮食与压力事件。
3. **偏头痛发作时**：在**安静、昏暗**的房间休息；对乙酰氨基酚/布洛芬常对轻症有效。
4. **规避诱因**：按日记找诱因、规律作息、补水进食。
5. **轻型外伤后头痛**：安抚、鼓励午睡、按需止痛；若几小时不退/加重 → 联系医生。
6. **紧张性头痛**：按需止痛；频繁则找医生，尝试找出并减少情绪压力源。
7. **视疲劳头痛**：医生查视力、必要时转眼科；调整桌椅/屏幕位置。
8. **按红线就医**。

## 备选计策

- **头痛日记 + 规避诱因（适合偏头痛）**：长期管理主力。
- **安静昏暗休息（适合偏头痛发作）**：缓解手段。
- **按需止痛（适合偶发头痛）**：对乙酰氨基酚/布洛芬。
- **压力疏导（适合紧张性头痛）**：找出并减少压力源。

## 决策规则

- **怎么算有效**：休息/止痛后头痛缓解、发作减少——方向对。
- **坚持多久再评估**：偶发头痛观察数小时；频繁/进行性立即就医。
- **出现什么信号换下一条**：颈硬 + 高热、意识改变、睡醒头痛、进行性加重、剧痛 → 立即就医。
- **用药纪律**：按体重/医嘱用止痛药。

## 反模式

- **把"颈硬 + 高热 + 怕光"当普通头痛**：警惕脑膜炎。
- **忽视"睡醒就头痛 + 呕吐"**：可能颅内问题。
- **把进行性加重的头痛当"压力大"**：需排除器质原因。
- **依赖止痛药不找诱因**：偏头痛应记日记、避诱因。
- **把"一上学就头痛"当装病**：可能是真头痛，需评估诱因。
- **忽视视力/视疲劳因素**：需查视力。

## 边界

- **性质边界**：本条以"头痛"为主轴；发热为主轴见 fever 条。
- **月龄边界**：以能自述的孩子为主。
- **共病**：脑膜炎、鼻窦炎、牙病、视疲劳、偏头痛都可表现为头痛。
- **不替代检查**：进行性/警示性头痛需影像等评估。

## 就医红线

（tier-1；数值与征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

**联系医生（孩子头痛并伴以下）：**
- **异常嗜睡或意识模糊**。
- **不愿把脖子向前弯（前屈受限）**。
- **反复在睡醒时头痛，而没有其他疾病迹象**。
- **烦躁**。
- **拒绝喝水**。
- **体温高于 102℉（39℃）**。
- **呕吐但没有腹泻**。
- **肌肉无力或协调丧失**。
- 此外，原书警示：**频繁头痛、睡醒即头痛、突发剧烈头痛、或伴呕吐**，都要告知医生（多数复发性头痛良性，但医生可能想排除底层疾病）。

**立即就医（急症信号）：**
- **体温 >102℉ + 嗜睡烦躁 + 脖子僵硬 + 怕光**（警惕脑膜炎）→ **立即联系医生**。
- **头痛越来越严重、越来越频繁；躺下或刚睡醒时更重；走路笨拙或步态异常；伴呕吐**（警惕脑瘤）→ **尽快联系医生**，可能转神经专科。

## 代价与风险提示

- **分辨成本**：多数头痛良性，但少数需立即识别。
- **偏头痛长期管理**：记日记、避诱因、随访是持续投入。
- **评估/转诊成本**：进行性头痛需影像与专科。
- **心理成本**：孩子头痛频繁时家庭焦虑上升。
