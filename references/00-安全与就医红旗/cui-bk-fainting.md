# 孩子突然昏厥——立即拨打急救，先查有没有呼吸：没呼吸就心肺复苏，有呼吸让他平躺、解开颈部衣物、头偏向一侧清口中异物；期间别喂任何食物和水

## 解决的问题

孩子玩着玩着、或在哭闹中，突然就软下去、叫不醒——这种突发昏厥，家长第一反应往往是"抱起来赶紧送医院"或"掐人中、喂口水"。原书给的处置顺序与此不同：**第一动作是立即拨打急救电话**，然后在等待救援时先做一件关键的事——**检查孩子有没有呼吸**。呼吸有或没有，接下来做什么完全不同。

这一点很关键：昏厥现场最宝贵的是"有人同时呼救 + 有人判断呼吸"。如果你一个人在场，先拨打急救电话（把手机开免提或放在旁边），再俯身检查呼吸——既争取了专业救援时间，也没耽误就地处置。切忌抱着孩子狂奔下楼、或在等待过程中只顾掐人中而漏掉"查呼吸"这个决定性的分岔。

## 核心判断

**孩子突然昏厥时，立即拨打急救电话。等待救援时先检查孩子是否有呼吸：没有呼吸，立即进行心肺复苏；有呼吸，让孩子平躺，解开颈部衣物，同时使头部偏向一侧，便于清除口中异物。注意：在此期间不要让孩子进食任何食物和水，以免发生呛咳、引发其他症状。**

## 机制

**为什么先检查呼吸**：有没有呼吸决定了下一步是心肺复苏还是体位护理——这是急救的分岔点。

**为什么有呼吸时"头偏向一侧 + 清口中异物"**：便于清除口中异物、防止误吸，保持气道通畅。

**为什么"不要喂任何食物和水"**：昏厥期间孩子可能吞咽/保护反射不全，喂食水易**发生呛咳、引发其他症状**。

（蒸馏者注：原书未展开昏厥本身的病因机制，只给处置流程；昏厥与脑供血暂时不足有关属通行急救认识，非本书逐字内容。本条仅照录原书处置。）

## 诊断信号

**月龄判断**：本条覆盖 0-6 岁全段。

用本条的处境：
- 孩子突然昏厥、叫不醒 → 立即拨打急救
- 不知有没有呼吸 → 先检查呼吸
- 没有呼吸 → 心肺复苏
- 有呼吸 → 平躺、解颈部衣物、头偏侧、清口中异物
- 家长想喂水/掐人中 → 纠正

## 正常范围与个体差异

- 有呼吸、有反应者以体位护理 + 清口物为主，等待救援
- 无呼吸者按急症立即心肺复苏，直到救援到达
- 昏厥期间一律不喂食水（含"喝口水缓一缓"的善意举动）
- 昏厥是"症状"不是"病名"，具体原因（心源性、低血糖、热性等）由医生查明，本条只管现场处置

## 实操方法

1. **立即拨打急救电话**：孩子突然昏厥，**第一动作是拨打急救电话**。
2. **检查是否有呼吸**：等待救援时，**检查孩子是否有呼吸**。
3. **没有呼吸 → 心肺复苏**：**立即进行心肺复苏**（手法见 cui-bk-cpr）。
4. **有呼吸 → 体位护理**：让孩子**平躺**，**解开颈部衣物**，同时**使头部偏向一侧**，便于**清除口中异物**。
5. **不喂食水**：期间**不要让孩子进食任何食物和水**，以免呛咳。

## 备选计策

- **"边拨打急救边检查呼吸"**：一人打、一人查——适用"有旁人在场"的情况
- **"有呼吸摆体位"**：平躺 + 解衣 + 头偏侧——适用"有呼吸"的情况
- **"无呼吸立即按压"**：转心肺复苏——适用"无呼吸"的情况
- **"手机开免提放旁边"**：一人时边通话边施救——适用"独自带娃、无人帮忙"的家庭

## 决策规则

- **怎么算"要心肺复苏"**：无呼吸 → 立即心肺复苏
- **坚持多久再评估**：无呼吸持续按压至救援到达；有呼吸者等待救援并监护
- **出现什么信号换法/就医**：呼吸由有变无 → 转心肺复苏
- **何时停止自行处理**：交急救人员/医生

## 反模式

- **抱起孩子就往医院跑、不打急救**：应就地拨打急救并按流程处置
- **不查呼吸就下手/或干等**：有无呼吸决定下一步，必须先查
- **给昏厥孩子喂水/喂食**：易呛咳，原书明确禁止
- **有呼吸却不摆体位、不清理口物**：气道可能被堵
- **只顾掐人中**：非原书处置流程，耽误关键动作
- **无呼吸仍按"有呼吸"只摆体位**：应立刻转心肺复苏

## 边界

- 本条为昏厥现场处置；病因诊断与治疗由医生完成
- 无呼吸/心跳转心肺复苏（见 cui-bk-cpr）
- 外伤后昏迷见 cui-bk-head-injury / cui-bk-fall-injury
- 具体急救建议参加正规培训

## 就医红线

**出现以下任一情况，立即拨打急救/心肺复苏**（p562，卫健委 2022 交叉，2026-10-04 核对）：

- **孩子突然昏厥**——立即拨打急救电话
- **没有呼吸**——立即心肺复苏
- **意识不清**——拨打急救，按有无呼吸处置
- **口中有异物**——头偏向一侧、及时清除

## 代价与风险提示

- 第一动作是打急救而非抱走，与直觉相反
- 要先判断有无呼吸，再决定是否心肺复苏
- 期间不能喂任何食物和水，需忍住"喂水缓一缓"
- 有呼吸时摆体位、清口物，照护细节多
