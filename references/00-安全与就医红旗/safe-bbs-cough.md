# 咳嗽是身体在清理气道——普通感冒的咳嗽约一周慢慢消退；但"呼吸有杂音/急促/困难、体温≥101°F（38.3℃）持续超过 24-48 小时、迟钝嗜睡、唇口指甲发蓝、拒绝喝水"要立即联系医生。别擅自用非处方止咳药（6 岁以下不推荐）

## 解决的问题

孩子咳个不停，你分不清是普通感冒、过敏、还是更严重的问题。止咳糖浆要不要喂？咳了一周多还不好，会不会是肺炎？要是他咳得脸发青、停不下来，是不是呛到东西了？

这条要回答的正是这个具体场景。AAP 指出：**咳嗽是身体保持气道通畅的方式**。孩子得感冒或其他小病时，咳嗽等症状会**慢慢消退**；但若咳嗽**不减慢、不停、也不减弱**，且让孩子疲惫，可能提示**哮喘、百日咳**等更严重的疾病，需要医疗帮助。

## 核心判断

**普通感冒的咳嗽约一周消退，可居家护理；但出现以下要立即联系医生：呼吸有杂音/急促/困难、体温 ≥101°F（38.3℃）持续超过 24-48 小时、迟钝或嗜睡、唇/口/指甲发蓝、拒绝喝水。** 如果咳嗽**突然发生、且无其他症状**、你怀疑他呛了小物件或食物，也要立即处理（不能说话、发蓝 → 边急救边打 911）。

一条重要纪律：**不要擅自给孩子用非处方（OTC）止咳药**。原书明确——**6 岁以下的儿童不推荐用止咳药**；6 岁以上也只有在"咳嗽影响睡眠"时才考虑，且要先问医生。**12 个月以上**的孩子可以用**蜂蜜**缓解咳嗽。

## 机制

- **为什么咳嗽是好事**：咳嗽是身体**清理气道**的机制。
- **为什么感冒咳嗽会消退**：普通感冒或其他小病时，咳嗽等症状随时间**慢慢消失**。
- **为什么"不停不减"要警惕**：更严重的疾病（如**哮喘、百日咳**）里，咳嗽**不会减速、停止或减弱**，还可能让孩子**疲惫**——这时需要医疗帮助，针对病因治疗、打开气道、清除分泌物、让孩子休息恢复。
- **croup（犬吠样咳嗽）**：多发生在 **5 岁以下**，常继发于感冒/流感等病毒感染，因此**抗生素很少有用**；**男孩更多见**；**约 5 岁会自愈**；反复发生的 croup 多由**过敏**而非感染引起。用**蒸汽浴室**或**开窗的冷空气**常能缓解；卧室放**冷雾加湿器**（尤其空气干燥时）可预防发作；**不要让孩子接触二手烟**。
- **证据强度**：以上为 AAP 机构性口径。

## 诊断信号

适用窗口：0-6 岁全段。

用这条的处境特征：
- 咳嗽伴**流鼻涕、喉咙痛**（像感冒）。
- **夜间或运动、冷空气中**加重。
- **吸气时听到高调声（stridor）**。
- 咳**很久不见好**。
- **突然咳**，你怀疑他吞了小东西。

## 正常范围与个体差异

- **感冒咳嗽**：约 **一周**消退。
- **croup**：<5 岁、约 **5 岁**自愈；男孩更多；反复者多为过敏。
- **支气管炎**：婴儿病毒性肺感染，通常**一周内**好转。
- **流感**：体温 >100.4°F（38℃）；**6 个月以上**建议每年接种流感疫苗（很大程度上可预防）。
- **过敏性鼻炎**：白天咳、夜里少、清涕不断。
- **鼻窦炎**：感冒后黄涕 + 持续咳 **≥10 天**。
- **习惯性咳嗽/抽动**：白天持续、无其他症状、**睡着就停**。
- **个体差异**：咳嗽病因多样，靠伴随症状与病程区分。

## 实操方法

1. **感冒护理**：多休息、**清流质**稀释分泌物；嘴唇鼻孔干裂可涂软膏；**>12 个月**可给**蜂蜜**止咳。
2. **croup**：用**蒸汽浴室**或**开窗冷空气**缓解；卧室放**冷雾加湿器**；避免二手烟；若呼吸费力或发蓝 → 立即急诊。
3. **别自行用 OTC 止咳药**：尤其 <6 岁；>6 岁只在影响睡眠且问过医生后用。
4. **婴儿支气管炎**：<12 个月的宝宝**使劲咳 ≥2 小时** → 联系医生。
5. **流感**：多喝水、按医嘱用对乙酰氨基酚/布洛芬退热止痛；**2 天无改善、出现皮疹或呼吸困难或更病重** → 联系医生。
6. **过敏性鼻炎**：问医生是否需要药物。
7. **鼻窦炎**：感冒后黄涕 + 持续咳 ≥10 天 → 联系医生，可能需抗生素。
8. **习惯性咳嗽**：排查并减少焦虑源、与老师沟通、必要时咨询。
9. **环境刺激**：减少暴露、家庭戒烟、至少禁止室内吸烟、尝试空气过滤。
10. **哮喘**：夜间加重、运动/冷空气咳、喘鸣 → 医生评估肺功能并制定控制方案。
11. **异物**：**不能说话、发蓝 → 边急救边打 911**；否则**立即联系医生**（需取出异物）。
12. **囊性纤维化嫌疑**：慢性咳 + 频繁感冒 + 痰难咳出且变色 + 生长慢 + 大便多油臭 + 汗咸 → 医生检查。

## 备选计策

- **居家护理（适合感冒咳嗽）**：休息、清流质、蜂蜜（>12 月）。
- **croup 缓解（适合犬吠咳）**：蒸汽浴室/开窗冷空气 + 冷雾加湿器。
- **问医生再用药（适合 >6 岁、影响睡眠）**：OTC 止咳药只在医生指导下。
- **找病因管理（适合慢性咳嗽）**：哮喘、过敏、鼻窦炎、习惯性咳嗽各有方案。

## 决策规则

- **怎么算有效**：感冒咳嗽在一周内逐日减轻——方向对。
- **坚持多久再评估**：感冒以**一周**为节点；症状加重或持续 → 联系医生。
- **出现什么信号换下一条**：呼吸杂音/急促/困难、体温 ≥101°F 持续 24-48 小时、迟钝嗜睡、发蓝、拒水 → 立即联系。
- **用药纪律**：<6 岁不用 OTC 止咳药。

## 反模式

- **擅自给 <6 岁孩子用止咳药**：不推荐，可能有害。
- **把"越咳越轻"当必然**：严重病（哮喘/百日咳）咳嗽不减反持续。
- **把 croup 当普通感冒拖**：犬吠咳 + 吸气高调声需处理，呼吸费力要急诊。
- **二手烟暴露**：尤其易诱发 croup。
- **把异物呛咳当普通咳嗽**：突然咳、无其他症状要立即处理。
- **忽视流感疫苗接种**：6 月+ 建议每年接种。

## 边界

- **性质边界**：本条是咳嗽总入口；croup、呼吸困难、喘鸣各有专条。
- **月龄边界**：<6 岁不用 OTC 止咳药；<12 月蜂蜜不可用。
- **共病**：哮喘、过敏、鼻窦炎、囊性纤维化都可表现为咳嗽。
- **不替代诊断**：慢性咳嗽需找病因。

## 就医红线

（tier-1；数值与征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

**立即联系医生（孩子咳嗽且出现）：**
- **呼吸有杂音、急促、困难**。
- **体温 ≥101°F（38.3℃），且持续超过 24-48 小时**。
- **迟钝或嗜睡**。
- **嘴唇、口腔、指甲周围发蓝**。
- **拒绝喝水**。
- **突然开始咳嗽但无其他症状，怀疑呛入小物件或食物** → 若**不能说话、发蓝**，边急救边打 911；否则立即联系医生。

**其他：**
- **感冒症状应在约一周消退**；超过一周或加重 → 联系医生。
- **<12 个月婴儿使劲咳 ≥2 小时**（支气管炎）→ 联系医生。
- **croup（犬吠咳 + 吸气高调声，<5 岁）** → 按 croup 处理；呼吸费力或发蓝 → 立即急诊。
- **流感：体温 >100.4°F（38℃），2 天无改善、出现皮疹或呼吸困难或更病重** → 联系医生。
- **鼻窦炎嫌疑：感冒后黄涕 + 持续咳 ≥10 天** → 联系医生。
- **习惯性咳嗽（白天持续、睡着即停）** → 咨询医生，可能需处理焦虑。

## 代价与风险提示

- **抵住"止咳糖浆"的催促**：要反复向长辈解释 <6 岁不推荐的原因。
- **慢性咳嗽的长期管理**：找病因、规避诱因是持续投入。
- **就医门槛**：呼吸杂音、发蓝等要立即就诊，增加往返。
- **二手烟防护**：家庭戒烟是长期功课。
