# 3 个月以下的宝宝腹泻又发热（肛温≥38℃）就得马上联系医生；任何月龄的婴儿腹泻，只要出现"呕吐、没精神不吃奶、嘴干或 3 小时以上没尿"同样要马上打电话——补液用药店的口服补液盐，别自制盐水，也别断奶

## 解决的问题

今天宝宝的大便开始不对劲：不是平时那种软便，而是水汪汪的，一天拉了好几次，可能还带点发热。你一边清理一边犯嘀咕：母乳宝宝本来大便就稀、就频繁，那到底怎么才算"拉肚子"？家里老人说"小孩拉肚子，饿两顿清清肠胃就好了"，你半信半疑；看着宝宝有点蔫、嘴唇发干，你又想快点给他补点水——是喂白开水，还是喂奶，还是自己冲点淡盐水？

这条要回答的正是这个具体场景。婴儿腹泻里最要紧的不是"止泻"，而是两件事：**认出什么时候必须联系医生**，以及**用对补液方式防止脱水**。小婴儿脱水进展快，这两点的顺序不能颠倒。

## 核心判断

**腹泻不是"稀便"，而是"一天可达 12 次的水样便"。** 对婴儿，判断危险看三样：月龄、是否发热、有没有脱水与精神变差。硬阈值是——**3 个月以下的宝宝，腹泻同时肛温 ≥38℃（100.4°F），立即联系儿科医生**；**3 个月以上、有轻腹泻和低热超过一天**的，先量体温、查尿量，然后联系医生。任何月龄只要出现**呕吐、没精神或极度烦躁不吃奶、脱水（口唇干燥、3 小时以上没尿）**，都要马上打电话。

补液的正确做法是：**用药店卖的口服补液盐（ORS）**，因为它电解质和糖的比例正确；**自制盐水/糖水不能替代**（电解质比例不对，反而有害）；**母乳照常喂**，配方奶宝宝由医生决定是否换成含电解质的特殊饮品。不要自行断奶、断食，也不要给婴儿用成人止泻药。

## 机制

- **为什么婴儿脱水快**：婴儿体内水分占比高、代谢快，一次腹泻丢掉的液体和电解质（钠、钾等）按体重比例远大于成人。所以"腹泻本身不危险，脱水才危险"。
- **为什么看水样便次数**：原书把腹泻定义为"最多一天 12 次的水样便"；单纯软便、次数不多，不一定算腹泻。母乳宝宝的便本就偏稀、偏绿，还常带种子样小颗粒，这些是正常，不等于腹泻。
- **为什么继续母乳**：母乳富含水分、电解质和抗体，能同时补液、补营养、增强抵抗，是腹泻期间最好的"药"。所以原书对母乳宝宝的建议是"照常母乳"。
- **为什么不能自制补液盐**：自制溶液的电解质比例难以掌握，原书明确指出"自制溶液可能没有正确的电解质平衡，因此不应使用"。药店预混的婴儿口服补液盐才符合比例。
- **为什么病毒性腹泻能自限**：让宝宝呕吐腹泻的病毒性肠胃炎，可能让他烦躁 1-2 天，若宝宝其他方面健康，症状会自行消退——家庭端的任务是补液与观察，而不是"止泻"。
- **证据强度**：以上为 AAP 机构性建议（tier-1）；口服补液盐防脱水是儿科公认一线措施。

## 诊断信号

适用窗口：本条偏重婴儿，尤其是**3 个月以内**；越大越接近"儿童腹泻"的处理（见相邻条目）。

用这条的处境特征：
- 大便由平日的模样变成**水样**、**次数明显增多**。
- 伴**发热、呕吐**，或宝宝**精神变差、不肯吃奶**。
- 你在纠结"要不要饿两顿""能不能自己冲盐糖水""用不用现在去医院"。
- 你分不清母乳宝宝的稀便算不算腹泻。
- 你开始留意**尿量**（这是判断脱水最实用的家用指标）。

需要区分的正常现象（不是腹泻、不必处理）：母乳便稀、频繁、带种子样颗粒；大便呈绿色。真正提示问题的粪便特征见红线（白陶土样、水样且大量黏液、硬干、发黑、带血）。

## 正常范围与个体差异

- **母乳宝宝**：大便浅黄、软甚至很稀，常带种子样小颗粒；可能每次母乳后都排便——这是正常，不是腹泻。
- **配方奶宝宝**：大便黄到褐、稠度大致像花生酱——这是正常。
- **随月龄**：无论母乳还是配方奶，宝宝长大后大便次数通常会**减少**，属于正常发育过程。
- **颜色**：带绿色调属正常。
- **什么时候才该担心**：粪便呈**白陶土样**、**水样且充满黏液**、**又硬又干**，或**发黑/带血**——这些不是正常范围，联系医生。
- **脱水家用参照**（结合原书就医点）：口唇干燥、**3 小时或更久没有排尿**，提示可能脱水。这条不等于"腹泻本身危险"，而是"脱水需要就医"。

## 实操方法

1. **先确认是不是腹泻**：是否为水样便、次数是否明显多于平日；把母乳本就稀/频繁的情形排除掉。
2. **看粪便危险特征**：白陶土样、水样伴大量黏液、又硬又干、发黑或带血 → 联系医生。
3. **按阈值决定动作**：
   - 宝宝 **<3 个月 + 腹泻 + 肛温 ≥38℃** → **立即联系儿科医生**。
   - 宝宝 **>3 个月 + 轻腹泻 + 低热超过一天** → 先检查他**尿量是否正常**、用体温计**量体温**，然后**联系儿科医生**。
4. **补液（核心动作）**：用**药店预混的婴儿口服补液盐**，按说明冲配；**不要自制盐糖水**。
5. **继续喂养**：母乳宝宝**照常母乳**；配方奶宝宝按医生指示，可能换成含电解质与糖的特殊饮品。
6. **记录尿量**：数湿尿布次数、观察口唇是否干燥、有无眼泪——这是你向医生描述"脱水风险"的关键依据。
7. **不擅自用药**：不给婴儿用成人止泻药；不自行断奶/断食。

## 备选计策

- **药店口服补液盐（适合所有家庭）**：一线补液手段，按需备几包在家，腹泻一开始就能用上。
- **继续母乳 + 少量多次（适合母乳家庭）**：与其一次喂很多，不如增加喂哺频次，减少肠胃负担。
- **就医前先电话分诊（适合离医院远或夜里发作的家庭）**：先打给儿科/急诊分诊，说明月龄、体温、尿量和精神状态，按指示决定观察还是出发。
- **记录单（适合焦虑的家长）**：把每次大便的样子/次数、尿量、体温记成小表，就诊时给医生看，比自己回忆可靠。

## 决策规则

- **怎么算有效**：补液后宝宝**精神好转、尿量恢复、口唇不干**，大便次数逐步减少——说明方向对，继续补液、继续观察。
- **坚持多久再评估**：病毒性腹泻若宝宝其他方面健康，症状通常 1-2 天自行消退；**超过 24 小时仍无改善或加重**，或出现任何红线，立即就医。
- **出现什么信号换下一条**：呕吐、没精神/不吃奶、脱水征象 → 立即联系医生，不再在家观察。
- **月龄决定优先级**：3 个月以下一旦"腹泻 + 38℃"，就医优先级最高。

## 反模式

- **自制淡盐水/糖水补液**：电解质比例无法保证，原书明确不应使用。
- **"饿两顿清清肠胃"**：婴儿腹泻不适合断食，母乳更应照常喂；断食断奶会加重脱水和低血糖风险。
- **把母乳宝宝的稀便当腹泻治**：正常便被当成病，反而会误用药物。
- **只看大便、不看尿量和精神**：婴儿脱水的危险藏在"尿少、口干、精神差"里。
- **给婴儿用成人止泻药**：不在家庭处理范围，可能有害。
- **非要在就医前"先止住泻"**：病毒性腹泻的处理目标是补液防脱水，不是止泻。

## 边界

- **月龄边界**：本条以婴儿（尤其 3 个月以下）为主；更大孩子的腹泻分级见相邻条目。
- **性质边界**：本条是"识别 + 补液 + 观察"，不替代医生对病因（病毒、细菌、过敏、寄生虫）的判断。
- **共病提醒**：腹泻伴呕吐会加速脱水，两种症状叠加时阈值更敏感。
- **家庭条件**：若一时买不到口服补液盐，应优先联系医生获取替代方案，而不是自制溶液。

## 就医红线

（tier-1；阈值与征象来自本书第1章原文，AAP healthychildren 现行页 2026-10-05 校准）

- **宝宝 <3 个月，腹泻同时肛温 ≥100.4°F（38℃）** → **立即联系儿科医生**。
- **宝宝 >3 个月，出现轻腹泻伴低热超过一天** → 检查尿量是否正常、量体温，然后**联系儿科医生**。
- **腹泻伴呕吐** → 立即联系医生（加速脱水）。
- **没精神，或极度烦躁、不肯吃奶** → 立即联系医生。
- **脱水征象**：口唇干燥、**3 小时或更久没有排尿** → 立即联系医生/就医。
- **粪便异常**：白陶土样、水样且充满黏液、又硬又干，或发黑/带血 → 联系医生。
- **体重不增或下降** → 尽快就医。

## 代价与风险提示

- **一刻不能松懈**：婴儿脱水以小时计进展，看护期间要反复查尿、口唇、精神，家长几乎没有喘息。
- **就医门槛低带来的奔波**：3 个月以下"腹泻 + 发热"即就医，注定有不少最终是普通肠胃炎的夜晚要跑医院。
- **补液方式的隐性成本**：药店口服补液盐要现买现配，比"随手兑糖盐水"麻烦，但省掉这一步就是拿安全换方便。
- **家里观念的阻力**：要反复拒绝"饿两顿就好"的说法，这在老人帮带的家庭会持续消耗沟通。
