# 宝宝两个脸颊突然红得像被打了一耳光——多半是第五病，出疹时已经不再传染、病程自限；但它对孕妇风险大，要远离孕早期的孕妇

## 解决的问题

孩子前两天有点低烧、喊喉咙痛，你没太在意。今天早上给他穿衣服，突然发现两张小脸通红通红，两颊各一块斑，对称得像被人扇了一巴掌。你吓一跳：是不是发烧烧的？是不是过敏？是不是摔了？到了下午，胳膊、肚子、大腿上又冒出一片粉色的、像蕾丝花边一样的疹子，一圈一圈的。你越看越慌，赶紧翻手机查，跳出来一个陌生名字——"第五病"。

还有一类场景更能把家长问住：家里大宝出了这种疹子，而妈妈正怀着二胎。这时"要紧不要紧"的答案完全不同——对宝宝本人，它多半是只纸老虎；可是对孕早期的孕妇，它真的需要当回事。

这条要解决的，就是认出这个"打得像扇耳光"的疹子，知道它什么时候来、什么时候不传染、什么情况必须打电话，以及——别把它传给孕妇。

## 核心判断

**脸颊鲜红如"被打耳光"、随后在手臂躯干大腿臀部出现花边样粉疹，多半是第五病（细小病毒 B19 感染）。它高度传染，但皮疹出现时孩子已经不再具有传染性；对健康的宝宝通常轻微、几乎不需治疗、可自行好转。真正要防的，是让它接触到孕妇——尤其是怀孕前三个月的孕妇。**

## 机制

**它是什么**：第五病是一种由细小病毒（parvovirus）引起的高度传染性的常见儿童疾病，也叫细小病毒感染；因为脸颊的红色皮疹，俗称"被打耳光病"。

**疹子为什么长这样、又为什么"来得晚"**：病毒先在体内活动，起皮疹前，一些孩子会先出现轻微的类感冒症状——喉咙痛、轻微发热、头痛和疲劳，瘙痒也可能是个早期信号。等面颊先出现鲜红斑块、再过几天手臂躯干大腿臀部冒出轻微隆起的粉色花边样疹子时，**疾病其实已经接近尾声**。（这是临床观察到的规律，也是本篇判断"是否还传染"的关键。）

**为什么疹子时有时无**：皮疹可能来来去去存在长达 3 个星期，当孩子暴露在极端温度下或待在太阳底下时会变得更加明显。（机制层面的解释为临床经验总结，证据强度为观察性。）

**为什么对孕妇是另一回事**：细小病毒对孕妇影响较大，如果一个孕妇在怀孕期间被感染，她肚子里的宝宝可能也会受到影响。所以让生病的孩子远离孕妇，尤其是在妊娠前 3 个月。

## 诊断信号

**月龄判断**：第五病在学龄期儿童中最常见，但婴儿和幼儿同样可感染，本条的识别与处置窗口覆盖约 4-6 月龄到学龄前。皮疹可来去持续约 3 周。

用本条的处境信号：
- 宝宝面部鲜红、发热、两颊起对称斑块，像"被打耳光"
- 随后的几天里，手臂、躯干、大腿、臀部出现轻微隆起的粉色、花边样疹子
- 出疹前有过轻微的类感冒症状或瘙痒
- 皮疹起起落落，遇热、晒太阳时更明显

**不适用**：皮疹按压不褪色、呈淤点淤斑，或孩子精神极差、呼吸吞咽困难——那不是普通第五病，直接就医。

## 正常范围与个体差异

- 面颊鲜红斑块→数日后臂/躯干/大腿/臀出现花边样粉疹，是第五病的典型疹形
- 皮疹出现在疾病接近尾声、孩子不再具有传染性时
- 皮疹可来来去去长达 3 周，遇极端温度或日晒会更明显
- 对大多数健康的宝宝，感染轻微、几乎不需要治疗
- 例外人群更重：有镰状细胞性贫血或免疫力低下的孩子，感染可能引起更严重的问题

## 实操方法

1. **先认疹形**：两颊对称鲜红斑块 + 躯干四肢花边样粉疹，出疹前有过类感冒症状——高度提示第五病。
2. **打电话给医生确认**：皮疹在家里不容易诊断，怀疑第五病时最好给宝宝的医生打电话，以确保它不是另一种需要治疗的其他疾病。
3. **让宝宝充分休息、多喝水**：确保你和孩子都得到充足的休息，喝大量的水。
4. **发热或轻微疼痛可按医嘱用对乙酰氨基酚**：缓解发热或轻微疼痛（具体用药遵医嘱，见发热条目）。
5. **不必隔离已出疹的孩子**：隔离已患第五病的孩子既不现实、也不必要——皮疹出现前你不知道孩子感染了，等皮疹出现了，他也不再具有传染性。
6. **重点防的是孕妇**：让生病的孩子远离孕妇，尤其是妊娠前 3 个月；家里有孕妇或密切接触孕妇的，提前分开、告知对方。
7. **皮疹反反复复别慌**：知道它可以来去可达 3 周、遇热遇晒更明显，不必因为"没彻底退干净"而反复折腾。

## 备选计策

- **拍照记录疹形与变化**：每天同一光线下拍面颊和躯干——适用"疹子时隐时现、就诊说不清"的家庭
- **孕妇隔离预案**：明确"谁近期要避开这个孩子"——适用"家里有孕妇或常来往孕妇"的家庭
- **就医时带上出疹时间线**：记下起疹前后几天有无发热、喉咙痛——适用"想让医生更快判断"的家庭
- **遇热遇晒加重的应对**：天热时给孩子待在凉爽环境、避免长时间日晒——适用"疹子一热就明显、家长跟着焦虑"的家庭

## 决策规则

- **怎么算"可以居家观察"**：精神、吃睡都好 + 疹形典型 + 出疹前有类感冒前驱 + 无疤痕人群（无镰状细胞贫血、免疫正常）——同时满足可先居家、电话咨询
- **怎么算有效**：疹子按约 3 周的自然病程起落、孩子整体状态平稳——即达标；不追求"疹子彻底消失"
- **坚持多久再评估**：皮疹可长达 3 周；期间只要精神好、能吃能喝就观察
- **出现什么信号换法/就医**：见"就医红线"——精神状态、呼吸吞咽、疤痕人群发热，任一出现即就医

## 反模式

- **把第五病当过敏、自行忌口**：它的疹形易与其他病毒性皮疹或药物过敏相混，确诊交给医生，别乱停食物或药物
- **皮疹不退就反复加药**：病程可长达 3 周、遇热遇晒更明显，属自然波动，不是"没好"
- **为了"消毒彻底"大动干戈**：出疹时孩子已不传染，隔离不现实也不必要
- **忽略家里的孕妇**：这是第五病真正高风险的对象，出疹期一定要让孕妇远离，尤其孕早期
- **把出疹前后当成仍在传染期**：传染窗口在出疹前的类感冒阶段，误判会让家长做无用功

## 边界

- 本条针对健康的婴儿和幼儿；**有镰状细胞性贫血或免疫力低下的孩子，感染可能更严重，不得套用"轻微自限"的判断**
- 皮疹在家不易诊断，本条的疹形识别只是"高度提示"，最终确认交给医生
- 第五条对孕妇的风险尤其集中在妊娠前 3 个月，孕中晚期风险相对低，但仍应避免接触
- 本条不覆盖发热的通用处理与退热药用法（见发热相关条目），用药一律遵医嘱
- 若出现皮疹按压不褪色、精神极差等情况，超出本条范围，按就医红线处理

## 就医红线

（原书 + 梅奥诊所第五病/细小病毒 B19 患者教育页，2026-10-04 核对）

**出现以下情况立即联系医生或就医**：

- **孩子有类似第五病的皮疹，同时患有镰状细胞性贫血或免疫力低下**——这类孩子感染可能引起更严重的问题，联系医生
- **呼吸或吞咽困难、极度嗜睡唤不醒、面色苍白**
- **高热不退、精神明显变差**
- **皮疹按压不褪色、呈淤点淤斑**
- **家长怀疑但拿不准时**——直接打电话给医生，确认不是另一种需要治疗的疾病
- **孕妇接触了疑似第五病的孩子**：即使孕妇本人无症状，也应告知产科医生，尤其孕早期

## 代价与风险提示

- 接受"皮疹在家不易诊断"，意味着必须打电话请医生把关，而不是自己拍板
- 家里有孕妇时，出疹的孩子要物理隔离，家庭安排会受影响，这是必要成本
- 皮疹可来去 3 周，家长要忍受"看着吓人却没事"的心理落差
- 对镰状细胞贫血或免疫低下的孩子，"轻微"的判断不成立，这一类绝不能按普通第五病轻描淡写
