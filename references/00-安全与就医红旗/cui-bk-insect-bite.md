# 普通蚊虫叮咬冷敷就行（别直接贴冰块）；蜂蜇用硬卡片刮出蛰针再肥皂水洗+冷敷；蜱虫用镊子贴皮夹头拔出别左右扯；红肿感染、发热呕吐、意识不清要就医

## 解决的问题

夏天孩子腿上、胳膊上一串包，又红又痒；或者被蜜蜂蜇了一下、皮肤上还留着根黑刺；又或者玩草回来发现皮肤上叮着一只蜱虫。家长最常问的是："有没有毒？要不要去医院？"原书把昆虫咬伤分成两类：**大多数轻微、不需特殊治疗**，但有一部分会过敏、或由蚊虱传播严重疾病，需要就医。

## 核心判断

**常见昆虫（蚊子、蜜蜂、蚂蚁、蜘蛛、虱子）咬伤大多症状轻微——皮肤发红、疼痛、发痒、肿胀，短时间内消失，一般不需特殊治疗。处理：轻微痒痛用冷敷（不要直接使用冰块）。蜂蜇后能用硬卡片（如银行卡）把蛰针刮出，再用肥皂水清洗伤口并冷敷。被蜱虫/虱子咬伤，用镊子紧贴皮肤夹住虫子头部拔出，千万不要左右拉扯；因可能携带病毒细菌，应尽快就医。伤口严重红肿、感染、过敏，或孩子发热、呕吐、行动异常甚至意识不清，及时就医。**

## 机制

**为什么冷敷但"不要直接使用冰块"**（p553）：冷敷可缓解痒痛；但直接贴冰块会**对皮肤造成额外的刺激**，所以要用毛巾等隔开（具体冷敷做法见 cui-bk-cold-heat-compress）。

**为什么蜂蜇要"刮"不要"捏"**（p553-554）：蜂蜇后能看到蛰针，用硬卡片刮出即可；捏挤可能把毒囊里的毒液挤进皮肤。

**为什么蜱虫/虱子不能左右拉扯**（p554）：用镊子紧贴皮肤夹住**虫子头部**拔出；**千万不要左右拉扯**，以免把虫子头部留在皮肤内、引发感染。且这类虫可能携带病毒或细菌，应尽快就医检查。

**为什么部分叮咬会成重症**（p553）：有些孩子对**毒液严重过敏**，出现大面积皮疹伴发热、红肿；有些昆虫（如蚊子、虱子）**携带病毒或细菌**，可能引发莱姆病、斑疹热、兔热病等严重感染性疾病。

## 诊断信号

**月龄判断**：本条覆盖 0-6 岁全段。户外活动多的幼儿期高发。

用本条的处境：
- 轻微痒痛、红肿，短时消退 → 冷敷缓解
- 蜂蜇、可见蛰针 → 刮针 + 肥皂水 + 冷敷
- 被蜱虫/虱子咬 → 夹头拔出 + 尽快就医
- 无法确认毒性的蜘蛛咬伤 → 就医
- 大面积皮疹、发热红肿、严重红肿感染过敏 → 就医
- 发热、呕吐、行动异常、意识不清 → 及时就医

## 正常范围与个体差异

- 大多数昆虫咬伤症状轻微、短时间消失，一般不需特殊治疗（p553）
- 少数孩子对毒液严重过敏 → 重症
- 蚊/虱等可能传播莱姆病、斑疹热、兔热病等
- 蜱虫、蜘蛛等致伤需就医评估

## 实操方法

1. **轻微痒痛**：**冷敷**叮咬处缓解不适；**不要直接使用冰块**，以免刺激皮肤。
2. **蜂蜇（蜜蜂/马蜂/黄蜂等）**：皮肤上能看到蛰针时，**用银行卡等硬卡片把蛰针刮出**，然后用**肥皂水清洗伤口并冷敷**。
3. **蜱虫/虱子**：在皮肤上找到虫子，**用镊子紧贴皮肤夹住虫子的头部拔出**，**千万不要左右拉扯**（防头部残留、感染）；因可能带病毒细菌，**尽快带孩子就医**，让医生检查是否感染。
4. **蜘蛛咬伤**：**无法确认蜘蛛的毒性时，及时带孩子就医**。
5. **出现重症信号就医**：伤口**严重红肿、感染、过敏**，或孩子**发热、呕吐、行动异常甚至意识不清**，**及时带孩子去医院**。

## 备选计策

- **"冷敷（隔布）"**：普通蚊虫叮咬居家首选——适用所有家庭
- **"卡片刮针"**：蜂蜇取刺——适用"可见蛰针"的情况
- **"镊子拔蜱 + 就医"**：蜱虫/虱子——适用"户外草丛活动后"的家庭

## 决策规则

- **怎么算"可居家"**：仅轻微痒痛、短时消退 → 冷敷；否则按红线处理
- **坚持多久再评估**：冷敷后症状很短时间应缓解；出现大面积皮疹/发热 → 就医
- **出现什么信号换法/就医**：重症过敏、蜱虫/蜘蛛咬、发热呕吐意识不清 → 就医
- **何时停止自行处理**：发现蜱虫叮入或无法确认毒性 → 转交医生

## 反模式

- **冷敷时直接贴冰块**：刺激皮肤，应隔毛巾
- **捏/挤蜂蛰针**：可能把毒液挤入，应"刮"不"捏"
- **直接拔/左右拉扯蜱虫**：虫头残留、引发感染
- **把大面积皮疹+发热当普通虫咬**：可能是过敏或虫媒病
- **蜱虫咬后不就医**：可能携带病原体
- **无法确认毒性的蜘蛛咬伤在家观察**：应就医
- **给蜇伤/咬伤处乱涂药膏偏方**：非原书处置，可能刺激

## 边界

- 本条为昆虫叮咬的现场处理与就医信号；过敏性休克等急症按急救处理（见 cui-bk-cpr，必要时抗过敏就医）
- 蜱虫拔出后仍需就医评估
- 若出现呼吸困难、全身性过敏反应，立即拨打急救
- 有过敏史的孩子被叮咬标准更严，遵专科医嘱

## 就医红线

**出现以下任一情况，及时/立即就医**（p553-554，卫健委 2022 交叉，2026-10-04 核对）：

- **被蜱虫或虱子咬伤**——尽快就医检查是否感染
- **被蜘蛛咬伤且无法确认其毒性**——及时就医
- **叮咬处严重红肿、感染、过敏**——及时就医
- **皮肤出现大面积皮疹，伴发热、红肿等**——就医
- **孩子出现发热、呕吐、行动异常**——及时就医
- **孩子出现意识不清**——立即就医/拨打急救

## 代价与风险提示

- 冷敷要隔布、不能图快直接贴冰块
- 蜂蜇取刺要"刮"不能"捏"，手法需注意
- 蜱虫要慢慢贴皮夹头拔出、不能左右扯，费心
- 蜱虫/蜘蛛/可疑重症要就医，可能白跑
