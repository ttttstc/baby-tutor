# 新生儿这些"吓人"的现象大多不用治——马牙、乳房肿胀、红色尿、耳朵变形、倒睫、总打喷嚏打嗝，看过医生确认就行

## 解决的问题

刚出生的宝宝太经不起细看了。牙龈上冒出几个黄白色小点，婆婆说是"马牙"，撸起袖子就要拿针挑；换尿布发现男宝女宝的乳房都鼓鼓的；有一次尿布上还带点粉红；耳朵一边有点卷、一边有点塌；鼻子稍微一凉就打喷嚏，一天能打十几个。

这些现象每一个都够家长在网上搜一整夜。原书的判断是一只手掌按下来的：**它们大多是新生儿正常的特殊现象，不需要治疗，也不该被"处理"。** 这条把崔书列的这一串一次讲清。

## 核心判断

**新生儿的马牙、乳房肿胀、红色尿、外耳形状异常、倒睫、频繁打喷嚏和打嗝，绝大多数是生理现象、会自行消失——核心处理原则是"不挑、不挤、不刮、不慌，观察等待"。只有少数越线表现（化脓、发红发热、伴听力未过、分泌物加深黄且眼白发红）才需要就医。**

## 机制

**马牙**（p55）：牙龈上出现的黄白色小颗粒，是上皮细胞堆积形成的角化物，不是牙、也不是"上火"。正常现象，几个月内自行脱落。处理就是**不治疗**——尤其不能挑破、不能用布擦，挑破会造成感染。

**乳房肿胀**（p56）：男宝女宝都可能出现，摸起来约硬币大小，是受母体激素影响的表现，**几周内自行恢复**。不要挤压——挤压可能引发感染（新生儿乳腺炎）。

**红色尿**（p55）：尿液呈粉红色，多是因为水分少、尿酸盐浓度高，**通常 72 小时内消失**。不是尿血。增加喂养、观察即可；持续不退或伴其他异常再就医。

**外耳形状异常**（p56）：耳朵形状不规整多因宫内受压，**几周内自行恢复**，不需要绑、不需要矫正器。若外形明显异常且听力筛查未通过，交耳科评估。

**眼分泌物多**（p56）：新生儿鼻泪管狭窄、泪液引流不畅所致，可做**鼻泪管按摩**（按医嘱手法）。但若出现**深黄色分泌物 + 白眼球泛红**，提示细菌感染，需就医。

**倒睫**（p57）：因鼻梁发育不成熟、睫毛向内扫眼角所致，随鼻梁发育**自行改善**。不要拔睫毛。

**总打喷嚏**（p57）：新生儿鼻腔窄、黏膜敏感，打喷嚏是在排出羊水、黏液，是保护性反射，不是感冒。不必因此加衣、喂药。

**总打嗝**（p57-58）：膈肌痉挛引起的打嗝是自限性的，可通过**吮吸（喂奶）或啼哭**缓解，不会伤害宝宝。不必当成"进气多"乱拍乱喂。

（各条机制为新生儿科通行解释；"不挑马牙、不挤乳房"是防感染的核心原则。）

## 诊断信号

**月龄判断**：本条覆盖出生到满月前后（newborn-early 到 newborn-adaptation）。这些现象集中在新生儿期出现，多数在数周内消退。**不适用**：满月后新出现的类似表现，或伴发热、精神差、喂养困难者，按异常处理。

用本条：新生儿期出现上述任一"看着吓人"的表现，家里主张"处理一下"，你想确认是否正常。**不适用**：出现化脓、发红发热、深黄眼分泌物伴眼白发红等越线表现——见红线。

## 正常范围与个体差异

- 马牙：牙龈黄白小颗粒，几个月内脱落
- 乳房肿胀：男宝女宝均可，约硬币大小，几周恢复
- 红色尿：粉红色，通常 72 小时内消失
- 外耳形状异常：几周自行恢复
- 眼分泌物：鼻泪管狭窄所致，可按摩；深黄+眼白发红才是感染
- 倒睫：随鼻梁发育自行改善
- 打喷嚏/打嗝：属反射，自限，吮吸或啼哭可缓解打嗝
- 个体差异：出现时间和消退速度有个体差异，但"不处理、观察"的原则一致

## 实操方法

1. **马牙**：不挑、不擦、不刮，正常喂养观察，等它自行脱落。
2. **乳房肿胀**：不挤、不揉，保持局部清洁，观察几周。
3. **红色尿**：确认是喂养不足导致尿浓缩还是正常现象；正常喂养、观察，多数 72 小时内转清。
4. **外耳**：不绑不夹，观察几周；外形明显异常或听力筛查未过，交耳科。
5. **眼分泌物**：先按医嘱做鼻泪管按摩；分泌物变深黄且白眼球泛红 → 就医。
6. **倒睫**：不拔睫毛，观察随发育改善；若频繁流泪、角膜发红 → 就医。
7. **打喷嚏/打嗝**：不因打喷嚏加衣喂药；打嗝时喂奶或让其啼哭缓解，不打乱喂养节奏。

## 备选计策

- **"现象清单"贴冰箱**：把马牙/乳房肿胀/红色尿/外耳/倒睫等贴出来，老人一念叨就对照——适用"家里老做法多"的家庭
- **拍照记录**：外形异常（耳朵、马牙）定期拍照对比，看是否在好转——适用"肉眼看不准变化"的家庭
- **一次问诊打包确认**：把几处不放心的地方攒一次儿保问清楚——适用"反复上网吓到自己"的家庭

## 决策规则

- **怎么算"正常不用管"**：符合上述生理画像、无化脓/发红发热/伴发热精神差 → 观察
- **坚持多久再评估**：红色尿 72 小时、乳房肿胀与外耳几周、马牙几个月；到期未改善再就医
- **出现什么信号换法/就医**：马牙挑破后化脓、乳房发红发热、外耳畸形伴听力未过、眼分泌物加深黄+眼白发红、打嗝伴频繁吐奶呛奶 → 就医

## 反模式

- **挑破马牙 / 用布擦马牙**：造成口腔感染，是明确禁止的做法
- **挤新生儿乳头"通了就好了"**：可引发新生儿乳腺炎
- **把红色尿当尿血、把打喷嚏当感冒**：过度处理或乱喂药
- **给耳朵绑夹矫正形状**：无益且可能压迫损伤
- **拔倒睫**：损伤睫毛毛囊与眼表

## 边界

- 本条只覆盖崔书列出的这批新生儿常见现象；新生儿期其他异常（发热、黄疸、喂养困难等）走各自条目
- "多数自愈"不等于"一律不管"：化脓、发红发热、伴听力未过等越线表现必须就医
- 早产儿、有特殊疾病的宝宝出现这些现象，遵专科医嘱

## 就医红线

- **马牙被挑破后出血、化脓**——就医（口腔感染）
- **乳房肿胀处发红、发热、有波动感**——就医（警惕新生儿乳腺炎）
- **外耳畸形伴听力筛查未通过**——耳科评估
- **眼分泌物呈深黄色且白眼球泛红**——就医（细菌感染）
- **打嗝/喂养伴频繁吐奶、呛奶、精神差**——就诊（卫健委《3岁以下婴幼儿健康养育照护指南（2022）》危重症识别，2026-10-04 核对）

## 代价与风险提示

- 顶住老做法（挑马牙、挤乳头）可能得罪长辈，要提前把原理讲清
- "看着吓人但不用治"的判断需要信任来源，误判为严重疾病会过度就医
- 观察等待意味着几天到几周的悬着，得靠记录和一次问诊来落地
- 一旦把真异常当正常（眼分泌物感染、乳房感染）拖着，会延误治疗
