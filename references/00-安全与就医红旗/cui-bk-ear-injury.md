# 耳朵进了东西——小虫用手电引、金属用磁铁吸，自己取不出来就去医院；耳朵一旦出血、红肿、流脓，或孩子说听不清，立即就医

## 解决的问题

孩子一个人玩的时候，把一颗小珠子、一粒豆子塞进了耳朵里，越掏越深；或者有小虫飞进耳道，孩子捂着耳朵大哭。你翻出棉签、耳勺想掏，又怕伤到他。耳朵眼小、里面看不见，处理不当很容易伤到耳道皮肤甚至鼓膜。

原书把耳朵受伤分成两类：**一是异物进入，二是耳部出血、红肿、流脓**。两类处理完全不同——异物要看类型想办法取出或送医，而出血/肿/脓/听不清则一律立即就医，没有家庭处理的余地。

## 核心判断

**耳内异物的处理取决于异物类型：小虫用手电照射引诱其爬出、金属小物用磁铁吸出、能看到的木制/塑料小物可用蘸胶水的回形针粘出（但稍有不慎就会伤耳道皮肤，孩子不配合别用）。自己取不出就去医院。而耳部出血、红肿、流脓，或孩子说听不清，无论有无异物都要立即就医。**

## 机制

**为什么小虫要用手电引诱**（p546）：小虫有趋光性，用手电照耳朵，让它自己顺着光爬出来，比用器具掏更安全。

**为什么金属可用磁铁吸**（p546）：小螺丝等金属异物可被磁铁吸附带出，是不接触耳道的一个方法。

**为什么回形针粘取要格外小心**（p546）：原文明确这种方法"稍有不慎就会损伤孩子的耳部皮肤"，且"如果孩子不配合，不要轻易使用"——它是一个高风险、需要配合的操作，不是首选。

**为什么要按类型分别处理**（p546）：不同异物的取出手段不同，用错方法可能把异物推得更深或损伤耳道。尤其豆类等遇水膨胀物，不能用水冲。

## 诊断信号

**月龄判断**：本条覆盖 0-6 岁全段。幼儿期（会把小物塞进耳、耳道窄）风险高；小虫入耳夏季多见。

用本条的处境：
- 明确知道或怀疑孩子把异物塞进了耳朵 → 按异物类型处理或送医
- 耳朵出血、红肿、流脓 → 立即就医
- 孩子说一边耳朵听不清、对声音反应变差 → 及时就医
- 自行尝试取出仍未成功 → 尽快送医

## 正常范围与个体差异

- 能自己处理的范围：明确类型 + 孩子能配合 + 方法对得上
- 出血、红肿、流脓、听不清，都属于必须就医的情形
- 回形针粘取属高风险操作，孩子不配合时不属可自行处理范围
- 自己取不出，属正常会遇到的情况，直接送医即可

## 实操方法

1. **先判断异物类型**，再选方法：
   - **小虫**：打开手电，照射小虫进入的那只耳朵，**用灯光引诱小虫爬出来**。
   - **小螺丝等金属物品**：可用**磁铁**将其吸出。
   - **小体积木制/塑料玩具、配件**：肉眼能看到时，可用**回形针**取出——先把回形针拉直，**在一端滴一滴不会粘到皮肤的胶水**，轻轻探入耳内把异物粘出。**稍有不慎会伤耳道皮肤，孩子不配合时不要轻易使用**。
2. **取不出立即就医**：上述方法都无法取出异物时，**尽快带孩子去医院**，不要反复硬掏。
3. **出血/红肿/流脓 → 立即就医**：一旦发现耳部出血、红肿、流脓，**立即带孩子就医**。
4. **听不清 → 就医**：孩子主诉耳朵听不清时，引起重视，**及时求助医生**。
5. **别用棉签/耳勺掏**：避免自行清洁外耳道，防止把异物推深或损伤耳道。

## 备选计策

- **"手电引诱"**：小虫类首选，安全无接触——适用"能安静配合、异物是活虫"的情况
- **"磁铁吸取"**：金属小物——适用"确认异物为金属"的情况
- **"直接送医"**：任何取不出、类型不明、孩子不配合的情形——最稳妥，适用所有家庭

## 决策规则

- **怎么算"能自己处理"**：异物类型明确 + 孩子能配合 + 方法对得上 → 可尝试；否则送医
- **坚持多久再评估**：尝试一次取不出，立即就医，不反复掏
- **出现什么信号换法/就医**：出血、红肿、流脓、听不清 → 立即就医
- **何时停止自行操作**：孩子哭闹抗拒、异物越推越深 → 停止，送医

## 反模式

- **用棉签/耳勺/镊子反复掏**：把异物推得更深、损伤耳道甚至鼓膜
- **对豆类等异物用水冲洗**：可能膨胀，加重堵塞
- **孩子不配合还硬用回形针粘取**：易伤耳道皮肤
- **出血/红肿/流脓在家观察**：延误治疗
- **把"听不清"当成孩子闹着玩**：需就医排查
- **自行清洁外耳道**：卫健委指南明确不建议

## 边界

- 本条为耳内异物与耳部外伤的现场处理；具体取出与用药由耳鼻喉医生决定
- 异物类型不明、孩子不配合时，直接送医是最安全选择
- 若伴外伤性鼓膜损伤可能，避免任何耳内操作
- 早产儿、有耳疾史的孩子遵专科医嘱

## 就医红线

**出现以下任一情况，立即/及时就医**（p546，卫健委 2022 耳及听力保护交叉，2026-10-04 核对）：

- **耳部出血、红肿、流脓**——立即带孩子就医
- **孩子主诉听不清、对声音反应变差**——及时就医
- **异物自己取不出**——尽快送医，不要反复硬掏
- **异物为豆类等可能遇水膨胀物**——送医，不要冲洗
- **耳部持续疼痛或异常**——就医（卫健委：外耳道有分泌物/异味、耳痛等及时就诊）

## 代价与风险提示

- 自己取异物要极小心，方法不对或孩子挣扎就可能伤耳道，风险不低
- 孩子不配合时只能送医，来回一趟费时费力
- 出血/红肿/流脓必须就医，家庭无法自行处理
- 反复硬掏可能把小问题拖成大问题，忍住"再试一下"的冲动
