# 动物咬伤感染风险高，被蛇、野生动物或不明犬咬要马上联系医生；虫蜇后若"嘴/舌/喉肿、皮肤湿冷苍白、虚弱意识模糊、呼吸困难"是严重过敏，打 911；蜂刺用信用卡刮出、肥皂水洗、冰敷，蜱用镊子贴着头夹出

## 解决的问题

孩子在小区被狗蹭了一口，皮破了一点；或者从公园回来，你在他腿上发现一只小小的蜱虫；又或者他被蜜蜂蜇了，肿起一片。你拿不准：这些要不要紧？要不要马上去医院？该不该处理、怎么处理？

这条要回答的正是这个具体场景。AAP 指出：**动物咬伤看起来可能很轻，但感染风险很高**；而**大多数虫咬、虫蜇只是红、痒、肿，会自行消退**——但少数人会对虫毒产生从轻微到**危及生命**的过敏反应。所以要会分：哪些在家处理，哪些必须就医。

## 核心判断

**两条最重要的边界：一，被蛇、野生动物或不明犬/动物咬伤——立即联系医生；二，虫蜇后出现严重过敏（嘴/舌/喉肿、皮肤湿冷苍白、虚弱或意识模糊、呼吸困难）——立即拨打 911。** 动物咬伤感染风险高，可能需要**破伤风加强针**或**狂犬病**评估，还可能要把动物留观或送检。

其余情况按类型处理：**蜂刺**可见时用**信用卡刮出**（别用镊子挤毒囊）、肥皂水洗、冰敷；**<2 岁用冷湿布而非冰袋**；**蜱虫**用**镊子尽量贴着头部夹住、完整拉出**（不推荐用手指或其他方法）；**蛇咬不要冰敷、不要扎止血带**，用夹板固定咬伤部位、尽快送医。

## 机制

- **为什么动物咬伤危险**：动物（及人）咬伤**感染风险高**，涉及破伤风、狂犬病等；伤口可能看似轻微，但感染可迅速进展。
- **为什么大多数虫咬没事**：多数昆虫叮咬只造成轻微红肿、刺激和瘙痒，很快消失、无需特殊处理。
- **为什么虫蜇要当心**：在某些人身上，虫毒会引发**从轻微到危及生命**的过敏反应——这就是要认识 anaphylaxis 的原因。
- **为什么要尽快完整取出蜂刺**：留在皮肤里的毒囊会持续释放毒液；**完整、快速地取出**很重要。
- **为什么蜱要正确处理**：蜱会传播**莱姆病、落基山斑疹热、兔热病**；蚊子会传播虫媒病毒，国际旅行还可能遇到带疟疾的蚊子。**取出蜱要完整**，残留口器会增加感染风险。
- **证据强度**：以上为 AAP 机构性口径（tier-1）。

## 诊断信号

适用窗口：0-6 岁全段，户外活动季节尤其相关。

用这条的处境特征：
- 被**动物（尤其陌生狗/野生动物）**咬破皮。
- 被**蜂/蜘蛛**蜇后局部红、肿、痒、痛。
- **咬/蜇处之外**也起疹子或荨麻疹。
- 从**草丛/树林**回来发现蜱虫。
- **咬伤周围**出现红纹、发热、肿胀加重。

## 正常范围与个体差异

- **局部反应正常**：多数虫咬仅红、痒、肿，**很快自行消失**。
- **动物咬伤**：即便外观轻微，也**存在较高感染风险**。
- **莱姆病特征**：被蜱咬后数天出现**"靶心样"皮疹**（中央深色斑块 + 浅色晕环 + 红色外圈）——需抗生素。
- **过敏的范围**：虫蜇过敏从轻微到致命不等；已知过敏者需随身**肾上腺素自动注射笔**（检查有效期、剂量适配）。
- **个体差异**：是否过敏、蜱是否带菌、咬伤深度都影响后果。

## 实操方法

1. **蜂刺可见 → 用信用卡刮出**；然后**肥皂水清洗**、**冰敷**（<2 岁用**冷湿布**，不用冰袋）。
2. **普通虫咬** → 冷敷减轻肿胀与不适。
3. **蜱虫** → **用镊子尽量贴着头夹住，向外拉离附着处，完整取出**；不建议用手指或别的方法。
4. **动物/人咬伤** → **肥皂水洗**，并**立即联系医生**预防感染；可能需要**破伤风加强针**；尽量**无风险地捕获动物（或保留尸体）**供狂犬病检测。
5. **蛇咬** → 立即 911 或送急诊；**不要冰敷、不要扎止血带**；用**夹板**固定咬伤部位不动；若是**珊瑚蛇**咬伤，叫急救并让孩子**保持不动**。
6. **蜘蛛咬伤** → 若怀疑是黑寡妇、棕色隐遁蛛、塔兰图拉等剧毒种，立即 911/急诊；否则肥皂水洗 + 冷敷；若局部发炎或出现溃烂，立即联系医生。
7. **水母/黄貂鱼蜇伤** → 冷敷；呼吸困难或昏厥立即 911；用衣物或沙子把触手从皮肤上刷掉。
8. **防虫**：DEET ≤30%（避开伤口/破损处，勿过量/勿吞服）；permethrin 用于衣物；香茅油 + 薄荷等天然驱虫剂稀释后用于衣物；修好纱窗；去可能有蜱的地方穿**浅色长袖长裤**、衣服喷驱虫剂、回家检查蜱。
9. **已知虫蜇过敏** → 随身带肾上腺素笔、会使用、并教其他看护人使用。

## 备选计策

- **家庭防虫包（适合户外活动多的家庭）**：镊子、驱虫剂、冷敷用品、信用卡（刮蜂刺）。
- **咬伤就医路线（适合被动物咬伤）**：尽快就医评估破伤风/狂犬病。
- **急救包 + 肾上腺素笔（适合已知虫蜇过敏）**：随身携带、定期检查有效期。
- **旅行防蚊（适合去疟疾流行区）**：纱窗、驱虫剂、必要时按医嘱预防用药。

## 决策规则

- **怎么算有效**：局部红痒在几天内减轻、无扩散、无全身症状——方向对。
- **坚持多久再评估**：局部虫咬以**数天**为节点；动物咬伤**立即**联系医生。
- **出现什么信号换下一条**：被蛇/野生动物/不明犬咬、蜇处之外起疹、蜱咬后皮疹、感染征象、发热呕吐脖硬/行为异常、严重过敏 → 立即就医/911。
- **急救纪律**：anaphylaxis 立即呼救，别在家观察。

## 反模式

- **用镊子挤蜂刺毒囊**：会挤入更多毒液——用信用卡刮出。
- **用手指拔蜱**：不推荐，易残留口器。
- **蛇咬冰敷/扎止血带**：原书明确不建议。
- **把严重过敏当普通肿**：嘴/舌/喉肿、呼吸困难是急救信号。
- **已知过敏却不带肾上腺素笔**：暴露时无法自救。
- **忽视不明犬/野生动物咬伤**：狂犬病与破伤风风险高。

## 边界

- **性质边界**：本条管咬/蜇伤的识别与急救；具体感染诊断与疫苗决策由医生负责。
- **月龄边界**：越小越倾向就医；<2 岁冷敷不用冰袋。
- **共病**：过敏体质孩子的虫蜇风险更高。
- **旅行差异**：国际旅行需考虑疟疾等地区性风险。

## 就医红线

（tier-1；征象来自本书第2章原文，AAP healthychildren 现行页 2026-10-05 校准）

出现以下任一，**立即联系医生**：
- **被蛇、野生动物或不明犬/动物咬伤**。
- **咬/蜇处之外出现皮疹或荨麻疹**。
- **蜱咬后出现皮疹及其他症状**。
- **咬伤周围出现感染征象**（红纹、发热、肿胀加重）。
- **发热、呕吐、脖子僵硬或行为异常**。

**出现严重过敏反应（anaphylaxis）症状，立即拨打 911/当地急救**：嘴、舌、喉肿胀；皮肤湿冷、苍白；虚弱或意识模糊；呼吸困难。**若孩子没有脉搏，呼救后立即开始心肺复苏（CPR）。**

其他：
- **蛇咬**（尤其响尾蛇、噬鱼蝮、珊瑚蛇、铜头蛇）→ 立即 911/急诊。
- **怀疑剧毒蜘蛛咬伤** → 立即 911/急诊。
- **水母/黄貂鱼蜇伤且气短或昏厥** → 立即 911。

## 代价与风险提示

- **户外防护的日常成本**：驱虫剂、长袖、回家查蜱是持续的功课。
- **过敏家庭的长期准备**：肾上腺素笔的携带、有效期管理、看护人培训。
- **就医门槛**：动物咬伤、蜱咬皮疹都要及时就医，增加往返。
- **旅行风险**：去疟疾流行区需额外防蚊与预防措施。
